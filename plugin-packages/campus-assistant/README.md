# 校园助手

需要 LCA v0.1.10。在插件页安装本目录并启用即可；不再导入 `student-hub/mcp.json` 或安装 `student-hub-candidates`。已装旧版时，新版启用后聊天不再重复提供旧两项工具；可以在插件页关闭旧入口，原有候选和忽略状态保留。

这个包是 LCA 的完整读取工作流适配器，使用本机已安装、已登录的 Student Hub 后端；不是独立打包的 Python/学校登录环境。默认适配当前电脑路径。其他电脑将 `connection.example.json` 复制为 `connection.json`，填已安装的后端、Python、配置路径；此文件不放账号密码。缺依赖会明确返回不可用，不能冒充空邮箱。

对桃子说“检查校园助手是否准备好了”。通过后说“扫描学校更新，读完后把需要我决定的事情放成候选卡”。一次 scan 返回 jobId；status 读取同一任务，成功后 collect 将未整理原文交给 LCA 现有抽取、引用校验和候选流程。扫描本身不等于整理完成。运行中可说“取消这次校园扫描”。启动或读取失败不会自动重发扫描。

无需扫描时说“导入已有校园事项”。插件启用时也会读取现有事项一次，不联网。重复导入保持当前确认/忽略状态；有实质日期变化才生成新版本。新采集证据保留在 Student Hub，候选决定由 LCA 保存；不会伪装成改写了 Student Hub 的 review case。

在书页看原文、确认/忽略，确认后点“导出新确认事项”，打开真实 `.ics`/Markdown。没有用户确认不导出；本地交付不等于手机日历或 Todoist 同步。附件文字整理继续使用 LCA 文件入口。学校登录、课程提交、外部同步不在本插件范围。

原始证据经主进程交给当前选择的模型：隐私独立时失败即停；跟随主模型时允许主模型读取原文。插件工具只返回进度和计数，原文不作为工具返回进入普通日志。未运行真实学校扫描的自动化结果不代表账号连通验收。
