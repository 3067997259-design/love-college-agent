# 技术文档与第三方资源说明

Love, College & Agent · LECA杨西北、任泓竹 | 上海科技大学 | 2026-10-18

### 系统架构

Electron + React + TypeScript 的 Windows 桌面应用。渲染进程通过 getSnapshot / subscribe / dispatch 等受限接口消费安全快照和发出命令；主进程拥有事实、权限、模型连接、工具执行、统一时钟和持久化。renderer 不直接取得密钥或任意 Node 文件系统能力。

| 层 | 主要职责 |
| --- | --- |
| 界面与 preload | 书本、对话、候选与交付卡、设置、工作台、迷你窗；窄 IPC 与来源校验。 |
| 主进程 | Harness、插件注册、审批、时钟调度、模型端口、校园/资料、记忆与生活、恢复与窗口管理。 |
| 本地存储 | append-only JSONL 保存事实；SQLite 投影可重建。邮件/资料正文在私有源库，成品与受管理文件分层保存。 |
| 外部服务 | 用户配置的模型、邮箱、MCP/校园后端和生成服务。外部响应按不可信数据校验。 |

### Harness：执行有边界，完成有依据

采用回合、步骤、事件收件箱、工具调用与结果组成的循环。工具白名单、步骤数、重复动作、资源预算、取消和失败处理由确定性代码约束。上游失败按配置、连接、额度、内容拦截、输出格式等分类；已经执行过的动作不因一次聊天失败而无条件重放。

工具返回、实际文件与版本核对是完成依据。命令需要逐次审批，Windows AppContainer/Job 将进程树、资源、文件范围和网络限制在受控书桌副本；确认版本后才写回。普通聊天没有任意本地目录浏览工具。

### 进程与时钟

时间走统一 Clock/Scheduler。PDF 在独立解析子进程处理，失败不拖垮应用；子进程不继承供应商凭据。开发模式使用独立 profile、假模型和鉴权调试入口；展位模式禁用调试和高风险操作。

## 上下文、隐私与校园链路

### 按来源与回合准备上下文

角色/系统约束、当前会话、合法记忆引用、当前工具结果、来源状态与本轮获授权原文分层拼接。新上传文件优先绑定紧接着的回合，后续通过 documentId 显式读取；邮件原文只在实际读取校园事项的回合补入，避免永久混进闲聊。

忽略候选会退出当前工具、原文和待投递事件；用户旧页及忽略决定保留。旧外部工具结果替换为历史回执，扫描 jobId 只保留为查询/取消句柄。工具编号可能跨回合复用，因此按当前回合的结果核对，不能仅凭编号删除。生成中权限或来源改变会使旧回复和旧工具调用失效。

原文补充不记录入普通 model/seen。外部工具正文、其直接复述及自动邮件/资料事件不作为个人记忆抽取；当时见闻证据仍供实际交付与赠笔条件核验。旧版本没有逐句来源标签，历史改写内容的语义删除不作绝对保证；已经发给供应商的内容无法撤回。

### 明确选择隐私模式

| 使用方式 | 行为 |
| --- | --- |
| 独立隐私模型 | 无工具端点处理原文，经 schema、长度、枚举、日期和逐字引用校验后只放行窄字段。服务失败停止，不回退主模型。 |
| 跟随主模型 | 用户明确关闭隔离，主模型可处理获授权的新原文。历史隔离资料不会因切换自动公开；文件需要明确重试或读取。 |

### 校园助手单插件

统一 health / import / scan / status / collect / cancel。扫描返回可持续查询的任务编号；成功后的 collect 将原始证据经主进程窄接口送入提取、校验、候选、用户确认和本地 .ics/Markdown 交付。插件工具只返回进度与计数，不把原文写进普通工具日志。

插件依赖单独安装并登录的 Student Hub。已有事项重复导入保留确认/忽略状态；实质日期变化形成新版本。来源失败不等于没有更新，候选确认不等于改写后端 review case，本地导出不等于外部日历同步。

## 持续状态与验证

### 记忆、日记和角色生活

经历记忆只从成功输入记录的允许片段抽取，保留来源、时间、作用域与纠正链，确定性检索；引用、摘要、记忆工具结果不反复成为新经历。压缩旧完整回合只改变模型投影，用户旧页保留。日切有回合、空闲和计时条件，不能在工作中途换页。

日记是角色化的主观回顾，加密保存；写入时生成并固定钥匙，不作为事实来源。未完成尝试可补写并有次数上限。地点、出返时间和带回物由代码定，离线仅补算一次虚构事件；恢复存档不虚构离线工作。真实读写要有登记材料和实际产物。

### 礼物、文件与恢复

羽毛笔绑定实际交付和角色当时可见经历；实时礼物制作需用户同意，受配置、预算和取消约束。存档包含作用域内日志、数据库备份及登记文件，校验哈希后显示概要；确认恢复前先安全备份，失败可回滚。凭据与连接配置不随存档复制，当前私人存档本身不加密。

### 本轮验证与实际使用修复

截至本稿：类型检查与 lint 通过，77 个单测文件、569 项测试通过；包含来源退出、工具编号跨回合复用、资料处理超过旧 30 秒界限以及主模型失败分类。源码 Electron 已验证引用重发/恢复，普通真实程序日志确认资料整理曾在 30 秒被截断；新版将资料整理总时限设为 90 秒，仍保留连接空闲超时、取消与资源限制。

包内回归覆盖模型配置、上传文件、校园候选、记忆、礼物、连续演示、旧页、心流、审批、备份、插件和重启。准确版本、场景数与安装器哈希以对应 Release 的 build-receipt.json 和 package-unpacked-report.json 为准，不把源码测试当成某个旧安装包的结果。

校园单插件自动化使用合成 Python/SQLite 和模型服务。本轮没有执行真实学校扫描，health 只证明后端和配置存在。历史真实聊天、工具往返、隐私及只读 IMAP 链路有独立记录，但不等于所有真实模型质量或新插件账号认证已验收。

### 明确限制

任意系统目录探索、多学校即插即用、真实 TTS/OCR 质量、长期开放式自主生活质量与跨设备自动同步不列入本版承诺。当前 Windows 安装器未签名。已有用户安装存在时，包回归在独立 profile 的包内 EXE 执行，不覆盖用户安装；第二机人工安装需单独记录。

### 配乐与提交影片

现有 V8 中文字幕短片约 207.5 秒，使用 Orangestar《花筏》（feat. 夏背）原曲。音乐著作与录音权利不属于团队；现有工程记录未包含用于赛事提交或网络发布的单独音乐授权凭证。本文如实记录这一状态，不将其写成原创音乐、已获授权或已经换曲。

本次视频定位为产品概念与叙事展示。片中长期陪伴与恢复意象属于艺术表达；真实能力由可操作应用、工具记录和实际交付文件展示。视频提交/播放范围及配乐处理由团队与主办方确认。
