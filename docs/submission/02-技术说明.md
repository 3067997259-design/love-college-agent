# 技术说明文档（草稿 · 2026-10-17 晚）

> 状态：按 [提交材料骨架](../submission.md) §3 的 12 点起草。所有“已实现”指代码与自动化/合成验收；真实外部服务、真实模型质量和安装包最终版本另有边界，见 §17。设计依据与更细的记录在 [技术方案](../tech-design.md)、`docs/engineering/` 与 `docs/research/`。

## 1. 系统概览

**产品形态：** Windows x64 Electron 桌面应用。书本式主界面（左页她的房间、右页对话与卡片），专注时缩成透明置顶迷你窗。数据全部在本机，网络只用于用户配置的模型/邮箱/MCP/生成服务。

**技术栈：** Electron 44 + React 19 + Vite/electron-vite + TypeScript；主进程用 better-sqlite3 做可重建投影，业务事实写入 append-only JSONL；模型走 OpenAI 兼容协议（按用途分 chat / background / privacy 槽位）；校园邮件走 IMAP（imapflow + mailparser）；PDF 解析在独立子进程（pdf-parse）；存档为 ZIP（jszip）；外部工具走 MCP（stdio / Streamable HTTP）；本地 GLB 礼物用 model-viewer；字体（霞鹜文楷、Long Cang）随包分发。

```text
┌──────────────────────── renderer（React，contextIsolation + sandbox）────────────────────────┐
│ 书本：左页房间／外景、右页对话与卡片、工作台、设置、书签     迷你窗（独立 BrowserWindow）        │
│           ▲ 只读 AppSnapshot（安全投影）        │ 白名单命令（10 个方法 / 11 条 IPC 通道）      │
└───────────┼──────────────────────────────────────┼─────────────────────────────────────────────┘
            │ preload 窄 bridge（不暴露 Node/路径/配置）│ 校验 sender 与 surface
┌───────────┴──────────────────────────────────────┴─────────────────────────────────────────────┐
│ 主进程：统一 Clock／Scheduler／Harness／插件注册表／日志与投影／SQLite 缓存／模型端口／            │
│        privacy 滤芯／私有源库（邮件、资料）／记忆／心流与书桌／备份恢复／MCP／资源账本／窗口管理    │
└───────┬───────────────────┬───────────────────┬───────────────────┬───────────────────────────┘
        │ append-only JSONL │ SQLite 投影        │ 私有 SQLite       │ 外部（经用户配置与逐次批准）
        │ journals/<scope>/ │ 可重放重建          │ 邮件/附件原文     │ 模型 API／IMAP／MCP／Rodin
```

## 2. 进程、数据所有者与共享接口

- 主进程是唯一的数据所有者：业务事实、日志、SQLite、私有源库、模型配置、MCP 配置与存档都在主进程；渲染层只消费 `src/shared/` 的安全状态与白名单命令。
- preload 在 contextIsolation + sandbox 下提供窄 bridge；不暴露 Node、任意文件路径或供应商配置。窗口命令校验实际 sender 主 frame；hover/move 只有迷你窗可发。
- 统一时钟（`src/main/clock`）：业务代码禁止直接 `Date.now`/`setTimeout`，由 ESLint 拦截；可注入时钟供测试与演示加速，但“回书本”“窗口过渡”等原生可见性用系统时钟。
- 渲染层与主进程之间是快照 + 命令 + 事件：命令 accepted 只表示接收，实际结果由后续状态给出。

## 3. 日志、投影与统一时钟

- 业务事件按作用域追加到 `journals/<owner hash>/<day>.jsonl`；每行有单调 seq，写入前校验文件大小未变、fsync，损坏即失败关闭，不截断、不回写。
- SQLite 是可重建缓存：启动时从日志重放投影；界面与她的上下文都是日志的投影。压缩只改变给模型看的旧回合投影，不删原始事件；用户旧页保留。
- 用户与角色进入作用域；按上海时间 04:00 划分日会话；UI revision/epoch 与日志 seq 分开。
- 日志中不写邮件/附件/成品原文、模型推理、密钥；私有内容留在主进程私有库，访问走用户专用接口。

## 4. Harness：有界执行

- 每一回合是一个有界循环：模型 → 工具 → 工具结果 → …，每回合最多 12 步；同一调用第三次即停；支持停止、取消、超时和每日用量上限。
- 收件箱（inbox）：用户新消息、审批、工具进度在步边界并入；心流任务与普通聊天共用一套回合语义但作用域隔离。
- 完成判定看工具结果与校验后的文件，不看模型一句“做完了”。失败按类（配置错误、上游繁忙、网络、余额、内容被拦截、半截回复）分类给旁白与重试，旁白是书本的声音、不替她说话。
- 活动模板与旁白文案在独立 JSON（`voice/*.zh.json`、`narrator.zh.json`），代码只引用；模型输出继续当不可信数据。

## 5. 番茄钟与相处节奏

- 计时由确定性代码负责（`src/main/pomodoro`），模型只通过工具/命令使用它；阶段事件持久化，重启后按截止点核对，跨 04:00 与过期只结算一次。
- 计划有三种状态：生效计划、单独待确认的提案（proposal）、已完成进度；确认/丢弃任一阶段都不丢当前计时与已完成数。`plannedCount` 是当天总数，`get_timer` 返回已完成数。
- 专注 = 安静陪伴：书合上、迷你窗显示手上的活，她不主动开口；休息 = 交付与交流；熄灯 = 暂停计时与所有后台活动，不等于睡眠。

## 6. 记忆

- 来源：只从**成功模型输入记录**（model/seen）的允许片段抽取；邮件、附件、整理成品、私有源库与工具原始结果不参与。记忆条目带来源、时间、用户/角色作用域、纠正/取代链与未审核标记。
- 检索是确定性的（中文二字片段相关度 + 时间衰减 + 被想起次数），不引入向量库；召回引用、日摘要和记忆工具返回不递归变成新经历。
- 层级：日摘要 → 周/月归并（追加版本、保留来源）；上层摘要依赖的日摘要被纠正后失效（新鲜性守卫）。跨日翻页在 04:00 后、回合结束、最近发送空闲两分钟、未熄灯且番茄未运行后发生。
- 压缩：`/compact` 只替换旧完整回合的模型投影；用户仍能在“历史会话”看原文。

## 7. 外部内容、权限与隐私

- **privacy 滤芯：** 标了“可能处理隐私数据”的插件，原文先交给 privacy 专用、无工具的模型，只输出 schema 允许的短字段或直接交用户的成品；日期、逐字证据、长度、枚举由代码校验；privacy 缺失/失败就停止，**不回退 chat/background**。邮件正文固定走隔离，附件与拖入文件由 `/privacy` 开关控制。
- **MCP：** 连接前在原生对话框核对启动目标与 fingerprint，只开放 allowTools 白名单；stdio 支持 command/args/cwd/env，HTTP 支持 Streamable HTTP；重启不自动重连；默认隔离、无模糊重试。
- **命令执行：** 心流中的真实 cmd 使用 AppContainer/Job 限制在书桌副本、无网络、限进程树与资源；版本核对通过才写回，编码不能保真则明确失败；逐次人工审批，展位禁用。
- **Electron 安全：** contextIsolation + sandbox + CSP；renderer 不关闭资源内联；CDP 与本机鉴权 MCP 只在显式开发模式、独立 profile 中开启，展位模式禁用。
- **`data-*` 可断言界面：** 姿势、地点、阶段、审批、回退状态都有 `data-*` 标记；自动化不靠截图比对。

## 8. 数据模型、备份与恢复

- `.lca-save` v1 是当前用户的私人 ZIP：四个 SQLite 的 backup、作用域过滤、日志与已登记文件，每项 SHA-256；凭据、连接、调试配置排除；已载入应用密钥时拒绝导出。存档不加密（当前明确标注，不能当公开角色包分享）。
- 导入：校验 → 用户核对 incoming 概要 → 确认后自动创建恢复前存档 → 关闭连接、重启、可回滚替换；保留其他所有者数据；恢复原会话与剩余计时，不把恢复间隔计作在线工作。
- 恢复后颜色从羽毛笔尖晕开、房间重新上色（界面语义与片子第 18 镜呼应）。

## 9. 校园流程：证据 → 候选 → 确认 → 交付

- 只读指定文件夹；每次只读最近未读、最多 30 封；来源失败、登录失效、解析失败明确区分为“看不到”，不能说成“没有更新”。
- 候选卡展示邮件原文、原始截止时间、建议完成时间；原始截止与用户计划完成时间分别保存；确认/忽略必须带候选当前 revision，防并发误确认。
- 确认后生成实际 `.ics` 与 Markdown；改期走变更卡（同 UID、递增 SEQUENCE）；扫描≠用户接受全部建议；外部日历实际写入与手机重复导入需另行验收。
- 相对日期由代码规范化；证据高亮按原文 UTF-16 偏移，找不到就报错，不让假数据悄悄错位。

## 10. 世界泡与她的生活

- 世界泡按真实时间推进、作息跟用户；地点、时间、带回物等事实由代码定，模型只负责措辞。离线期间只一次性补算虚构事件，恢复存档不补空档，不声称停机期间真实工作过。
- 外出：确定性出返、物品来源、桌面/抽屉投影；工作优先返回。左页外出页复用片子外景（海岸/秋千），去向与回来时刻来自快照。
- 自主作品：只能从登记过的书桌材料读写；实际文件提交后才推进步数或完成；重启/私人恢复保持检查点，离线不补工作。
- 日记：写时定钥匙、加密存她的文件夹；正文只走用户专用接口，不加入模型上下文或调试状态；日记是主观产物，不是事实来源。

## 11. 心流与工具

- 一次一场心流：冻结人设与前文摘要成前缀，工作投影独立；退出时工作摘要并入对话。计划/执行、命令与回执、diff、撤回、只读分身、提问、`/init` `/review` 草稿、`/goal` 目标、书桌预览、网页读取、computer use、Microsoft Minecraft 展位模式等都在同一审批框架内。
- 书桌只是她房间文件夹里的 `书桌/`：拒绝绝对路径、`..`、符号链接/硬链接与 realpath 越界；Git 影子提交只版本化本步修改文件，不执行原仓库 hooks、不改其 refs/索引/配置。
- 回退不是跨文件原子事务：逐文件版本核对 + 补偿，写回不确定时明确失败/未知；不撤销文件之外的副作用。

## 12. 语音与光学记忆（可选）

- 语音：可选、默认静音；唯一书本播放器，PCM 分块、取消、预算与失败回退纯文字；无 TTS 配置时只保留接线与开发模式合成测试音（不冒充她的声音）。嘴型音量信号已接到 `data-mouth` 三档，并按档位切换 2026-10-17 晚采用的半张/张开面部贴片；真实嘴型观感要等 TTS 服务确定后再验收。
- 光学记忆：默认关闭；把当时可见的旧对话排成真实印刷 PNG，四档解码后只保留能对上原话的残片，明确标“未审核印象”；不宣称已做出人类式遗忘曲线。

## 13. 资源预算与安全诊断

- 模型/语音准入进入存档外的 append-only 账本，跨进程锁；恢复书本或切换个人/展位不返还用量；默认日模型上限 50 万 token（自主活动最多 10 万），语音按自然日字符/次数另计。
- 调试入口：开发模式独立 profile、CDP 带鉴权本机 MCP、诊断只读且不返回密钥；展位模式禁用。

- 当前 `main`（本说明起草时）：`tsc --noEmit`（node/web）通过、ESLint 通过、**72 个测试文件 / 506 项 Vitest 全过**（真实日志/投影/时钟/文件系统，非纯 mock）。
- 历史验收：GitHub Actions Windows CI（workflow 存在；最近成功对应已推送的 `a8a0ed7`，当前本地 HEAD 尚未推送）、真实安装版 26 项原生场景（源码基线 `3edea7c`，含同档连续链、私人恢复、命令恢复、问答、资源账本、隐私探针隔离）。当前 UI/素材改动尚未重打安装包。
- 单独记录并区分：设计完成、代码存在、自动化测试通过、真实模型/工具通过、UI 体验通过、重启/跨天通过；合成 HTTP/fake 模型不写成真实质量。

## 15. 与 AIRI 的关系（单列）

- **独立实现，不是套壳：** 技术栈不同（React 对 Vue），目录、接口、进程模型与数据模型按本产品重新设计；本仓库没有 AIRI 的运行时代码。
- **参考的设计思想（注明）：** AIRI 及其 fork 的 append-only 日志/投影思路、记忆的抽取/重排/晋升/取代（继承原作者 Neko 的 DevLog 2025-04-14）、设置页的信息架构；fork 的 life-mode/flow 设计作为体验参考，未整体迁移。
- **本项目新做的：** 番茄钟作为相处节奏、校园证据→候选→确认→交付链、书本界面与生活投影、羽毛笔存档、隐私滤芯与有界执行/审批体系、心流书桌沙盒、私有存档格式等。
- 不复制代码；具体引用按赛事规则与来源许可记录。

## 16. 参考与改动说明

- **deepseek-harness（dsh）：** 借鉴“回合/步/插话收件箱/插件装配”概念与工程组织思路，不以其为底座。
- **Student Hub：** 作为外部 MCP server 接入（作者赛前已有项目），不搬代码、不读其私有数据；MCP 现有工具面小于底层能力，接入不等于全部校园业务接通。
- **mcpfabric：** 展位通过 MCP 配置接入的 MIT mod，代码不在本仓库。
- **Nestopi / 星穹铁道 PV：** 体验与视觉叙事参考，不复制素材与具体镜头。
- **模型与工具：** 用户自备对话模型密钥；图像由 NovelAI 底稿 + 内置 GPT-image 精修（工具未报版本）；Rodin 经 MCP 生成 3D 礼物；TTS/OCR 供应商未定。

## 17. 已知限制与未验收清单

- 真实 IMAP 连接被网络在认证前重置；学校 privacy 端点地址未拿到（业务按设计关闭，不回退主模型）。
- TTS/OCR 未选型；语音默认关闭，嘴型真实观感待 TTS 验收。眨眼、窗口 focus 抬头、`think` 表情、室内与海岸夜景重光已在 2026-10-17 晚接入（差分批次）；夜里暂不眨眼/张嘴（夜景整帧没有对应贴片），`think` 夜间仍走调色回退。
- MC 双客户端与实机画质未验收；Rodin 真实生成只用过 1/3 次预算；真实模型任务质量未系统验收（多为 fake/合成 HTTP）。
- 安装包当前未签名、不是最新 UI 的重打包版本；干净第二台机器安装、投影仪/多显示器、真人桌面穿透待人工验收。
- 展位/个人多 profile、真实存档加密、跨设备同步不是本版范围。
