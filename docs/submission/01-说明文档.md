## 2. 简介

**一句话定位：** 一个会替大学生干活、也不会忘记你的桌面 Agent。

她住在 Windows 桌面的一本电子书里：左页是她的房间和一天的光线，右页是你们的对话。你把校园邮件、资料处理和要做的事交给她；她按番茄钟的日子陪你专注、在休息时把成果递回来。她不只“说一句回一句”：她有自己的作息，会读书、写东西、出门，把带回来的小东西摆在自己书桌上；共同经历会被记住并可以带走——私人存档在界面上就是她送你的那支羽毛笔。名字里的 Love，指的是陪伴和被记住。

## 4. 功能说明（按演示顺序）

> 截图见 `screenshots/`。当前几张是浏览器假数据预览（占位），提交前替换为真实演示截图。

### 4.1 书本主界面与三种情境

左页是她的房间：在做用户交给的事时坐在电脑前，安静陪伴时低头写字，休息/交流时转过来面向你；门牌切换情境，熄灯暂停计时与后台活动，条绒把番茄串成一天。她会每 2–6 秒眨一次眼，窗口重新获得焦点时会抬头看你一眼；夜里是画内重光的夜景，不是给白天图加滤镜。右页是对话、候选卡、交付卡与工作台。窗口缩小为桌面角落的透明迷你窗，专注时她安静陪着，纸条上写着她手上的活。

### 4.2 计划与番茄钟

你在对话里说“今天要把作业和分享会排一下”，她排成几个番茄并给出草案；确认后开始计时。专注时书合上、缩成迷你窗，她不主动说话；铃响后展开，交付与交流在休息段发生。计划条目、独立草案与当天的已完成进度分别保存，任何阶段确认都不丢当前进度。

### 4.3 校园邮件 → 证据 → 确认 → 日程文件（演示主线）

- 她只读指定邮箱文件夹；候选卡上带着邮件原文和原始截止时间，按“证据 → 候选 → 确认”给你核对。
- 你确认后，她生成实际的 `.ics` 和 Markdown 到本机；老师改截止时间时走变更卡，同 UID 更新。
- **边界：** 本机网络当前在 IMAP 认证前被重置，现场演示使用事先放入的演示邮件/演示存档，台上如实说明；不把合成邮件说成现场读取。

### 4.4 资料处理与隐私滤芯

拖入或选择资料、邮件附件走同一套私有源库；开 `/privacy` 时原文只交给配置的隐私模型（只输出校验过的短字段/成品），模型拿不到原文，失败就停、不退回主模型。整理成品只给你，邮件与资料原文不进普通日志、快照或对话上下文。

### 4.5 记忆、往回翻与引用回忆

一天一页；跨日后可以往回翻，左页换成那天拍下的照片。选中她当时真的看见过的一句话点“引用”，她只按当时的材料回忆，邮件/附件/成品/工作原文不会被翻出来。被纠正的事实保留来源和取代关系。

### 4.6 她自己的生活

按真实时间推进的作息；你休息、看起来是休息日时她可能出门，回来带回小东西摆在窗台上。外出时左页是她在外面的一页（复用片子里的外景），去向和回来时刻由主进程定。她也可以在自己的书桌上读写登记过的材料，只有实际提交的产物才推进进度。

### 4.7 礼物、羽毛笔与私人存档

第一件真事之后，她把羽毛笔递给你；笔就是私人存档入口，点击从书缝里的笔导出 `.lca-save`。恢复时颜色从笔尖晕开、房间重新上色，之前发生的事还在记忆与书页里。礼物架上的每件礼物写明来自哪段经历；没有配置 Rodin 时只有这支笔。

### 4.8 心流与工具权限

需要写代码、改书桌、读网页或点预览时进入心流工作台：计划、执行、diff、撤回、分身、提问。写文件和运行命令逐次等你批准；命令限制在她自己的书桌副本与受控环境里，不继承密钥、不碰系统其他位置。

### 4.9 设置、部署与展位

正常模式从原生文件选择导入模型配置（只主进程读取，界面只显示装配状态）；开发模式使用独立 profile 与假模型；展位模式使用独立数据区、禁用调试与运行代码。
