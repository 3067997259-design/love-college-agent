## 1. 系统要求

- Windows 10/11，64 位（x64）。
- 磁盘：安装包约 252 MiB，安装后预留约 1 GB 给程序与本地数据（日志、SQLite、投影文件会随使用增长）。
- 内存：建议 8 GB 以上。
- 网络：安装时不需要网络；使用时需要能访问用户所配置的模型服务（以及可选的邮箱/MCP）。纯本机预览、设置和小窗不需要联网。
- 不需要安装 Node、pnpm、Python 或浏览器；安装版自带运行时。

1. 下载 `Love-College-Agent-0.1.0-Setup.exe`：GitHub Release `v0.1.1`，直达链接 `https://github.com/3067997259-design/love-college-agent/releases/download/v0.1.1/Love-College-Agent-0.1.0-Setup.exe`（release 页：`https://github.com/3067997259-design/love-college-agent/releases/tag/v0.1.1`）。文件 264,344,481 字节，SHA-256 `770554c225c426da7632dc8e421c82f39d4f59cff2d30bc8d411758529499710`。仓库目前 private，代码冻结后转 public；在此之前可在本机 `D:\lca-gpt\release\` 取同一文件。
2. 双击安装。当前安装包**未做代码签名**，Windows SmartScreen 可能提示“未知发布者”：选择“更多信息 → 仍要运行”。其他杀软误报同理，请核对上面的哈希。

4. 安装完成后从开始菜单启动。

## 3. 首次启动

向导里的必填步骤对应应用里的真实入口：

1. **你的名字**：只存在本机档案里，用于她被叫你的称呼。
2. **模型配置**：点“选择配置文件”，读取一个 JSON；格式见 §4。体检通过后才能下一步。
3. **她的名字和基础身份**：默认使用内置桃子人设；也可以在这一步导入角色包（静态素材回退，不生成差分）。
4. **已经有一本书了**：如果之前导出过私人存档，在这一步选“我已经有一本书了”导入 `.lca-save`；应用会校验、显示 incoming 概要，确认后自动先备份当前数据再恢复并重启。

## 4. 模型配置（providers JSON）

正常模式从“工具与设置 → 模型配置”用系统文件选择框导入，内容形如：

```json
{
  "providers": {
    "chat":       { "base_url": "https://…", "api_key": "…", "model": "…" },
    "background": { "base_url": "https://…", "api_key": "…", "model": "…" },
    "privacy":    { "base_url": "https://…", "api_key": "…", "model": "…" }
  }
}
```

- 槽位：`chat`（主对话）、`background`（记忆/摘要/分身等后台）、`chat_google` / `chat_claude`（可选，多供应商按用途）、`privacy`（隐私滤芯，必须**无工具**、只输出短字段的模型）。
- 配置只由主进程读取，保存到数据根 `connections/providers.json`，重启后应用；界面只显示“已装配/已配置”，**不显示密钥值**。保存成功不代表连接成功。
- **privacy 缺失或调用失败时，邮件/附件/资料等隔离业务按设计停止，不回退主模型。** 不配置 privacy 时，路演/展示要照实说“跟随主模型、这次没走隔离”。
- 开发/展位模式不读取真实配置；展位模式使用独立数据区和设置。

## 5. 可选配置

- **邮箱**：正常的 IMAP 收信需要单独的邮箱配置（当前开发环境本机网络在认证前被重置，真实 IMAP 连接仍为阻塞项）。没有配置时邮箱能力显示未就绪；**连不上不等于没有新邮件**，她不会看到信。
- **MCP server**：在设置页用系统文件选择框导入标准 `mcpServers` JSON；每个 server 默认 `allowTools=[]`、`privacy=always`。连接前会在原生窗口核对 fingerprint 与实际启动目标；重启不自动重连；只把明确列入白名单的工具给她。
- **语音（可选）**：默认关闭；配置 `providers.tts`（OpenAI speech 兼容协议、HTTPS、model、voice、密钥）后才可用；失败只显示“语音失败，已改为纯文字”，不影响对话。
- **光学记忆（可选）**：默认关闭，把旧页封成印刷图再按清晰度读回，作为“未审核印象”；不代表人类遗忘曲线。

## 6. 数据位置、备份与卸载

- 安装版数据在 Electron 用户数据目录（默认 `%APPDATA%` 下应用目录）；源码运行默认 `<checkout>/.local-data`；可用环境变量 `LCA_DATA_DIR` 指定独立数据目录（多实例/测试用）。
- 正常安装且未指定 `LCA_DATA_DIR` 时，她的房间投影（日志/数据库的投影文件）放在“文档/桃子的房间/…”，不同数据根不共用。
- **备份/恢复**：界面上的入口就是她送你的**羽毛笔**（书缝里，点击导出 `.lca-save`）；设置页也有导出。恢复走向导“我已经有一本书了”或设置页导入；恢复前自动备份当前数据。
- **注意：** 当前 `.lca-save` 含私有邮件/资料源库且**不加密**，只能作为自己的私人存档，不能当公开角色包分享，也不要上传到公开网络。
- **卸载**：从“应用和功能”卸载；不会自动删除用户数据。彻底清除需手动删除用户数据目录与“桃子的房间”投影目录。

## 7. 从源码构建（开发/复现用）

本机验证环境：Windows + Node 24.14.0 + pnpm 11.24.0。

```powershell
Set-Location '<repo>'
$env:PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD = '1'
pnpm store path                 # 本机为 D:\.pnpm-store\v11
pnpm install --frozen-lockfile
pnpm setup:electron             # 下载/确认 Electron（缓存与临时目录放 D 盘）
pnpm rebuild:native             # 为当前 Electron 从源码重编译 better-sqlite3
pnpm probe:sqlite               # 验证原生模块加载与写盘重开
pnpm dev                        # 开发运行
# 或
pnpm build && pnpm start        # 构建后预览
pnpm package:win                # 生成 Windows x64 NSIS（release/）
pnpm test:package               # 对实际安装包做原生探针/场景（需要真实安装）
```

- 每个 checkout 单独安装依赖，不共用 `node_modules`；多实例时用 `LCA_DATA_DIR`、`LCA_RENDERER_PORT`、`LCA_CDP_PORT`、`LCA_MCP_PORT` 分开。
- 打包前先确认 `pnpm rebuild:native` 与 `pnpm probe:sqlite` 通过；不要手改锁文件。
- 不运行 `playwright install`；场景测试用本机已装的 Electron/Chrome。

## 8. 常见问题

| 现象 | 处理 |
| --- | --- |
| SmartScreen 拦截 | 未签名属正常；核对安装包 SHA-256 后选择“仍要运行”。 |
| 模型配置报“配置错误/上游繁忙/网络/余额不足/内容被拦截” | 这些是分开的错误类别；先在设置里检查 base_url/model/密钥与余额，网络问题稍后重试。错误详情可点开查看原因代码。 |
| 邮箱登不上 | 她不会显示“没有新邮件”；检查 IMAP 配置与网络/代理。当前本机已知认证前连接被重置的阻塞。 |
| privacy 未配置/失败 | 隔离业务停止且不回退主模型；配置无工具的 privacy 模型，或明确接受“跟随主模型”的口径。 |
| 迷你窗黑底/黑角 | 显卡驱动兼容问题；启动前设置 `LCA_MINI_OPAQUE=1` 使用不透明圆角回退。 |
| 端口/单实例冲突 | 用 `LCA_DATA_DIR` 与端口环境变量为每个实例分开数据与端口；同一数据根只开一个实例。 |
| 想重置但保留旧数据 | 不要删除数据来“清空书本”；用独立空 profile/数据目录，或先导出存档再在设置里重置。 |
