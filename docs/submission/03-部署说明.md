# Windows 部署说明

2026-10-18，面向 v0.1.10。完整操作卡见 [安装到首聊](../exhibition/first-run.md)，构建来源、哈希与验收范围见 [发布记录](../engineering/release-0.1.10.md)。旧版本记录留在 Git 历史，不套用到新包。

## 安装与首聊

1. 使用 Windows 10/11 x64；预留约 1 GB 空间。应用自带 Electron，不需要另装 Node、pnpm 或 Python。
2. 从 Release 或操作者提供的副本取得 Love-College-Agent-0.1.10-Setup.exe，核对同目录 SHA256SUMS.txt。安装包未签名；确认来源后处理 Windows 提示。仓库目前 private，未登录下载尚不可保证。
3. 退出已有应用后安装。若提示无法关闭，先关闭书本与托盘中的应用再重试；不要删除用户数据来解决安装问题。
4. 安装器创建桌面/开始菜单快捷方式，结束不自动启动。双击 Love College Agent；也可运行安装目录中的 LoveCollegeAgent.exe。
5. 向导填写昵称，配置日常对话并保存、测试连接。模型连接保存立即生效；固定欢迎词不算模型验收。发送第一句，重开应用验证聊天保留，再让她调用时间工具。

## 模型与隐私

在“工具与设置 → 模型与声音”配置连接，或用原生选择框导入 providers JSON。密钥仅由主进程保存，不能放进公开卡包、截图或提交材料。

- 记忆与日记可跟随主模型，也可独立配置。
- 隐私“跟随主模型”明确表示关闭隔离，主模型可读取新邮件/资料原文。公开演示使用公开样例。
- 独立隐私模式失败即停，不自动回退主模型。历史隔离资料不因切换自动公开，需显式重试。
- 模型连接和路由即时生效；语音、Rodin、邮箱按界面提示重启。新安装默认跟随；旧独立配置保留，需明确切换。
- v0.1.10 修复了旧 providers 附加字段/BOM 导入问题、过短的资料整理时限及跟随模式错误分类；未经操作者重试，不能宣称其真实请求已成功。

## 校园助手与可选能力

解压 LCA-Campus-Assistant-v0.1.0.zip，在插件页安装 campus-assistant 目录并启用。它使用本机已有且已登录的 Student Hub 后端；不附带 Python、后端工程、凭据、数据库或登录状态。另一台机器需独立安装/配置依赖，按插件 README 指定路径。缺依赖不是“没有学校更新”。

校园助手统一提供依赖检查、扫描、查询/取消、读取、候选和本地交付；用户看原文并确认后才导出 .ics/Markdown。它不提交课程内容，也不写入手机日历或 Todoist。新版启用后旧两个 Student Hub 工具退出聊天工具列表，已有候选和忽略决定保留。

资料支持文字层 PDF、UTF-8 文本/Markdown；扫描图片不能保证识别。普通聊天不能凭磁盘路径遍历任意仓库，心流文件工具只操作她的书桌。语音/OCR/实时礼物生成不是首聊前提。

## 数据、备份与模式

安装版默认数据在 Electron 用户数据目录（APPDATA 下应用目录），源码运行默认 checkout/.local-data；LCA_DATA_DIR 可指定独立目录。升级和卸载不应靠删除数据完成。

羽毛笔或设置页导出 .lca-save；恢复前应用自动备份。存档包含私人邮件/资料源库，当前未加密，只能私下保管，不能当角色包公开。

开发模式使用独立 profile 与合成模型；展位模式禁用调试与受限执行，但仍可能使用已配置的真实模型，不能当作断网/零费用保证。评委扫描使用独立普通演示档，同学体验使用展位档。

## 源码复现与验收范围

本机 Node 24.14.0、pnpm 11.24.0。依次运行 pnpm install --frozen-lockfile、pnpm setup:electron、pnpm rebuild:native、pnpm probe:sqlite；开发用 pnpm dev，构建用 pnpm build，安装包用 pnpm package:win。不要运行 playwright install；每个 checkout 单独安装依赖。

pnpm test:package 检查真实安装；已有用户安装时不得覆盖测试。本轮用 pnpm test:package --unpacked-only 检查最终包内 EXE 与独立数据目录，具体结果以回执为准。第二台 Windows 的实际升级、真实供应商回复、学校认证及投影设备体验仍需真人验收。
