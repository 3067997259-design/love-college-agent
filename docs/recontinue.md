# 从这里重新继续

状态：已在 `codex/same-day-recontinue` 实现并完成本机合成验证，基线 `bb259b0`。尚未打包安装或发布。

今天右页的用户消息下可选择“从这里重新继续”。预览影响范围并确认后，目标消息及后续内容退出当前对话，目标原文回到输入框，等待修改和发送。输入框已有草稿或引用时先处理它们。原文仍在原来的日页：今天可通过“查看今天撤下的内容”查看，换日后标记为历史版本。这些内容不参与模型召回，不提供恢复分支或再次切点的入口。

## 时间与切点

- 沿用上海时间 04:00 日界线。11 月 4 日当前页不能回退到 11 月 3 日；已过 04:00 但尚未翻页时也拒绝旧页操作。
- 只接受当前有效版本中的普通用户消息。审批回答、模型问题的回答和自动事件不作为切点。
- 切点在目标消息之前，撤下目标本身及整个后缀。第一条消息可切成当天空白上下文，仍使用当前人设和合法历史参考。
- 必须能在当前项目的 DSH 原始日志中找到独立回合。运行中插话、合并输入、重复且无法识别的旧文本拒绝，不近似移动切点。第一版不支持跨项目切点。
- 预览后新消息或工作变化要求重新预览。确认前后再次核验日、版本和目标；同一操作重复提交不重复切换。

## DSH、日志与恢复

LCA 桥使用固定 DSH `0.2.1-rc.2` 的 `buildForkSeed` / `agents.create`，以前一个完整 `turn/end` 为前缀，首条消息使用空前缀。当前人设和权限由正常开根流程绑定。新根完成原生持久化、旧根及其成员确认停止后，LCA 才追加 `conversation/recontinued`。模型步骤、工具、取消和重试仍归 DSH。

该日志事件是生效依据，包含父版本、目标、撤下区间和新旧原生根映射。原始日志不改写。`dsh-sessions.json` 只是缓存：提交前崩溃保留原对话，提交后缓存失效不能退回旧根。已提交根缺失时停止使用，不静默装作恢复成功。其他项目缓存按会话版本失效，再进入时只补充有效对话。

私人存档保留版本事件和原始日页。恢复沿用既有策略退役本机 DSH 索引，从有效投影建立新运行会话，避免接回存档之后增长的日志。凭据和旧审批不随之恢复。

## 记忆与上下文

`recontinue/policy.ts` 统一判断撤下区间、原始消息 ID 和受影响回合。它与成功模型输入、隐私资格取交集，不从原始工具结果、附件或证据库补造经历。

| 链路 | 生效方式 |
| --- | --- |
| 当天上下文、跨项目补充 | 排除撤下消息；执行结果、计时、账本和世界状态仍作为事实重放。 |
| 自动抽取、迟到的 Worker 输入 | 按来源 ID、回合和输入帧排除；新回合再次观察旧输入不能使之复活。 |
| 事实记忆、目录、向量召回 | 在候选排序、访问统计和晋升之前排除。曾经批准该事实也不豁免。 |
| 提案与手工管理 | 失效来源的待审提案不能再批准。独立手工记忆操作和已完成遗忘保留。 |
| 日、周、月摘要 | 检查完整输入覆盖，不只检查模型选出的引用。父摘要失效沿依赖传播；重建使用有效前缀，空输入不回退到旧摘要。现有周/月均从日摘要归并。 |
| 旧页引用、经历展开、光学召回 | 用户可查看历史，模型读取重新检查来源；`includeSuperseded` 不放回撤下版本。 |
| 日记 | 原加密文件保留；阅读时提示来源已撤下或失效，不静默重写。 |
| 远端镜像 | 本地资格立即失效，持久化 outbox 清除远端副本；远端不可用不使旧事实回到本地召回。 |

后台抽取、日记等先取消并等待结算。运行中的持久工作先停止；依赖撤下决定的工作不再向模型提供目标、决定或检查点，也不能直接恢复旧目标。实际文件、执行证据、已花额度和未知外部结果保留，取消不代表撤销或退款。

## 边界与证据

| 场景 | 结果 |
| --- | --- |
| 普通切点 / 当天第一条 | 准确保留前缀 / 空前缀；目标进入草稿，无自动发送。 |
| 原生压缩后 / 正在生成时取消 | 后续实际模型请求不含撤下内容或污染摘要。 |
| 重启 / 重复提交 | 恢复有效版本和未发送草稿，不重复生效。 |
| 预览后新消息 / 跨 04:00 / 其他日页 | 拒绝，原始记录不变。 |
| 已批准事实 / 待审提案 | 不抢召回名额、不增加访问数、不晋升，失效提案不能批准。 |
| 摘要引用漏列污染片段 | 完整覆盖仍使其失效，重建和周/月归并无污染内容。 |
| 已改文件的工作 | 文件、证据保留，旧目标退出上下文，直接恢复拒绝。 |
| 存档后又继续聊天，再恢复 | 新请求既不含撤下内容，也不含存档之后新增内容。 |
