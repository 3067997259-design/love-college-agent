## MCP 的数据边界

实现位于 `src/main/mcp/`。标准配置的扩展字段为 `allowTools`、`privacy`、`disabled`。默认工具白名单为空、`privacy=always`；隐私依赖缺失时，在远端工具执行前拒绝调用。远端返回仍按不可信数据处理，校验文本内容、限制长度、剔除工具 schema 的说明性字段和引用；原文只在主进程隔离处理，日志与主模型只接窄出口。显式 `privacy=none` 的公开服务返回经有界和打码的文本。

用户先在页面确认 fingerprint，再由原生对话框核对实际程序、参数、工作目录或服务地址。环境变量只展示名称。配置值不进入页面快照或调试工具；子进程 stderr 不继承到日志。修改配置要重新确认，不做自动重连或模糊失败重试。外部动作取消后可能已在远端执行，固定错误保留 unknown，不能显示为“已撤销”。

实际 Student Hub 探针仅作为外部标准 MCP 进程启动，生成全新配置和空 SQLite，只调用 `integrity_check`。没有学校采集、没有读取参考项目运行数据、没有复制或修改其代码。HTTP 测试使用本工程合成服务。未验收官方 Rodin OAuth；SDK 反序列化之后才进行结果大小限制，尚无通用流量配额实现。

## 私人存档的真实范围

实现位于 `src/main/backup/`。格式 v1 的 `.lca-save` 含当前用户＋角色的已保存日志、四个 SQLite 库的一致快照、已登记且哈希匹配的本地交付文件、当前页与番茄剩余量。明确排除 settings、连接配置、插件授权、调试令牌和凭据目录；另检查本机已载入的应用密钥／授权码，发现被嵌进数据的已知凭据则拒绝导出。

**私人存档包含用户邮件和资料的私有源库，当前不是加密容器，不应作为角色包公开分享。** 凭据检查不是对所有任意文档秘密的识别保证。角色包仍是另一种格式，尚未实现。

导入先检查 ZIP 中央目录、压缩／展开上限、路径、重复项、链接、CRC、manifest、所有文件哈希、SQLite schema／完整性、日志与来源作用域。压缩包最多 128 MiB，展开最多 512 MiB，最多 2000 个数据文件，单文件最多 128 MiB。fake／real 和用户／角色不匹配均拒绝。

选中文件和校验通过都不代表恢复成功。用户确认当前 restoreId 后，先创建 `backups/pre-restore-<id>.lca-save`，关闭业务和 SQLite，再重启替换。事务文件记录 applying／committed／rolled-back；中断的替换在下次启动回滚，不打开已知混合状态。保留回滚材料，不自动删除。其他用户／角色的现有数据不随本次恢复倒退。

恢复继续存档中的会话，按恢复时刻加保存的剩余时长重建截止点；导出到恢复之间不算番茄流逝、不补算停机工作。目前没有自主外出或日记，因此也没有虚构其恢复验收。

## 模型、隐私与诊断

`src/main/model/task-ports.ts` 将记忆抽取／概括限制在 `background`，将邮件、文档、插件窄出口限制在 `privacy`；这些任务没有工具，输出按各领域 schema 验证。30 秒统一时钟截止点与父取消信号传递到客户端；逐次重试计入预算，当前代码上限为总量 500000、自主 100000 的每日预留 token。JSON 任务提示位于 `task-prompts.json`，不包含角色对白、日记或做梦提示。

正常模式设置页通过原生文件选择导入配置，保存到数据根 `connections/providers.json`，下次启动优先加载；快照只有槽位名与保存状态。开发 profile 拒绝真实配置导入，不读取真实配置内容，使用 fake 依赖。学校 privacy 的真实 URL 仍缺失；本轮没有真实供应商请求，不声明质量或外网连通通过。

安全诊断只给开发模式。上下文明确区分最近一次成功输入与尚未发送的投影；回合统计只报告已采集值。首字延迟、缓存 token、成本未采集，返回 null。调试不查询私有证据库或成品；原文核对继续由单独的用户 `readEvidence` 通道提供。
