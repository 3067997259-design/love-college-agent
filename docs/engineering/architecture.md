# 技术说明初稿：第一圈实现

2026-10-16。这是已经落地的架构说明；产品目标与尚未实现的方案以 README、技术方案为准。真实运行、合成验收和设计意图分别记录。

## 进程与数据所有者

Electron 主进程装配统一 Clock、调度器、日志／投影、harness、插件、私有源库、模型端口、MCP、资料解析、存档与窗口管理。React 渲染层只消费 `src/shared/` 的安全状态与白名单命令。preload 在 contextIsolation＋sandbox 下提供窄 bridge，不暴露 Node、任意文件路径或供应商配置。

书本与透明迷你窗使用同一个主进程会话、harness 和番茄计时器；它们不是两个代理。窗口命令校验实际 sender 主 frame；hover／move 只有迷你窗可发。窗口位置是本机偏好，不作为角色记忆或私人存档状态。原生可见性过渡使用 Clock 模块中的系统时钟，业务推进使用可注入时钟；冻结测试时钟不能冻结“回书本”。

## 日志、投影与执行

业务事实追加到 `journals/<owner hash>/<day>.jsonl`，SQLite 是可重建的运行投影。用户和角色进入作用域，按上海时间 04:00 划分日会话。UI revision／epoch 与日志 seq 分开；命令 accepted 只表示接收，实际结果由后续状态给出。

harness 有界执行聊天与工具回合，负责 inbox、取消、重复调用／步数／预算限制和终态。工具动作记录和校验后的文件构成交付证据，模型措辞不构成外部执行证明。调度器统一推进番茄阶段、后台与翻页，不让渲染层重算事实。业务代码的原生取时和定时器由 ESLint 拦截。

停止会取消客户端和受控任务；对于已发出的外部调用，只能报告已取消等待或结果未知，不能承诺远端撤回。存档操作会阻止新增写操作，等待或拒绝仍在运行的业务，再执行一致快照。

## 私有数据与模型投影

邮件证据与源附件／文件保存在主进程私有 SQLite，不进入通用 JSONL、UI 快照、调试上下文或主模型。用户查邮件走 `readEvidence`，看整理成品走有界的文件预览；这些不是模型工具。

邮件正文固定隔离；附件与拖入文件由 `/privacy` 开关控制。privacy 专用无工具模型只输出 schema 允许的短字段，或生成直接交用户的文档；错误不回退主模型。日期、逐字证据、长度、枚举与来源由代码校验。外部 MCP 和代码插件声明可能处理隐私时复用窄出口，模型输出继续当不可信数据。

记忆只从成功模型输入记录的允许片段抽取，保存来源、作用域、纠正链与未审核标记；不从私有源库或原始工具结果反向补材料。日摘要、检索记忆和记忆工具引用不递归变成新经历。压缩只替换完整旧回合的模型投影，用户旧页保留。后台端口只用 background；并未实现周／月归并和日记。

## 插件、MCP 与凭据

内置功能经插件注册；本地代码插件使用 fingerprint 与权限授权。外部 MCP 是通用客户端，经用户原生配置导入，只开放 allowTools，支持 stdio／Streamable HTTP，默认隔离、无自动重连、无模糊重试。启动目标在原生窗口核对，命令／参数／地址／env／headers 不进渲染和调试投影。stdio stderr 丢弃，错误固定分类。

providers JSON 只在主进程读取。正常模式的导入配置保存在数据根 connections，重启应用；开发 profile 使用 fake，拒绝导入真实模型配置。背景任务、隐私任务、聊天端口分开，私有任务不保存输入输出正文到日志。实际模型的外网连通与质量要独立验证，本轮仅使用 loopback 合成服务。

## 存档与连续性

`.lca-save` v1 是当前所有者的私人 ZIP，不是角色包，也不是加密容器。四个 SQLite 的 backup、作用域过滤、日志和已登记文件共同组成清单；每项有 SHA-256。凭据／连接／调试配置排除，已载入应用密钥嵌入数据时拒绝导出。

导入先校验并暂存，用户明确确认后自动创建恢复前存档；关闭连接、重启、可回滚替换。保留其他所有者数据。恢复原会话与剩余计时，不把恢复间隔计作在线工作。羽毛笔是由真实本地交付与当时可见事实绑定的首件礼物；实时 Rodin、外出与加密日记尚未完成。

## 独立实现与依赖

应用业务代码在用户宣布开赛后独立编写。Student Hub 作为赛前已存在的作者项目，只以外部 MCP 标准进程连接空测试库验证；不嵌入代码或数据。AIRI、mcpfabric 用于机制研究，其运行结果不计作本产品验收。具体参考固定点见 [参考工程调研](../reference-research.md)。

运行依赖包括 Electron、React、electron-vite／Vite、TypeScript、better-sqlite3、MCP SDK、imapflow、mailparser、JSZip、pdf-parse 等。依赖版本由 package.json 与 pnpm-lock.yaml 固定；采用开源库不代表其所有功能已经接入。PDF 使用独立 Electron Node 子进程解析，不装浏览器。美术来源与采用范围另见美术规格和精修交接。

验收证据与未完成项见 [第一圈收尾记录](first-circle-closeout.md)，实际操作见 [部署说明](../deployment.md)。真实 IMAP 仍被网络重置阻塞，不能将 fake 场景展示为真实采集。
