# 第三圈：有产物的自主生活

2026-10-17。接口 `a19c596` 先合 main；持久服务 `b2b9e8d` 随后合 main。本轮使用她书桌里的固定合成材料与 fake 模型，没有调用真实模型、邮箱或 Rodin。

## 已落地的范围

- `src/main/life/work/`：登记合成材料、阅读／写作任务、三步生产器、私有日志检查点、每日尝试预算及恢复。
- 阅读逐节留下笔记；写作依次留下提纲、初稿、修订稿。文件在 `书桌/自主作品/<workId>/1.md` 至 `3.md`，每个版本独立保存。
- 每天每种任务最多一个。生产器只读已登记材料和自己的上一个产物，绝不递归读取书桌、邮件库、附件或整理成品。`developer.life.seed` 在开发 profile 写固定合成材料；已有同名异内容文件拒绝覆盖。
- 模型只能返回经校验的 Markdown。任务 id、日期、路径、步数、状态和完成条件由代码决定。空输出、重复输出、伪造完成字段、文件冲突和写入失败不能增加进度。
- 每一步先追加草稿意图，再写书桌文件并回读一致，最后追加提交记录和进度。只有三个实际文件提交后才能 completed。启动时只有磁盘上已有且匹配的未结算写入才能补记；不存在的意图不算产物。
- 已提交文件可由私人日志重建；用户编辑过的文件保留并报 conflict。查阅时重新核对哈希，以无 preload／无 bridge／无 Node／无网络的原生预览窗给用户看，不把正文送回聊天。

## 调度和恢复

当日 read/write 安排接生产器，有材料且有模型时保持 planned，产物完成后才 settled。未接通时仍 skipped。只排当前自然日的任务，不从离线日期循环中生产作品。

用户正在专注，或明确工作／安静工作时，她才能做自己的事。前台 harness、心流、外出、休息、熄灯、备份冻结及禁用 `life-work` 插件都阻止推进；模型返回时再次检查条件。前台会取消进行中的调用；忽略 AbortSignal 的迟到返回也不能落盘。每次只有一步执行，30 秒上限，每日最多 8 次尝试，包括失败／取消；不按离线时长补调用。

重启保留已提交步数；未完成且非用户暂停的任务转 interrupted，需要显式续做。用户暂停保持 user，不自行恢复。离线三天不增加步数，不写停机期间的作品。私人存档带日志里的材料和产物，恢复时重建文件，空档不结算工作；普通 profile 与角色作用域沿用存档校验。

正式模式尚未接通自主作品模型（source=none），不会自动向真实槽位发送书桌内容。本轮验收的是 fake 模型的完整生产与恢复链路，不能报告为真实模型写作质量或长期自主运行。

## 给 Claude 的接线

接口在 `src/shared/state.ts` 的 `LifeWorkView/LifeWorkItem`、`LifeView.work`，命令在 `src/shared/commands.ts`。接口 SHA **`a19c596`**。

- `life.work.start {kind:'read'|'write'}`：当天幂等排队，只在允许时执行；不接受任意路径或正文。
- `life.work.pause {workId}`／`life.work.resume {workId}`：暂停或保留步数续做。
- `life.work.open {workId}`：用户查阅最新已校验产物。
- `developer.life.seed`：仅开发 profile 的固定合成材料。
- 快照只有元数据：source、status、completedSteps/totalSteps、时间、reason、output 的相对路径／哈希／字节数。不要凭经过时间自己画成完成，也不要自行读取正文。

朴素入口在“工具与设置 → 她的生活 → 书桌作品”。左页姿态／作品呈现交 Claude。本轮没有改她最终的声音；fake prose 在 `fixtures.json`，不能当最终角色文案。普通上下文只收到带 autonomous 来源的作品事实元数据，不含材料或作品正文；记忆仍只取成功输入中她当时看到的内容。房间运行记录只含动作类型，不写原文。
