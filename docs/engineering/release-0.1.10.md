## 行为

上传文件可在整理请求完成前进入获授权的当前回合；后续回合按文档 ID 显式读取。忽略的校园候选退出当前来源、自动事件和旧工具结果，历史页面与忽略决定保留。旧外部工具结果不长期充当当前证据；只保留经格式校验的扫描 jobId 供跨回合查询/取消。生成期间来源或权限改变会丢弃旧回复与其工具调用。

校园助手提供一个入口完成依赖检查、扫描、进度/取消、读取、提取候选和书页本地交付。新版启用后聊天不重复提供旧 Student Hub MCP 和候选导入工具，已有候选和忽略状态保留。原文按用户选择的隐私模式处理；独立隐私失败不回退主模型。外部原文及其直接复述不自动抽成个人记忆，赠笔等所需的当时可见经历仍保留。

详细拼接/退出规则及旧历史语义删除边界见 [上下文审计](context-lifecycle-20261018.md)。已发给模型供应商的内容无法撤回。

资料整理总时限从 30 秒调整为 90 秒，保留无输出时限、取消与资源预算。本机试装的失败记录显示资料已明确允许主模型读取，但在 30 秒被代码取消；不是操作系统文件权限拒绝。跟随主模型的失败现按连接、额度、输出等真实分类展示，不再统一写成 privacy-unavailable。普通聊天仍不能凭一句磁盘路径遍历仓库；心流文件工具限她的书桌。

修复部分供应商跨回合复用 tool callId 时，历史上下文清理误删当前工具结果的问题；当前结果依据所属回合和最新配对位置保留，旧结果仍退出。
