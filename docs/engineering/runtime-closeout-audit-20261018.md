# 10-18 再次打包前：真实使用链路审计

起点：用户在第二台 Windows 安装后报告“连接测试成功但聊天未连接”，并指出日记与隐私滤芯缺少“跟随主模型”。随后明确：隐私跟随主模型意味着关闭隔离，主模型直接处理并看到原文；要求再次打包前审计日记、礼物等难以短时间人工验证的功能。

本轮在 `D:\lca-gpt` 的 `codex/model-routing-fix` 工作，使用独立临时数据。审计以用户操作到实际所有者的链路为单位，同时核对配置、调度、持久化、渲染入口、失败、取消、重启和恢复。没有发起付费 Rodin 生成，没有读取真实邮件、访问参考项目私人库或打印供应商配置。下列 Electron 证据使用合成服务；真实服务的效果与第二台机器的人工体验单列。

## 已确认并修正的问题

| P1 | Rodin 连接必须填一个实际不会使用的模型名 | Rodin API 的规格由服务端实现选定，GUI 却套用聊天必填表单。移除无效模型输入，允许地址+密钥保存 | Provider GUI、配置单测 |

| P1 | 旧文案仍称“关闭后只暂存”“原文永不进入她的上下文” | 文件入口、设置、斜杠提示、模式说明按真实路线更新；开发假模型仍按隔离夹具暂存，不伪装成主模型整理 | Electron 原文对照、界面检查 |

共享原文仅在主进程读取和临时组装。邮件/文件原文补充不会写入通用 `model/seen` 或自动记忆抽取；实际给主模型的正文保留邮箱、电话等业务字段，仍遮盖凭据。模型在正常回复中复述已获准内容会成为聊天记录，不能声称“已经发送的原文可以撤回”。普通对话使用最近来源的有界节选，单项上限 24000 字符、总计 48000 字符，显式标记截断；不声称读完所有历史全文。

迁移原则：新安装默认跟随主模型；已有独立槽位（包括旧配置中的空占位槽位）保持独立，缺配置即关闭，避免升级时静默撤去原有隐私隔离。开发模式不读真实供应商文件。

## 日记和礼物：实际能证明什么

**日记**：只取成功模型输入中允许的经历片段；一天结束且完成翻页后写前一天，刚安装当天没有日记是预期行为。日记正文不回流记忆，不保存内部推理。生成时固定钥匙及下一日页 04:00 解锁时刻。已有 Python 独立解密测试，本轮再次检查加密 ZIP、用户专用读取、普通快照/调试无正文钥匙、原生存档恢复后密文和钥匙不变。中断和每日尝试上限已补测试。真实模型的文笔、长期内容一致性及 Windows 资源管理器手动输密码体验，本轮没有冒充验收。

**礼物**：必须关联实际可见经历；答应仅保存同意，专注时才提交，ready 与休息时 given 分开。失败/取消计入当日一次提交预算；私有 Rodin handle 不进快照和私人存档，恢复不重发 begin。生成前后都有模型文件校验；本轮实际 Electron 的 model-viewer 加载及恢复后重新加载通过。第二台恢复“制作中”的礼物若没有私有 handle，会明确失败，不能声称能跨机器继续云端生成。真实付费生成的质量、耗时和供应商瞬时可用性不由合成测试证明。

## 第二台机器的最短人工复核

1. 关闭旧程序、安装新包后从快捷方式打开；保留原书本，不删数据。核对发布版本，确认旧聊天仍在。
2. 在 GUI 保存并测试日常对话模型，不重启直接发一句，再要求调用本地时钟。分别看到回复和实际工具结果。
3. 把记忆/日记设为跟随主模型，确认不再“未配置”。当天没有日记是正常状态；不要为赶演示修改电脑时钟或把合成日记当真实生成。
4. 把隐私滤芯设为跟随，拖入随附公开样例，查看实际 Markdown，再问样例里的日期或地点。只用公开内容，明确主模型能读原文。
5. 如果已配独立 privacy，再开启文件滤芯，验证隔离整理；未配就跳过这条，不能用跟随模式的成功证明隔离服务可用。
6. 礼物优先展示已有、能打开的 GLB 和对应经历。没有真实成品就不把现场付费生成列作必过项；“好”只表示接受，制作仍等专注，交付等休息。
7. 关闭重开后复核聊天、交付和模型使用方式保留。由操作者记录成功/失败和错误分类；不提供密钥或私人原文截图。
