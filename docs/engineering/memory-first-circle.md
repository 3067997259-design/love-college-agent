# 第一圈：记忆、按天分会话与上下文压缩

2026-10-16，约 21:22（GMT+8）。本批按用户要求使用合成经历和独立 fake 后台模型，未读取真实邮箱、供应商配置或调用真实模型。IMAP 继续记为认证前 ECONNRESET 阻塞。本批完成文字记忆、运行中的日会话翻页、日摘要和旧回合压缩；不代表整个第一圈或长期自主运行已验收。

## 操作

在 GPT worktree `D:\lca-gpt` 运行 `pnpm dev`，从“工具与设置”打开开发模式并重启。当前开发 profile 与正常用户数据完全分开，chat 和后台记忆都标记 fake。

1. 连续发送以下合成经历，可在设置页点击“抽取可见经历”：`我把纸桥放在书桌上，给它取名叫周五桥。`、`我喜欢的饮料是咖啡。`、`我喜欢的饮料现在改为红茶，不再喝咖啡。`。fake 只识别仓库里的少数固定合成句，不是通用抽取模型。旧的咖啡事实保留并显示被新事实取代；后续“饮料”检索不返回旧事实。
2. 后台会在最近一次发送后空闲两分钟时补抽，每 30 秒检查一次。新回合中止后台模型并让路；熄灯暂停。也可手动抽取，不必等两分钟。
3. 至少有三个结束的回合后，在设置页“压缩旧回合”或发送 `/compact`。仅选旧的完整回合，最近两个结束回合及当前回合保留；过短、没有可用旧内容或压缩不能缩小时明确失败。`/compact` 由本地控制器处理，不作为用户话语交主模型，不增加聊天回复。
4. 设置页“历史会话”是用户专用入口，显示原始聊天。压缩没有删除聊天；翻页后仍可看昨天。这个桥没有供模型读取的工具，也不返回工具原始结果、邮件／资料原文或整理成品。
5. “记忆模型场景”切到后台失败／无依据输出后手动操作，应看到固定错误分类，源片段处理进度不推进、投影不被非法摘要替换；切回可用后显式重试。
6. `pnpm test:memory` 自动演示同一进程跨过上海时间 04:00：执行中的回合不翻页，熄灯不翻页，满足空闲条件后翻页；新一天的输入包含旧日摘要和相关记忆，旧页仍可查，重启后保留。它使用显式可调时钟，不是等到真实凌晨的跨天验收。

正常模式后台记忆模型目前为 unconfigured，没有装配真实 background 适配器，也不会改用 chat。原聊天、日会话和用户查阅仍存在，手动抽取／压缩明确拒绝；满足安全条件可以翻新页，未生成的摘要留待依赖可用后补做。开发模型的固定回答不代表它已根据记忆作了自然语言推理；验收直接核对实际输入和工具结果。

## 数据与执行边界

| 层 | 本批实现 |
| --- | --- |
| 可见依据 | 每次成功的 chat 调用后追加 `model/seen`，记录该次实际输入和允许抽取的索引；失败／取消调用不生成可用依据。只从这些记录分片，不遍历私有来源库或旧 `tool/raw` |
| 原文隔离 | 邮件和资料沿用已校验元数据出口；用户看原文／成品的独立窗口不回传内容。记忆没有 evidence／document vault 或 artifact 文件读取依赖 |
| 不重复学习引用 | 政策、压缩摘要、旧日摘要、自动召回块和 search_memory 工具的返回不标为新经历；同一天反复出现在上下文里的相同角色／文本片段按哈希去重 |
| 抽取验证 | 无工具的 `MemoryModel` 输出未知数据，严格 schema、来源 id、逐字引文、短 topic、控制字符与凭据检查后写入。每条最多 240 字符；所有条目标为 unreviewed，不能当作高优先级指令 |
| 事实纠正 | 用户可见原话明确出现“改为／改成／更正／不再”且同 topic，才建立 supersedes；旧条目不删，新事实来源、时间和取代关系保留 |
| 日志与投影 | batch、access、summary、operation 都先追加并 fsync 到当前 JSONL；`memory.sqlite` 只是可重建缓存，启动总从相同用户＋角色的日志重放。陈旧缓存不能覆盖事实 |
| 检索 | JavaScript 中文双字切分和英文词；`1.2 × relevance + 0.2 × exp(-hours × ln2 / halfLife) + 0.15 × log1p(accessCount)`；短期半衰期 24 小时、长期 4320 小时。排除无关和被取代条目，默认最多 5 条 |
| 晋升 | 至少三次不同回合／请求的实际召回，且依据来自两个日会话，才晋升长期；同一回合反复查同条不累加 |
| 上下文 | 政策 → 旧日摘要 → 今天的投影 → 相关记忆 → 最新用户消息；最近三条用户内容触发自动检索，另有只读 search_memory 工具。调试 get_context 显示最近一次成功调用的实际输入 |
| 日会话 | 上海时间 04:00 起算一天。只在无执行中／排队用户任务、最近发送空闲两分钟、未熄灯且番茄不在运行时翻页，重建 epoch 和作用域；正在做的回合不会被迁移 |
| 跨页持久状态 | 携带模式、灯光、番茄计划／暂停点和未消费的邮件／资料／番茄元数据事件；不携带昨天的原始聊天或工具原文。旧页字节不再改写 |
| 摘要依赖失败 | 标记失败且不写假摘要，安全翻页仍可进行；恢复后由新一天的后台补旧摘要。没有聊天模型回退，没有伪造昨日工作 |
| 用户查阅 | readSession 按当前用户＋角色查 opaque sessionId，最多 200 条／200000 字符，包含当日公开回复及等待休息再展示的回复；工具原文和执行日志不返回。未实现账号／角色切换 UI，作用域隔离在存储接口和探针验证 |

压缩阈值暂用序列化上下文 24000 字符，准备请求时自动尝试，硬上限 96000 字符；不是 token 估算或供应商窗口保证。只替换日志投影的旧 seq 区间，摘要放在保留消息之前，完整日志与用户聊天不改。后台每天最多 32 次调用、240000 个输入 JSON 字符，按实际时钟的日键统计跨页记录；单调用 30 秒统一时钟超时，失败和取消也消耗已预留的预算。默认每次抽取 5 个片段，单片段 2000 字符，摘要输入有界。具体上限仍需真实模型与体验验证。

fake 抽取／摘要采用可核对的逐字摘录，不验证真实语言模型的概括、纠正理解或抗注入质量。上下文引用为未审核数据，schema 验证不是语义可信证明。来源文本经既有固定格式打码后才交后台模型。没有实现周／月摘要归并、物理遗忘、永久“关于你”编辑、日记或光学记忆；时间衰减仅影响检索排序，原日志仍保留。
