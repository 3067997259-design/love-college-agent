# 番茄钟底座验收

**后续更新：** 第一圈已接通私人存档的计时重锚和运行中的日会话。2026-10-16 又补齐计划 items、原生迷你窗的展开销毁／不透明回退，以及 `test:pomodoro` 双窗口验收，见 [本轮增补](pomodoro-mini-update.md)。下文保留第零圈历史结果。

2026-10-16。内置 `pomodoro` 插件经同一加载器注册，声明 `plan_pomodoros`、`start_focus`、`pause`、`stop`、`get_timer`。只有用户专用 IPC 有确认计划命令，模型工具不能替用户确认；界面“工具与设置”提供相同控制。

默认 25 分钟专注、5 分钟短休息、每 4 段 15 分钟长休息；演示模式明确标注 1 分钟／20 秒，仍走同一代码。计划上限 24 段，时长由代码校验，标记 standard/demo 的参数必须匹配相应节奏。

每次状态变更追加 `pomodoro/state`，包含计划、阶段、剩余时长与 `endsAtMs`；SQLite 只是其投影。唯一 scheduler 管理阶段到点和有界 outbox 重试，UI tick 也用它。阶段事实带固定事件 id，先落日志再投 inbox；重放和多次核对不会重复添加，写事实后尚未投递就崩溃的空档能补齐。没有模型配置时事件保留，计时照常，不触发失败模型回合。

专注开始自动切 quiet，结束进入短／长休息并切 rest；休息结束回到等待用户启动的 idle，不自动跑下一段。提前翻到休息记 interrupted，不算一个已完成专注。熄灯自动暂停并保留剩余时长；开灯只恢复因熄灯而暂停的计时，手动暂停须明确恢复。启动和 powerMonitor resume 核对保存的截止点；过期专注在回来时结算一次，休息从实际核对时刻开始。

阶段事件进入现有 harness；专注期间自主事件攒着，用户消息仍可进入。当专注开始时已有自主回合在跑，其文字进入上下文但暂不公开，休息时由日志投影释放；真实任务／候选／交付能力仍在第一圈接入。停止不重跑已执行工具。

验证：6 个 Vitest 场景覆盖确认边界、长短休息、不自动下一段、熄灯／手动暂停差异、重启过期只结算一次、事实与 inbox 间崩溃、提前中断和安静期间发言。`pnpm test:pomodoro` 在真实 Electron 中检查 UI 操作、实际 SQLite 截止点、持久重启、阶段事件不重复、熄灯及中断；同轮 `test:harness` 通过。开发实例的时钟锚点会保存在独立 profile，冻结状态可跨测试实例重开。

自动化使用显式开发假模型和冻结／拨时，不能当作真实长期陪伴证据。完整私人存档恢复尚未实现；第一圈接入时必须为恢复重新锚定剩余时间，不补算导出到恢复的空档。

补充验收：`pnpm test:pomodoro:realtime` 在正常模式、真实系统时钟下跑一段演示专注和休息，2026-10-16 实测专注 60,000 ms、休息 20,047 ms，下一段保持等待；此实例 chat 未配置，没有运行真实或假模型。`pnpm probe:pomodoro` 使用合成时钟、真实 Electron SQLite 检查跨凌晨 4 点重开新会话时的截止点交接，以及过期阶段只结算一次。
