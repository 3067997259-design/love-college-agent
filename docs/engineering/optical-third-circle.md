## 固定边界

- 默认文字分层不变；光学可选、默认关闭。失败或未配置时保留文字记忆，不能假装已有 OCR 结果。
- 输入只取成功 model/seen 中实际可见的普通对话片段；不扫描文件、邮件、附件、整理成品或心流原始工作。必须在 user／character／session 作用域内取闭合旧页。
- 采用独立印刷页，实际生成 PNG，保存来源片段指纹。图片进入私人存档；旧图保持原样，不随新角色素材或时钟重画。
- Large/Base/Small/Tiny 只是解码参数：1280/1024/640/512，同图、crop=false，不映射成记忆年龄，也不宣称已校准人类遗忘体验。
- 解码是未审核印象，错误姓名／编号／日期不得凭 OCR 进入事实或记忆。出口只保留能回查至当时可见来源、作用域未被切断的逐字片段，明确拒绝／未知；细节引用仍走原文。守卫不是中文语义准确率证明。
- endpoint／凭据只在主进程配置，快照只带状态和计数，OCR 全文／页文不进普通快照和调试接口。私人存档不带服务配置或凭据。
- 本地合成服务先验收渲染、四档请求、取消／超时、错误守卫、重启和私人恢复；之后再验证真实解码服务。历史赛前实验不冒充本轮实际服务结果。

## 共享接口

`AppSnapshot.opticalMemory` 为可选元数据视图；`optical.configure` 走主进程原生配置选择；`optical.enable` 显式开关；`optical.encode(sessionId)` 只编码已结束的可见旧会话；`optical.decode(frameId,tier)` 显式试档。不接受 renderer 上传任意原图、正文或 URL。

## 实现与限制

`src/main/optical/` 包括源证明、分页、真实 Electron 印刷页、HTTP 端口、配置、结果守卫和可重建元数据。每页 24 行，CJK／ASCII／emoji 保守分行，UTF-16 来源区间和指纹保持可回查；单会话最多 64 张，超出明确拒绝，不静默截断。每次最多封四张，可继续补齐，编号和总页数可见。最多 256 张、每天 16 次封页尝试／8 次解码尝试；失败也消耗尝试。一次操作最多 30 秒，渲染另有统一真实时钟 5 秒保护。原生人工选择配置不使用网络超时。

默认关闭，第一次配置后仍要显式启用。失效／未配置服务不会代调主模型；仍可封页，解码明确 not-configured，文字记忆不受影响。前台用户任务、熄灯、备份冻结、禁用插件、关闭应用会取消进行中操作；重启不重放。已提交图片和印象随私人存档保留，但 `connections/optical.json` 不导出，换 profile 恢复不把服务端凭据带过去。配置秘钥加入主进程的存档排除检查。

模型工具 `recall_optical` 不给 OCR 发请求：空参数列最多 20 张已封页的 id／日期；可按 sessionId 筛，再用 frameId/tier 读已有印象。每次重验来源，只返回未经审核的保留片段和历史标记。原始 OCR 输出不落日志；被拒绝的文本不交模型。工具结果以及使用该工具回合的模型回复不进入后续 eligible 记忆材料，阻断经复述重新抽取；用户后来明确说出的新内容仍按自己的来源处理。

用户专用 `readOpticalMemory(frameId)` 仅书本窗口可用，给实际 PNG 与守卫后的印象；mini／诊断窗拒绝。朴素入口是“工具与设置 → 光学记忆（可选实验）”。正文不出现在普通快照／调试 MCP。

## 解码服务适配协议

原生选择一个本机 JSON（不能是链接或超大文件）：`{"endpoint":"https://your-decoder.example/decode","apiKey":"<local-secret>"}`。HTTPS 可远端；HTTP 仅回环，开发 profile 只接回环，拒绝 URL 内嵌账号、查询或片段。主进程保存到当前 profile 的 connections。对话、日志和快照不显示这些值。

适配器 POST JSON：`image_base64`、`mime:"image/png"`、`base_size`、`image_size`、`crop_mode:false`、`prompt:"<image>\\nFree OCR."`；如有秘钥则用 Authorization Bearer。返回严格的 `{"text":"decoded text"}`。上限 256 KB 响应／64000 字，拒绝重定向、不自动重试。这是本应用的明确适配协议，**不宣称是官方 DeepSeek-OCR HTTP API**；真实部署需给官方推理路径包适配端。未携带原文、任意模型工具、文件路径或别的 URL。四档请求同一源 PNG，仅改变两个 size 参数。
