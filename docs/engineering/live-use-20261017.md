## 本轮发现的问题与修复

1. **`get_clock` 只返回 UTC**：界面 21:xx，工具结果 `iso` 是 UTC，真实模型于是回答“13:59（UTC）”。修复：工具结果增加 `timeZone: Asia/Shanghai` 与 `local`（上海本地日期时刻），并更新工具描述，要求用本地时间说话。
2. **记忆抽取的 background 调用失败**：模型请求本身成功（728 输入 / 113 输出 token），随后 `memory/operation extract` 记录 `connection-failed`；最可能是真实模型把 JSON 包在说明文字/代码围栏里，`JSON.parse` 直接失败。修复：模型 JSON 任务改用容错解析（纯 JSON、```json 围栏、前后带说明各取一次），schema 校验保持不变；新增 5 项单测。
3. **真实模型给 `get_timer` 多加 `reason` 参数**，被严格 schema 拒绝两次（界面上出现两条“这一步没做成”）。修复：工具描述明确“只传 {}，不要加 reason/说明字段”；仍保持严格参数校验，不放松安全边界。
4. 恢复确认按钮：向导里是“从这本书恢复”，设置页里才是“备份当前数据并恢复”；两条入口都存在，测试分别核对。Playwright 等待进程 close 事件不可靠时，以 `.restore-pending.json` + 重新启动后的快照为准确认。

以上修复后：类型/lint 通过，**74 文件 / 514 项单测全过**，构建通过。修复尚未重打安装包；下次打包后需在安装版再复测“本地时间回答 + 记忆抽取成功”。
