# 逐次确认的公共网页读取

接口 `079d2bf` 先合 main：heartFlow.webFetch 与 flow.fetch.approve。只在 execute 心流，模型请求读取一个确切的公共 HTTPS URL 后，用户先核对再逐次确认。无自定义凭据／头、无 Cookie、查询或片段、不跟重定向；DNS 固定公共 IPv4，拒绝本机／内网。正文是有界不可信工作数据，不进普通记忆；快照只有 URL／状态／次数／字节／截断标记。

## 网络边界

`desk_web_fetch` 仅 GET、HTTPS 443、普通域名，不允许 IP 字面量／用户信息／查询／片段／其他端口。用户确认前没有 DNS 或网络调用。确认后查 A 记录，任何私用／回环／链路／共享／文档／测试／多播／保留地址、或本机网卡地址都拒绝；最多 16 条。使用全新的 TLS Agent 固定其中一个已检查 IPv4，Host／SNI 仍是用户确认的原域名，正常验证证书；不走环境代理、不二次解析、不跟重定向。暂不接 IPv6-only 或代理路由。

特殊地址依据 [IANA IPv4 登记](https://www.iana.org/assignments/iana-ipv4-special-registry)，2026-10-17 核对；192.0.0/24 等特殊子网采取保守整段拒绝。公共编号不保证特定网络可达，仍以实际请求结果为准。

## 预算、正文和取消

每次心流最多 12 次请求，拒绝／取消也计数；等待审批 30 秒，发起后 DNS＋读取总限 10 秒。新插话、停止、熄灯、换目标、退出、禁用或 plan 会取消，忽略 AbortSignal 的迟到结果不写日志／上下文。重启不补发网络或继承批准，尝试数从自己的日志保留。项目说明／审查草稿的窄来源任务不允许借这个入口读外部网页；隔离预览也同样关闭。

只接 200 的 UTF-8/ASCII text/plain、text/html 或 application/json；拒绝压缩、二进制、其他编码及重定向响应。最多收 64 KiB，最多投影 12000 UTF-16 单元，截断明确标识，HTML 当不可信源码，不渲染／执行。主进程先遮盖已知凭据，再把 raw/visible 交工作工具链；正文不进快照、房间记录、普通对话或经历。退出摘要仅有 source 和尝试／成败／拒绝／取消次数，明确内容未审核，不带 URL 或正文。正常模式真实端口；开发固定合成网页明确标 fake。
