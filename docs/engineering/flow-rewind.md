# 心流步骤回退

接口先行，2026-10-17。实现和运行证据待补。

`flow.rewind.prepare(changeId)` 预览当前心流中该文件步骤及之后的全部已记录书桌改动，最多 500 条／300 文件；同一文件多次改写、删除和旧的单文件撤销一起计算。快照 `heartFlow.rewind` 只含边界、文件路径、数量、状态及已核实写回数，不含文件内容。

`flow.rewind.apply(rewindId)` 是本次确认。确认前核对日志范围及全部受影响文件的版本；冲突则在写入前拒绝。确认后逐文件追加快照和结算，再写影子收据，允许 `flow.rewind.cancel(rewindId)`、停止、目标更新、熄灯和退出中断后续写回。写入失败不能宣称整批完成，重启与私人恢复不继续执行。

`/undo` 准备最近一步的回退，不直接写文件；列表可以选择较早边界。原 `flow.undo(changeId)` 保留为明确的单版本撤销兼容入口。日志和工作对话均保留；追加回退事件，工作模型下一次收到元数据提示并应重读文件。运行命令的非文件副作用不在回退范围内。画面仍归 Claude，先接朴素控件。
