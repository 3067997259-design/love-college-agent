# 第三圈：心流中的只读分身

2026-10-17，接口 `4594698` 已先合 main。独立实现，不调用 Codex 子代理服务，也不复制参考项目模块。

## 运行边界

`delegate_readonly {task,paths}` 只在活动心流内可用，计划模式也能只读。task ≤500 字，指定 1–5 个书桌相对路径；路径沿用既有防越界规则，所有源材料合计 JSON ≤32 KB。子任务只收到这个任务和这些文本／指纹，没有用户聊天、完整人设、私密配置、其他任务、写入工具、网络工具、递归分身或记忆写入口。

最多同时 3 个，每自然日最多 12 次尝试，包括失败、超时和取消。每个请求 30 秒上限，统一时钟；正式运行用 background 槽的独立 JSON 请求，仍经过总量／自主预算的预留守卫，不退回 chat。没有 background 配置则明确不可用。开发模式使用 fake，无真实模型调用。

`delegate_result {delegateId,wait?}` 返回当前心流内任务的未审核结论（≤2000 字）和来源 path／sha256 指纹／current 校验。引用必须精确来自该次输入，禁止伪造路径和指纹；结论本身仍是未审核数据，不等于来源蕴含或外部执行证明。本体可以据此继续核对并形成自己的结论，只有本体发言。完成只表示子任务请求产生了合法结果，没有执行任何写入。

子任务不创建 `model/seen`、记忆或日记。结果只作为心流工具结果交本体；心流输入继续全部 eligibleIndexes=[]。退出摘要只带子任务 id／状态及未审核标记，不把结论或文件正文混回普通上下文；原文仍留私有日志供程序投影，私人存档按已有同用户／角色规则保存。

取消单项用 `flow.delegate.cancel`。停止本体、退出心流、禁用编码插件、熄灯和关闭应用都会取消未完成子任务；等待结果时取消父调用也取消子任务。迟到的、不响应 AbortSignal 的返回不能写结果。重启把未完成记录追加为 interrupted/cancelled，不重放请求。读取其他心流任务 id 拒绝。

## Claude 接线

`HeartFlowView.delegates` 只有 id、flowId、source、sourceCount、status、时间和固定错误码，不含任务正文／源文本／结论。朴素进度与取消入口在 `HeartFlowControls.tsx`。接口 SHA **4594698**，可用于 Q 版活动卡；不要把 cancelled/failed 画成完成，也不要让分身代替本体说话。
