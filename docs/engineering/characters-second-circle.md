# 静态角色包与作用域

2026-10-17，接口 `9d860b6`。最小包 `.lca-character` 是 ZIP：`manifest.json` 与声明过的 `images/*.png`；卡片字段严格为 formatVersion=1、kind=lca-character、name（称呼最多 12 字）、persona（最多 4000 字）和 images。具名图槽如 `facing-user_calm`、`desk-writing_calm`；同姿势 calm → 正面 calm → 内置画面回退。首版只接 PNG，避免在赛中增加多种图片解析路径；不改 CSP，不接受 URL、SVG、脚本、私人档案字段或未声明文件。

ZIP 先独立检查中央目录／本地头／路径／数量／压缩方法／实际有界解压／CRC，再解码图片；拒绝 ZIP64、多卷、软链接、加密、穿越、重复项、尺寸伪造、8 MB 单图／32 MB 总量以上或超像素图片。PNG 在解码前检查 IHDR 尺寸，Electron nativeImage 再解码重编码，移除原元数据和尾部载荷。公开 ID 由规范化卡片与素材哈希决定，图片存本地 CAS。

选择角色后重启，所有私有仓库按新 characterId 打开，新角色独立新手流程；切回原角色恢复原聊天／记忆／名字。角色卡是独立系统配置层，不作共同经历。导出只取静态卡片和 PNG；内置包导出十张已批准整景图，persona 暂为空（待 Claude 语气线完善），不带“关于你”、邮箱、附件、成品、日记、凭据。自定义图目前朴素显示，内置着色器不动。

私人存档保持同用户／同角色校验；新机器先导入同一角色包并切换，再恢复对应私人存档。不会为了方便导入放宽关系隔离。丢失图片回退；缺素材的存档导出仍如实报错，重新导入同包可补资源。

实际通过 typecheck、lint、3 项单测（静态包、私有／多余字段、路径／膨胀／像素拒绝与槽位回退）；`test:characters` 真实 Electron 原生选择导入、PNG 本地加载、重启角色隔离、系统卡片、公开导出、切回原关系及内置十图导出。合成图片仅 1 像素，用于边界验收，不是最终美术。
