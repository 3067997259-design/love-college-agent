# 上下文归属、拼接与退出审计

2026-10-18。用户要求统一校园插件，并梳理忽略、上传、权限变化等情况下的上下文。以下是本轮实现后的规则，不把历史对话界面、当前模型输入和长期记忆当作同一份数据。

## 拼接顺序

系统约束与角色 → 用户会话（心流单独上下文）→ 合法的记忆/摘要引用 → 当前回合工具结果 → 当前来源状态 → 本轮获准读取的原文。外部原文始终视为数据，不获得指令权限。每次模型请求都重新检查当前状态，单份正文最多 24000 字符、合计最多 48000；截断会标记。正文补充不记录进 model/seen 或普通日志。

忽略后保留的是忽略决定与用户历史，不是仍有效的事项正文。已经发送给供应商的数据无法撤回；生成途中的旧回复会被丢弃，后续请求重新准备。旧版本没有逐句的原文依赖标签，因此历史回复按外部工具回合和被忽略候选标题保守退出；这不是对任意历史改写内容的语义删除证明。

| 触发情形 | 当前模型输入与退出规则 | 保留的持久事实 |
| --- | --- | --- |
| 新上传文件，随后发送消息 | 本轮自动带入授权正文；不等另一请求整理完成 | 私有源库、资料任务与交付状态 |
| 文件整理中/失败/不支持/无文字层 | 提供明确状态；没有正文不能说已读，不能用邮件替代 | 错误与可重试任务 |
| 后续回合再问文件或重启后继续读 | 先看文件列表，再按 documentId 用 read_uploaded_file 取本轮来源；不永久注入最近文件 | 文件仍可显式读取 |
| 同一文件重复上传 | 复用文档 ID，重新绑定紧接着的回合；不重复交付 | 原任务和交付 |
| 文件取消 | 排除正文；迟到处理结果不得提交 | 取消状态 |
| 邮件/校园事项读取 | 只有实际读取校园事项的回合才补充当前允许的原文 | 私有证据与校验后的候选 |
| 忽略候选 | 退出当前工具、原文、待投递新事件；历史自动邮件记录去掉旧字段；相关旧回复从模型投影退出 | 用户原聊天、原日志、忽略决定 |
| 重扫/再次导入同一证据 | 不复活相同版本的忽略项、不重复确认/交付 | 当前 revision 和处理游标 |
| 截止时间等实质内容改变 | 新 revision 重新待复核；旧正文不当成当前证据 | 旧已确认安排保留到用户复核 |
| 忽略已确认事项的改期 | 当前安排退回已接受版本；拒绝的新原文不注入 | 原日历 UID/已确认日期 |
| 用户确认 | 当前状态变 confirmed，导出由本地代码执行；模型话语不算确认 | 版本和实际交付证据 |
| 外部工具进入下一回合 | 旧 MCP/校园/资料工具内容替换为历史回执，保留工具调用配对和经格式校验的 jobId；任务句柄只供查询/取消，旧进度和正文不继续有效 | 原始执行日志和历史页面 |
| 忽略或权限变化发生在模型生成中 | 对比上下文版本；丢弃旧回复及旧回复携带的工具调用，重新准备 | 原操作事实不重放 |
| 隐私切到独立 | 当前不再补正文；隐私失败停止，不回退主模型 | 私有资料和用户决定 |
| 隐私切到跟随 | 只给当时明确授权主模型的新资料；历史隔离资料不自动解密给主模型 | 历史授权记录 |
| 自动记忆/摘要/压缩 | 外部工具正文、其直接复述和自动邮件/资料事件不作为个人事实抽取；已失效引用不自动召回 | 经历证据仍保留，赠笔可核验真实交付 |
| 用户主动翻旧页/引用 | 可按显式请求回看历史；历史不变成当前待办 | 当时实际可见的聊天和来源 |
| 停用插件/MCP 断开 | 工具立即退出可调用列表；旧结果在后续回合不作实时依据 | 已确认事项/交付不删除 |
| 心流/普通聊天 | 继续沿用独立上下文和执行入口；普通原文补充不进入心流 | 心流工作记录、用户普通聊天 |
| 日切/重启/存档恢复/角色隔离 | 使用既有作用域和恢复机制；文件需按 ID 重新读取，MCP 不自动连接 | 用户和角色所属事实，不重放动作 |

## 校园助手单插件

`plugin-packages/campus-assistant` 提供 health/import/scan/status/collect/cancel 一个工具入口。新证据通过主进程的 SourceMail 窄接口进入现有模型提取、引用校验、候选确认及本地导出链；不把大块扫描结果扔进普通对话再指望模型猜下一步。已有 Student Hub items 继续导入同一候选 ID，保留忽略决定。已被 Student Hub 整理成 items 的 artifact 不再次抽取，避免两条链生成重复卡。

启用新版时，普通聊天优先使用新版，旧 Student Hub MCP 和候选导入工具不再重复提供；旧安装记录不删除。可在插件页停用旧入口。旧版 MCP 若单独使用仍是通用远端工具，不能保证其任意自然语言结果都能逐项映射到 LCA 候选；现场使用新的一体插件。

本插件依赖本机 Student Hub 后端与已登录配置。health 仅检查安装/配置，不证明账号连通；自动化使用合成 Python 服务和 SQLite，不读取真实学校数据。扫描只采集，collect 才整理；失败与取消不当作空结果。本次不实现课程提交、手机日历和 Todoist 外部同步。

## 验收边界

新组合回归覆盖安装单插件 → 合成扫描 → 状态 → 新证据提取 → 原文候选 → 确认 → 实际本地交付，以及忽略旧三项后的即时读文件。新增单测覆盖生成途中上下文变化丢弃旧回复/工具、外部结果退场、记忆与赠笔见闻证据分离、跨回合文件显式读取。最终命令结果与包哈希在发布记录补齐；没有以提示词测试代替真实服务质量验收。
