# 历史照片与引用回忆：第三圈接口

共享接口位于 `src/shared/state.ts`、`src/shared/commands.ts`。先独立提交合 main，再实现主进程和朴素控件；Claude 负责书页画面。

- `snapshot.history`：照片索引、捕获状态和回忆状态；不包含历史摘录正文。`SessionPage.photo` 是该页保存的真实截图，`recallableMessageIds` 由主进程核对成功模型输入后给出。
- `history.photo.capture`：仅书本窗口，截当前场景层，不接受任意矩形、路径、URL 或图片数据。不截对话、钟、门牌及设置浮层。照片为 PNG 私人资产，随 `.lca-save` 带走；旧页不按今天的角色素材重画。
- `history.recall { anchor, question }`：仅书本窗口正常聊天空闲时。anchor 是 sessionId／messageId／原聊天文字的 UTF-16 半开区间；主进程验证范围与实际可见证据，正文不由渲染层提交。无法证明看见的片段拒绝回忆，不把用户可查档案当成模型可读档案。
- 回忆材料仅来自该作用域的成功 `model/seen` 允许片段；不打开邮件、附件、整理成品或日记，心流工作过程也不参与。历史参考不获得用户直述的事实修正权限，不重复抽取为新经历。
- 画面可用 `history.recall.status === 'recalling'` 表现正在回忆，并临时显示 `recall.photo`；状态与图片以主进程结果为准。具体动画和最终文案交 Claude。

以上为接口约定，实际实现与验证如下。合成经历／fake 模型验收不等同真实模型质量或自然跨日运行。

照片底层：接口 `7db7bfb` 已先合 main。手动保存、实际交付／赠礼／在线外出归来择优拍照、翻页前缺图补拍均使用书本当前场景。等待水彩画布绘制完成，临时隔离非场景元素并等待 compositor 帧；隐藏书本时不显示或抢焦点。PNG 按哈希存入现有私人资产层，追加照片索引；每个自动事件至多三次捕获尝试，跨会话／关闭后的迟到结果丢弃。无图时明确缺图，不重新生成过去画面。

`pnpm test:history` 是实际 Electron 场景：合成聊天、场景真实 PNG、打开设置时排除浮层／钟／门牌、跨日旧页查图、重启、私人存档导出和空 profile 恢复。像素回归在钟／门牌上先画可检测的洋红测试色，确认全窗口截图里存在，再断言历史照片中没有；不能只依赖 DOM visibility。另有三项照片单测，类型与定向 lint 通过。运行中曾发现首次捕获取到旧 compositor 帧，已补等待绘制和双帧同步；实际截图已目视复核。

引用底层：`history/seen.ts` 以旧页消息 ID、已 drain 的用户消息、成功 `model/seen.eligibleIndexes` 的角色／全文匹配建立可见证据。只接受普通对话 user／assistant；未被成功模型输入再次看见的最后一条回复保守地不开放引用。排除 inbox 通知、工具结果和心流工作层；不依赖当前压缩投影，因此原有上下文压缩不会抹掉历史可见证明。每个请求只绑定一个作用域内的旧会话。

初始参考装入选句、附近最多五条对话，以及能逐句在允许可见片段中核验的日／周摘要。历史参考放在当前问题之前，并从新经历允许索引中排除。模型工具 `recall_seen {requestId, relativeStart, count}` 只能扩读当前引用附近同一页的普通对话，每次最多四条、最多八次且总计 24,000 字符；工具结果也不参加新记忆抽取。请求／使用／扩读日志仅保存锚点、回合、计数，不复制摘录。禁用 history 插件后停止捕获和扩读。

朴素入口位于“工具与设置 → 记忆与日会话”：保存照片、选历史页、整句引用或鼠标选中≤1,000 UTF-16 单元、填写问题、发送。snapshot 仅含回忆状态、锚点和旧照片 URL；实际材料在主进程组装。四项引用单测覆盖可见证明、来源／作用域、摘要依据、初始索引排除、回合绑定和持久扩读预算。完整 Electron 场景实际走界面引用、fake 工具扩读、模型输入检查、其他作用域会话拒绝、重启与私人恢复后再次引用。测试里的延迟只由统一时钟推进。
