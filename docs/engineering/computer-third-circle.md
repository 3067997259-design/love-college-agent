# 隔离书桌预览与有界 computer use

接口先行：heartFlow.computer 及 flow.computer.open/close/approve。沿用用户确认的“仅书桌、运行逐次审批”边界：用户明确选一个书桌静态 HTML，模型只观察该预览／提议单个点击、文字输入或少量具名按键，动作每次人工确认。不是整机控制，不连接已有应用实例。真实外部应用目标仍待用户给出；未回答时仅做这个隔离场景。

目标无 preload／Node／IPC，页面脚本、网络、导航、下载、权限请求关闭；这是安全静态预览，不宣称可运行任意 JavaScript 应用。开窗／重启／退出／停止／熄灯不复用旧动作审批。截图只属于工作层，不能进入普通聊天、经历或调试原文。接口这一步尚未代表后端或验收完成。
