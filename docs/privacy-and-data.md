# 隐私与数据

应用在本机保存状态，通过用户配置的外部服务完成模型、邮件或生成任务。选择了什么服务、当前路由和资料授权，决定原文会被谁处理。

## 两种隐私模式

| 方式 | 原文处理 |
| --- | --- |
| 跟随主模型 | 关闭隔离，主对话模型可处理获授权的新邮件和资料原文。新安装默认采用此方式。 |
| 独立隐私模型 | 无工具的独立端点处理原文，经过代码校验后放行有限字段或生成给用户的文件；失败停止，不自动回退主模型。 |

独立 privacy 不自动等于本地或校内部署，端点的位置取决于用户配置。切换跟随不会公开旧隔离材料；旧暂存文件要明确重试，后续回合按文档 ID 显式读取。邮件和隐私插件按所选路由处理，文件另有 `/privacy` 过滤开关。

记忆、日记和后台工作使用 background 路由，可跟随日常对话或独立配置。已有独立槽位在升级时保留，即使为空也不会静默改用 chat。模型配置保存立即生效；其他连接按界面提示重启。

## 数据保存在哪里

| 数据 | 归属与边界 |
| --- | --- |
| 对话与执行事件 | 本地 append-only 日志及 SQLite 投影，按用户和角色作用域保存。 |
| 邮件证据、上传文件正文 | 主进程私有源库；不会完整进入通用快照、调试工具或普通工具日志。获授权回合仍可能发送给选定模型。 |
| 交付与书桌作品 | 受管理的本地文件，实际写入与状态分开核验。 |
| 经历记忆 | 从允许的成功输入片段抽取，保留来源与纠正；不从私有源库补填。 |
| 日记 | 角色化主观回顾，加密保存；钥匙和正文走用户专用读取，不作为事实来源。 |
| providers / MCP 配置 | 主进程管理的本地连接文件，不返回配置值。当前 providers JSON 不是加密保险箱，应按凭据文件保管。 |
| 私人 `.lca-save` | 含聊天、记忆、证据及登记文件，排除连接凭据；存档本身当前不加密。 |
| 静态角色包 | 用于角色与素材分享，默认不含聊天、校园数据和连接。 |

源码数据默认在 `<checkout>/.local-data`，安装版在 Electron 用户数据目录；独立 profile、开发场景和房间投影见 [开发说明](deployment.md)。

## 来源退出与记忆

忽略候选会让其退出当前读取工具、自动事件和原文补充，相关旧工具结果不继续作为当前事实；用户历史与忽略决定仍保存。取消文件、停用插件或切换权限后，新的模型请求重新核对来源。

外部工具正文、直接复述、自动邮件 / 资料事件不自动抽成个人记忆。检索、摘要和旧页引用不反复变成新经历。历史见闻记录可用于验证发生过交付或赠笔，但不等于允许记忆抽取。

旧版本的历史没有完整逐句依赖标签，不能承诺所有语义改写都能自动识别并退出。已经发送给外部供应商的内容无法由本地应用撤回。

## 备份与恢复

导出使用当前作用域的日志、数据库备份与登记文件，校验路径和哈希。恢复先显示概要，经确认后自动创建恢复前备份，重启替换并支持失败回滚。其他用户和角色的数据不能被混入当前恢复。

不要把私人存档当作角色包公开分发，也不要把完整存档、providers JSON 或原始数据库上传到公开 issue。换电脑后重新配置连接；复制安装目录不会自动迁移数据。

## 反馈与排查

优先提供版本、固定错误分类、操作步骤和合成样例。日志与截图先人工检查，去掉密钥、邮箱、正文、个人路径或其他不想公开的信息。涉及原文或凭据的问题，先按 [贡献指南](../CONTRIBUTING.md) 确定沟通范围，再提供最小复现。
