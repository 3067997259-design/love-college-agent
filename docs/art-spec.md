# 美术规格与素材维护

当前内置角色为桃子。风格采用淡彩、彩色线稿、柔光与纸面感，书本、房间与界面保持同一套视觉语言。保留已经批准的角色身份和画风，不以一次重绘替换整个资产体系。

## 资产与来源

- 运行时图像在 `src/renderer/src/assets/character/taozi/`，包含近景、宽景、外景、差分与生活瞬间。应用使用这些已复制的素材，不依赖本机视频制作目录。
- 采用记录在 `art/retouch-adopted.json`、`art/retouch-round2-adopted.json`、`art/retouch-deltas-adopted.json`，生成历史在 `art/gen-log.jsonl` 和 `art/deltas-records/`。
- 原始候选、制作工程和参考截图可能只在维护者本机；manifest 的 source 路径用于追溯，不表示这些本机文件一定随仓库分发。
- 历史规格与逐次采用记录可从 [冻结资料](history.md) 取回。新工作沿用当前来源链，不覆盖原始生成记录。

## 角色一致性

锁定身份、服饰、发型、镜头、比例和非目标道具。局部精修逐项复核头颈、领口、手、持物与透视；夜景另核对光源方向、衰减和已有夜色，避免重复叠加。

允许使用“NovelAI 生成整体画风与构图，再用图像工具精修局部”的流程，但每次记录输入、提示、输出、工具信息与采用状态。工具未返回具体模型版本时不宣称版本。

候选先做集中对比和应用组合预览，维护者采用后再接入正式资产。表情、眨眼、嘴型和光照差分须保留基准位置与遮挡，不能只凭单张美观判断可用。

## 参考边界

参考只借抽象风格与意象，不复制既有作品的具体人物造型、标志、镜头或原图。参考截图用于人工理解，不直接交给生图工具。角色提示词与检查不能依赖复现某个现成角色。

桃子的人设改编自维护者原创角色卡 ReLU；原卡含私人信息，不公开、不从其他项目的运行数据补填。可分享角色包与私人聊天、关系经历、校园资料分别管理。

## 素材接入

1. 对照采用基准列出目标变化，保留原图。
2. 生成或修整后检查目标区域、非目标变化和可组合性。
3. 在书页、迷你窗、不同状态与时段中预览，核对尺度、文字遮挡和缺素材回退。
4. 经维护者采用后更新运行时副本、manifest、来源和采用记录；只提交明确选定的资产。
