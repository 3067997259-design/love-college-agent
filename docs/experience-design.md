# 体验设计

产品围绕同一个角色的工作、安静陪伴和交流展开。她帮忙留下的成果、用户的建议和共同经历，应能影响后续互动；基本工作质量不依赖好感度或关系阶段。

## 一本书与一个小窗

左页呈现角色所在的场景、姿势、表情、时段和生活状态；右页承载对话、计划、候选、工作记录与交付。画面消费主进程事实，不用随机演出替代真实状态。

书签包含对话、日程、礼物、日记、设置和插件。设置按模型与声音、连接与插件、专注与作息、角色与书本、用量与实验、开发与调试分组。沿用纸色、手写标题与当前 CSS token，不为局部页面引入另一套无关设计系统。

专注时可收成桌面迷你窗，支持拖动、限位与展开。位置属于本机 profile；重启不强行恢复小窗，休息、停止和熄灯不抢焦点。透明失败时允许不透明圆角回退。

## 工作要看得见

工具活动、当前步骤、等待原因、失败与停止应有具体反馈。模型说完成不能替代实际文件和工具结果；同一个动作不能因重新叙述被重复执行。

校园候选保留原始截止与用户计划的区别。用户能看原文，再确认或忽略；改期形成新版本，未经确认不覆盖已接受安排。文件状态区分暂存、整理中、失败、完成与取消，交付卡打开实际产物。

多步工作就在对话里进行：她读写你选的项目文件、运行命令，活动按轮收起，要你批准的事停在输入框上方。工作中可以插话，她先回应再接着做；工作正文和读过的第三方原文不进记忆。

## 专注与她自己的生活

番茄钟由代码计时，角色通过工具使用。计划草案与生效计划分开；专注是安静陪伴，允许预算内后台活动，休息才适时交付或交流。熄灯暂停后台与计时，睡眠是另一个持久状态。

生活按真实时间和用户作息推进，地点、返回时刻和带回物由代码决定。离线只结算虚构生活事件；真实读写必须留下产物，不声称停机期间完成真实工作。

主动交流应有事件、经历或成果依据，也允许沉默。系统通知仅用于急件与等你批准的工作，普通后台活动不逐次弹通知。

## 共同经历与恢复

一天一页，翻页等待安全条件。旧对话、照片和来源可按用户请求回看；模型的回忆准确性与原始记录保存分开评价。压缩只改模型投影，不删除旧页。

礼物来自具体经历。第一支羽毛笔连接实际交付与私人存档；其他礼物制作需同意、配置和预算。日记保留角色主观性，不用它填补现实事实。显式好感度、解锁与更多关系系统尚未确定。

## 角色与视觉

内置角色桃子是默认体验，用户可导入静态角色包。角色包、场景概念与私人存档分别管理；一张图片自动生成完整角色差分仍是探索方向。

姿态、光线、表情、眨眼和嘴型由可用素材与状态映射组合。缺素材逐项回退，新素材先在应用中复核组合效果；具体契约见 [美术规格](art-spec.md)。
