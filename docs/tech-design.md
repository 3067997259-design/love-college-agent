# 技术方案与实现边界

本文维护当前架构，不把历史计划当作实现。产品方向见 [README](../README.md)，运行与测试条件见 [开发说明](deployment.md) 和 [测试说明](testing.md)。

## 进程与模块

Electron 主进程拥有事实、权限、连接和持久化；React 渲染层显示安全投影，preload 只暴露白名单能力。窗口使用 contextIsolation 与 sandbox，不给 renderer Node 或任意文件系统能力。

| 代码入口 | 职责 |
| --- | --- |
| `src/main/index.ts` | 实例、模型端口、业务模块和窗口装配 |
| `src/main/dsh/`、`harness/`、`plugins/`、`mcp/` | 她的 DSH 会话、LCA 工具与失败旁白、权限和外部扩展 |
| `src/main/clock/`、`scheduler/` | 统一时钟、阶段和后台调度 |
| `src/main/journal/`、`store/`、`storage/` | append-only 事实日志与 SQLite 投影 |
| `src/main/mail/`、`campus/`、`documents/` | 原始来源、提取校验、候选与实际文件 |
| `src/main/model/`、`config/`、`privacy/` | 模型连接、用途路由、配置与窄出口 |

## 执行与完成依据

她的回合在 DSH 会话里执行：DSH 处理模型步骤、工具调用、重试和取消；LCA 在每一步前按额度放行，把失败归入固定的失败词汇并写旁白。用户插话在下一步进入，不靠每一步额外生成播报推进。开发者模式把脚本回复做成本地的模型接口（`src/main/developer/endpoint.ts`），她的回合照样走 DSH；调试工具 `get_context` 返回 DSH 最近一次发给模型的内容。Minecraft 的游戏回合是唯一例外：它在自己的日志里跑一个有步数和用量上限的小循环（`src/main/minecraft/round.ts`），只看这一局。

命令 accepted 只表示接收。实际调用、结果、版本和文件证据才表示执行；生成待办、本地 `.ics` 或同步状态不等于外部服务已经写入。已有动作不会因为聊天失败自动重放。外部调用发出后，停止等待不能保证远端撤回。

她的对话和工作都在当天的 DSH 会话里（每个项目文件夹一个）。DSH 的会话日志记执行细节，journal 只记对话、对 DSH 回合的引用、活动行、审批与信任。命令在 OS 沙箱里运行，风险命令先问；用户可以信任一个项目，让命令不再走沙箱。LCA 的引用（记忆、她的世界、资料状态、旧页、要看的原文）随回合的开场消息发送，下一回合退役；读到第三方内容的回合降级，写入、命令和外发逐次询问，下一回合把这些原文退役。两者都从会话日志折叠得出，重启后照样退役。

1.2 的安全层将上述规则应用到每个成员：审批绑定运行实例、项目、成员本次活动和策略版本，主角色结束回合后仍可使用书里的审批卡。撤销信任会取消该家族的待审批与运行等待，并恢复项目沙箱；停止、换项目、退出和恢复不重放旧批准。当前保守地把新的根回合（含自动事件）作为新的授权边界，结束旧成员的等待与重试；需要继续的成员通过新指令重新激活。已发出的外部动作不能因此被视为已撤回。

来源投影按成员自己的轮次重放，覆盖原文、转述、完结消息、委派结果、fork 前缀和压缩摘要。调用时的来源类别写入 DSH 的插件记录；缺失声明的历史 LCA 工具结果保守视为插件来源。消息投递用发送者、正文摘要、项目和授权标识校验，缺失、歧义或过期投递不带原文进入模型。只替换模型表面，原始日志保留；无法核实来源时停止执行。跨项目接续与新的记忆抽取不自动采用来源受限或旧策略无法核实的助手回复，用户原话仍保留。实现、回归和限制见 [P2 回执](research/v1.2-p2-20261023.md)。

她问你的问题用 DSH 自带的 `ask_user_question`：一次一到四件事，每件可带选项（附一句说明）、可多选，也可以用你自己的话答。lca-bridge 接下 DSH 的提问请求交给 LCA，书里的问题卡来答（`src/main/questions/`）：专注和安静时排到休息，只算可见时间的十分钟内不答就告诉她没答上，每轮至多三次、每天十二次。你的回答作为工具结果回到她那里，也作为你的话进记忆；跳过就是每件都没选。审批是 LCA 替她问你，用同一张卡，只有选项。

扩展管理由主进程窄接口进入 DSH，不对 renderer 开放任意 RPC 或安装路径。profile 初始化保留用户声明；操作使用持久 ID、追加事实和安全投影，审批绑定来源及变更，构建脚本逐次批准。关闭 HMR 时，保存意图、实际插件状态与待重启分开记录。断连后核对原操作，不重放批准或盲目重装；无完成证据保持 unknown。实现与边界见 [P3 回执](research/v1.2-p3-20261023.md)。

P4 的插件书签直接消费这组接口，审批留在当前页。技能通过 DSH registry 与固定版本 filesystem parser 提供；LCA 只限定搜索根、文件边界和元数据投影。每次读取重新发现文件，目录不缓存旧候选；`skill` 工具结果作为插件来源追踪并在下一轮退役。原生选择、指纹审批、无覆盖复制和可追踪的移除由 main 完成；导入归属记录与操作日志留在私人数据目录，模型和 renderer 均不能直接读这些记录。MCP 继续走现有 LCA 单一连接与校园窄出口，见 [P4 回执](research/v1.2-p4-20261023.md)。

P5 在包外 bridge 装配 Team service，保留普通 spawn / fork；三个重名控制工具由单一适配按真实关系路由。独立产物用普通委派，稳定分工 / 共享任务用 Team，先续用合适成员。名册容量与共享运行容量分开呈现，停止不释放名册，运行实例数不可精确观察时显示未知。任务板和执行仍由 DSH 持有；LCA 只追加来源、用量、操作回执及安全投影，不另写代理循环。

成员操作绑定 runtime / project / root / parent / session 和控制版本；共享任务另校验 task revision，整组停止以根身份为目标，不被主角色普通活动更新误判过期。丢失回执不重发动作，显式刷新可重连并读取持久回执。停止成员会持久记录收件截止序号，旧消息即使在续派或冷恢复后迟到也不能重新获得授权。任务和成员标签保存原来源租约，改状态不能把旧来源洗成新内容。自主事件的整个成员家族共用六步额度。实现和验证边界见 [P5 回执](research/v1.2-p5-20261024.md)。

## 事实、投影与时钟

团队远景的当前步骤来自 bridge 的 `tool/call`、`tool/result`、同伴 `user/message` 和回合边界，在内存 Map 中维护，不因步骤变化增加成员控制 revision，也不逐步改写 root 日志。工具结束按固定运行时的 `message.toolCallId` 配对。主进程 `tool-kinds.ts` 与她自己的活动共用模板；`member-focus.ts` 用注入 Clock 维护 30 秒窗口、6 秒换位门槛与 20 秒思考状态，并到点发布。快照只含 `AgentView.work`，没有工具名与参数。

最近 12 个工具步骤由 DSH 自己的 `lca-member-steps-v1` 会话投影保存。`member-steps` 是独立的只读请求，不写协作操作或回执；成员归属由 bridge 的名册 / 后代关系核对，主进程另校验完整地址和控制 revision。已卸载成员通过 DSH persistence 的 read handle 回放日志，不恢复执行或批准。读回后重新校验作用域，迟到结果失效；回复由 zod 限制条数、长度和时间并剥掉未知字段。

目标摘要是白名单：文件只显示项目内相对路径，搜索截 60 字，命令截 80 字，网页只保留 host。成员原标签租约、已保存来源及当前来源均须干净；步骤投影也保留曾接触外部来源的限制，不能因下一轮来源退役而公开旧目标。`readMemberSteps` 只向书本主 frame 开放，不向小窗、诊断窗口或模型开放。书页只缓存打开卡片期间的详情，来源转为受限时立即隐藏旧目标；不写入 LCA 日志、快照、日记或记忆。

会话事件写入 append-only JSONL，SQLite 保存可重建的投影。用户、角色与数据根参与作用域。UI revision / epoch 与日志序号分别使用；renderer 不生成业务事实。

业务时间经 Clock / Scheduler，方便确定性回归。日会话按上海时间 04:00 划分，并等待回合结束、用户空闲和计时条件允许后翻页；不能在任务中途强行切页。加速时钟验证状态转换，不证明真实跨天或长期体验。

日切只在当前时段为夜间时申请自动入睡，避免白天补翻旧页让角色重新睡着。睡眠服务从当前用户 / 角色的事实历史核对最近一次入睡原因，自动入睡由 Scheduler 在其后第一个早晨分界（默认 06:00）写入 `day-start` 唤醒事实；启动和恢复同样校正已过期的自动睡眠。手动或无法核实原因的睡眠保留，不从其他角色借用事实。自动醒来不改变 lightsOut；睡姿、时段和素材继续消费主进程投影，不改素材来掩盖状态。

每个 DSH 新回合的开场附带 main 从统一 Clock 读取的 `currentTime`，包含 UTC 记录、上海本地时间和明确时区；与 `get_clock` 共用同一读取函数。提示词要求按本地时间理解问候，长回合需要更新时间时再调用工具，不能自行设定角色另一侧的钟点。时间随本轮引用退役，不能进入用户原话或记忆片段；这是提供时间依据，不保证供应商始终遵循提示。

`.lca-save` 从一致快照导出当前作用域的日志、数据库与登记文件，验证路径和 SHA。恢复须核对概要并明确确认，先创建恢复前备份，失败可回滚；恢复保持会话与剩余计时，不把导出到恢复的空档算作工作。连接和凭据不随存档迁移，容器本身当前不加密。

1.2 恢复时把 DSH 会话索引与书本数据纳入同一替换事务，旧索引保留在回滚目录；事务中断一起回滚，不能在恢复的书本上接回存档之后的成员。私人存档不包含外部项目、DSH 原始会话与 Team 执行状态、扩展安装或连接配置。恢复后新建协作家族，不重放成员或旧批准。项目切换与日切立即撤销旧协作投影，旧作用域的审批、模型步骤和迟到回调均拒绝进入当前书页。

## 模型路由与原文

手动模型能力保存在主进程连接配置的 `modelCapabilities` 注册表，键为接口地址、密钥和模型的有界摘要引用；renderer 只收到当前绑定的 opaque `modelRef`、能力字段与声明 / 运行时信息，不获得地址或密钥。`models.capabilities.save` 按当前引用核对，拒绝旧表单跨连接 / 模型写入。字段为严格白名单，token 数 1–100,000,000，文本输入必需、图片可选，思考档位限定现有七档，值为有界参数字符串；只有 off 可用 null 表示省略参数，必须至少有一档非 off，false 表示不提供可选档位。注册表最多 128 项，导入与 GUI 保存共用校验。

DSH pi-ai 模型条目收到 contextWindow、maxTokens、input 和 reasoningEfforts；不修改上游包或锁文件。声明改变时沿用既有模型配置热应用边界，忙时拒绝，关闭原 host 后重建，旧批准不重放；仅切换已提供的思考档位仍从下一步热生效。删除手动思考声明会移除失效的角色档位选择。目录 / 默认信息来自 DSH 的 resolveModelInfo，不进行网络发现或能力探针；配置来源与实际供应商兼容性分开。DeepSeek 官方原生适配器不接受此覆盖，GUI 无入口，导入绑定其上的声明会拒绝。LCA 自身固定任务端点只使用声明的输出上限及图片限制，DSH 会话的上下文容量与思考映射仍由 DSH 执行。

开发版门牌路由：`work` 从 work 槽位开始用户的新回合，`quiet/rest` 从 chat 开始；自主事件仍由 chat 开头。手动改门牌影响后续新回合，不重放当前步骤。原有 hands-on 工具交接保留。主模型另可输出完整 `{"lca_state":{"mode":"work","token":"本次凭据"},"reply":"简短回应"}` 请求切换，无需先发出原生 function call；普通文字、工具结果和引用示例不解析为命令。

状态凭据由 main 随当前会话、门牌和用户消息更新。只有当前根会话的用户回合可申请，取消、换项目、手动改变状态、睡眠或熄灯后拒绝旧指令；每轮最多接受两次实际状态变化，模型不能提前结束番茄专注。完整 stop 输出、严格字段/枚举/长度校验后，bridge 在 DSH 已有 pre-step / turn-stopping 边界等待 main 确认。chat → work 每轮最多注入一次程序交接消息，沿用原会话、原用户请求、权限、来源与每步额度，没有新增执行循环。控制 JSON 不进入书页与 LCA 记忆，只显示 reply；DSH 原始记录保留。格式错误或主进程拒绝时保持当前状态，显示失败提示，不自行重试。实际工作仍由工具结果和产物证明。

模型配置只在主进程。chat 用于日常对话；background 用于记忆、日记与后台工作，可显式跟随 chat 或独立配置。privacy 的跟随表示关闭隔离，独立模式提供无工具的原文整理端点。独立失败关闭业务，不自动借用 chat；旧独立配置不因升级静默降级。

设置里的“测试连接”走该槽位实际使用的通道：chat / work 由 bridge 经 `ctx.llm.stream` 用同一 DSH 适配器发一次小请求（收到首段回复即停止，30 秒超时），background / privacy 用 LCA 客户端单次请求、不重试。结果分两份：快照只带测试通道、DSH 路由名、闭集原因、HTTP 状态和代码；请求地址、服务商原话、原始响应与请求 ID 留在主进程内存，书页打开详情时经 `readConnectionTest` 按槽位读取，仅书页窗口可读，设置改动后作废。服务商原话只用于这份详情，不写入日志、模型上下文或失败旁白；所有已配置密钥与 Bearer 令牌在进入任何一份之前遮盖。

模型配置热生效，TTS / Rodin / 邮箱仍按配置提示重启。密钥、连接地址等配置值不进入安全快照或调试接口；不能把“在本机保存”描述成“不会发送原文”。详细数据归属见 [隐私与数据](privacy-and-data.md)。

每次模型请求重新准备：角色与系统约束 → 会话 → 有效记忆 / 摘要引用 → 当前工具结果 → 来源状态 → 当回合获准读取的原文。外部原文作为数据，不获得指令权限。正文单份最多 24,000 字符、合计最多 48,000，截断带标记。

| 变化 | 当前模型投影 | 保留的数据 |
| --- | --- | --- |
| 新文件与紧接着的提问 | 当回合补入获授权正文，不等待另一整理请求结束 | 资料与交付状态 |
| 后续回合或重启再读 | 按文档 ID 显式读取，不永久注入“最近文件” | 原文件和任务 |
| 取消文件或忽略候选 | 排除相关正文、当前结果和待投递事件 | 用户旧页、日志和决定 |
| 日期等实质内容变化 | 新 revision 待复核，旧已确认安排保持到用户决定 | 旧接受版本与变更链 |
| 外部工具进入下一回合 | 旧正文替换为历史回执；校验后的 jobId 仅供查询 / 取消 | 执行日志 |
| 供应商复用 tool callId | 结合所属回合和配对位置核对当前结果 | 各次实际调用 |
| 生成中来源或权限改变 | 丢弃旧回复及携带的工具调用，重新准备 | 已发生动作不重放 |
| 切换隐私模式 | 重新按授权选择来源，历史隔离材料不自动公开 | 历史授权和私有库 |

已发给供应商的数据无法撤回；旧历史没有逐句来源标签，不能承诺对任意改写内容做完备的语义删除。

## 校园与资料

`plugin-packages/campus-assistant` 提供 health / import / scan / status / collect / cancel。新证据经主进程 `sourceMails` 窄接口进入现有提取、引用校验、候选、版本确认和本地交付；插件工具回执只含进度与计数。

扫描与整理分开，jobId 可跨回合查询或取消；失败不作空结果解释。启用新版时旧 Student Hub MCP 和候选工具不重复暴露，已有确认 / 忽略决定保留。同源同版本不会因重扫复活忽略项。

资料正文在私有源库，PDF 使用独立解析子进程，不继承供应商环境。按模式整理后生成实际本地文件，错误、暂存和处理中分别显示。模型输出经 schema、长度、枚举、日期和引用校验，不能仅相信其自述。

## 记忆、生活与关系

记忆只从成功模型输入的允许片段抽取，带来源、时间、作用域、纠正链和审核状态。原始证据、工具正文及其直接复述、自动邮件事件不自动成为个人记忆；当时见闻证据仍可用于实际交付与赠笔核验。

摘要与召回不是新经历。日 / 周 / 月归并只处理已有合法摘要，保留来源与旧版本，避免上下文中重复覆盖同一会话；`/compact` 只压缩旧完整回合的模型投影，不删除用户旧页。光学封页是默认关闭的可选研究能力，不能代替文字记忆或被当作已验证的遗忘机制。

生活事实由代码定：地点、作息、外出返回和带回物持久化，离线只补一次虚构事件。真实阅读 / 写作需登记材料和实际产物；恢复空档不虚构工作。日记是加密保存的主观回顾，不作为事实来源。

礼物绑定角色当时可见的真实经历，实时制作先取得同意，再受配置、预算和取消约束。羽毛笔与其他实时 3D 礼物分别管理。关系机制优先通过建议、作品和共同经历的后果表达，显式好感度与解锁尚未定稿。
