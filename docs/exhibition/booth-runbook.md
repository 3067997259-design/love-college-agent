## 布置

- 桌边放一句邀请：“片子里的她，现在也在这本书里。可以交给她一件小事。”下方三个选项：整理一份公开资料／专注一分钟／留一句话。
- 主讲与体验者说话，队友操作、看等待状态、负责下一位复位。评委到场时，B 机减小音量，A 机立刻回书本。

## 两套真模型书本，一套彩排书本

用随附 `Start-LcaDemo.ps1` 启动已安装的 `LoveCollegeAgent.exe`。脚本只建独立数据目录，不拷原书、不取密钥、不自动扫描。三种模式分别配置；首次真实配置由操作者在 GUI 填写或自己选择本机配置文件。

操作卡包中也有三个双击入口：`Start-LcaJudges.cmd`、`Start-LcaVisitors.cmd`、`Start-LcaRehearsal.cmd`。双击对应入口，在提示处粘贴已安装 EXE 的完整路径即可。它们调用 Windows 自带 PowerShell，执行策略只对这次子进程生效，不修改系统策略。

| 模式 | 用途 | 已有约束 |
| --- | --- | --- |
| Judges | 评委演示，独立普通模式 | 可在已配置时只读扫描演示邮箱；由操作员控制，不向路人开放系统命令／插件操作 |
| Visitors | 同学体验，独立展位模式 | 真实聊天、privacy 文件整理、番茄、存档；真实邮箱扫描与本地代码插件安装关闭，调试关闭 |
| Rehearsal | 操作员演练 | 独立假模型与假来源，真实配置不读取；允许现有冻结／快进和场景切换，不可作为真实服务证明 |

命令示例（应用路径换成目标电脑实际安装位置）：

```powershell
& '.\Start-LcaDemo.ps1' -Mode Judges -AppPath 'D:\LCA\LoveCollegeAgent.exe'
& '.\Start-LcaDemo.ps1' -Mode Visitors -AppPath 'D:\LCA\LoveCollegeAgent.exe'
& '.\Start-LcaDemo.ps1' -Mode Rehearsal -AppPath 'D:\LCA\LoveCollegeAgent.exe'
```

默认根目录在 `%LOCALAPPDATA%\LCA-Demo-20261018` 下，三档分开。不要从普通安装快捷方式打开后误以为进了展位。脚本输出本次模式与数据目录；`-InspectOnly` 只检查路径，不启动、不建档。

## 一位同学的 90 秒体验

1. **0–15 秒，自己选一件事。** 队友：“你想让她整理资料，还是先认识一下？”不要求填姓名、邮箱或学校账号。
2. **15–45 秒，自己动手。** 首选把随附的 `public-notice.md` 拖进书本；先 `/privacy on`，看暂存／处理状态。用真实 privacy 服务，失败如实停下。聊天选择可问：“如果我只剩十分钟读书，你建议怎样开始？”
3. **45–70 秒，亲自核对。** 点完成后的交付卡“查看”，比对原始日期、地点、三项准备；这是实际 Markdown 文件。资料整理不会自动变成校园候选卡，不把两个入口混讲。
4. **70–90 秒，体验节奏。** 打开日程，勾演示节奏，生成／确认一轮计划；开始后缩成小窗。愿意多停留的同学陪她完成一分钟；赶时间就留下一句普通聊天后离开。

同学自由聊天可以改变这一本展位书里的经历。提前说明它是共享体验档，下一位可能看见当前内容，因此只聊公开的小事。现场不展示任何观众私密输入；需要换人复位时用应用恢复公开基线存档，操作员负责核对概要。

| 短片意象 | 产品中亲手可做的事 | 讲一句就够 |

| 推来日程纸 | 查看候选证据、确认、打开实际交付文件（评委档） | “纸不是一句答复，它最后落成了文件。” |
| 她低头写字 | 确认番茄后的一分钟安静小窗（两档） | “你专注的时候，她不主动打断你。” |
| 赠笔、颜色回来 | 从羽毛笔／设置导出并恢复公开演示书本 | “这里保存的是这本书里的经历和作品。” |

不承诺她永不遗忘、停机时实际工作或每一分钟都会产出礼物。带回物、真实 Rodin 成品和旧页仅在已经准备且实际存在时展示；没有就略过，不用假的替代实机成果。

## 评委来前准备好的三个状态

- **J0 待核对：** Judges 中只有专用演示邮件／公开资料。一张候选尚未确认，原文可查看；有一份已完成的公开资料备用。现场确认＋导出这张候选。
- **J1 已交付：** 真实打开过的 `.ics`／Markdown 和一段普通共同经历。保留给网络故障时展示；说明“这是刚才／赛中已经跑过的结果”。
- **V0 公开基线：** Visitors 里只有公开资料／不含私密内容的聊天。若从 Judges 恢复，只能用经过操作员逐项核对的公开演示存档，不能用含个人邮件的 `demo-mail-day2.lca-save`。配置不跟随存档，需要在目标根单独设置。

这些是准备要求，本文及启动脚本不会凭空创建 J0/J1/V0。存档目前含私有源库且不加密，不对访客散发。恢复会先自动备份旧档；它是现场复位，不等于删除此前访客数据。

## 调试模式怎样收尾

本轮先复用已验证入口，不把真实模型塞进假模型开发档，也不临场改调度／时钟。操作员彩排路径：设置 → 启用开发 → 重启 → 合成邮箱初始场景 → 扫描 → 核对确认 → 文件；日程演示节奏一轮；完整恢复另走 `.lca-save`，不用 fixture JSON 冒充。

需要调时间时用“快进一分钟”或 1 倍／60 倍；对外演示的短番茄仍走真实的一分钟，不快进。测试场景切换会生成新开发档，旧档保留，重启才生效。彩排后退出该实例，用 Judges／Visitors 重新开；勿只把面板关掉便认为已切回真模型。

## 卡住时的操作卡

| 情况 | 操作 | 现场说法 |
| --- | --- | --- |
| 模型 10 秒未回应 | 指向正在处理的状态，讲本次要核对的结果；超过 20 秒转 J1，不重复点提交 | “这一步依赖网络，我先给你看刚才跑出的文件。” |
| privacy 不可用 | 保留暂存状态，打开已完成样例；停止现场整理 | “隐私服务没连上，这份资料现在不会改发给主模型。” |
| 邮箱扫描失败 | J0/J1 的预读证据继续演示，明确非现场新抓取 | “这封是事先读入的演示邮件，现在现场做确认和导出。” |
| 恢复超时 | 不再点确认，不删数据；切另一独立档的已验证结果 | “恢复仍在进行，我们先看另外一份已验证的书本。” |
| 来人多 | 每人选一个入口，队友负责复位；不临时开多模型任务 | “先挑一个最想试的。” |
| 只剩一台电脑 | 排队时循环短片，操作时切应用；不把书本挤成难以读字的小窗 | 片子只负责引人停下，操作时让人看清结果 |

同学展示不等于全天无人值守运行验收；操作者一直在场。
