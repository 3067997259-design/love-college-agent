# 评委巡查：三分钟操作与讲法

2026-10-18。此卡优先于旧五分钟讲稿中的时间安排。操作者用独立 Judges 书本；完整短片在旁边循环，评委到场先降音量。讲稿是供主讲调整的草稿。

## 三分钟

| 时间 | 操作员 | 主讲可以这样说 |
| --- | --- | --- |
| 0:00–0:25 | 书本停在对话页，她在房间里；不打开设置 | “这是桃子，一个面向大学生活的个人 Agent。我们想把两件事放在一起：她能把通知和资料里的事办妥，你们做过的事也能成为以后相处的经历。” |
| 0:25–1:20 | 打开预读的演示邮件候选，展开原文，指向截止时间；当场确认、导出、打开实际文件 | “这封是我们准备的演示邮件，已经读入。她提取出候选，但要先让我对照原文确认。现在点确认，再打开她交付的日程文件。这里的完成有文件和回执，不只是聊天里说一句做完了。” |
| 1:20–1:55 | 打开一份已完成的公开资料；彩排能在 20 秒内返回时，可现场拖入随附样例；按本档实际模式讲 | 跟随模式：“这是一份公开资料，现在直接交给主模型，她整理后也能和我讨论内容。”独立模式：“这份资料走独立隐私模型，普通聊天不拿正文。服务失败就停，不自动改发主模型。” |
| 1:55–2:15 | 日程里生成并确认一轮演示番茄，开始，露出小窗，然后手动展开 | “番茄钟是相处的节奏。你专注时，她安静陪着；现在演示的是一分钟，计时仍由代码负责。它不是让模型猜时间。” |
| 2:15–2:45 | 展示已准备且不含私人内容的旧页／一段普通经历；有公开存档则指向导出入口 | “这本书保存原来的对话、作品和经历。模型上下文可以压缩，但用户的旧页不会跟着删掉。回忆只取她当时看见过的内容。私人存档可以带走和恢复。” |
| 2:45–3:00 | 回到书本全景 | “片子讲的是这种关系会怎样继续。现场这本书证明的是：她做事有结果，相处有来处，换一台电脑也能继续。” |

如果第二台安装或恢复尚未通过，最后一句改成“存档可以把这段经历保留下来”，不先承诺跨设备已验收。

三分钟里不等待一分钟完整走完，不演删除数据，不新生成 3D，不现场安装外部工具。旧页／成品明确说是事先准备的。没有公开旧页时，展示本轮聊天与交付的重启保留，不拿含个人邮件的旧档给路人看。

用户选择演示插件安装时，以“校园助手”单插件替代上述预读邮件段的开头：在未安装该插件的独立演示书本里，添加本地插件目录并确认启用；后端和学校登录提前配置好。解释“安装这一项，就把扫描、证据整理、候选卡接到书页里”。已完成扫描时直接读取结果生成候选；不要为等真实网络牺牲整段演示。新版启用后不重复提供旧 Student Hub MCP 和候选导入工具。

## 只有一分钟

> 这是桃子，一个把工作和共同经历放进同一本书的个人 Agent。学校通知很零散，她先从邮件里提出候选，我对照原文确认后，她再生成真正的日程文件。这里是原文，这里是截止时间，这是刚导出的文件。专注时她会缩成安静的小窗，休息再交流。对话、作品和经历可以保存在自己的电脑里，也可以导出、恢复。旁边的短片把这个想法讲成了一个故事，你面前这本书可以直接操作。

## 多停留两分钟：现场恢复

1. 只在已走通的独立公开演示档执行。留下一句普通对话，例如“今天我们选了蓝色封面的书”。等真实回复完成。
2. 用羽毛笔／设置导出 `.lca-save`；核对文件成功生成。
3. 通过应用“导入／恢复”选回刚才的存档，核对概要，确认一次。自动备份后重启。**无需清空目录。**
4. 先展示原聊天和交付还在，再询问刚才聊过什么。把文件和历史作为证据；模型没有准确答出时如实说回忆回答仍需改进。
5. 存档不是云同步，不含供应商凭据，也不是公开角色包；它包含私有源库且目前不加密。

## 六张答辩卡

- **为什么不只是聊天皮肤？** 现场的证据核对、实际文件、确定性计时、日志恢复组成了完整工作流程；人物与工作共享经历。不要用对其他产品的未经核实的贬低来回答。
- **记忆会不会编造？** 只抽取成功送入模型的允许片段，保留来源与纠正链；召回是确定性的。它减少无来源的说法，不保证每次回答绝对正确，也不声称永不遗忘。
- **隐私数据去了哪里？** 由用户明确选择：独立滤芯时原文只发到该端点，普通聊天拿校验后的字段；跟随主模型就是关闭隔离，主模型会看到新资料原文。不能把跟随说成已脱敏，也不能把“privacy 槽位”说成“数据不出校”。切换不会自动公开历史隔离来源，已经发出的内容不能撤回。
- **技术难点是什么？** 举一条：来源里的“没有提交”不能因为包含“提交”就被抽成已提交；我们有来源、否定／作用域和修订守卫。实验装置的数字只代表那批合成用例，不当真实中文准确率。
- **哪些是你们写的？** 应用主进程、日志投影、harness、隐私边界、书本和恢复独立实现；开源依赖与参考机制另列。Student Hub 是作者赛前已有的外部项目，未内置其整套业务。代码有大量 AI 辅助，按实际分工说明。
- **现在没做完什么？** 真实 TTS／OCR 质量、开放式长期自主生活质量、多学校即插即用、任意系统桌面操作、一图生成完整角色差分均不作为本次承诺。书桌操作有范围；可选实验功能不进入主线。
