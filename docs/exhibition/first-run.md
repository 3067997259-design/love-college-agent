# 第二台 Windows：安装到第一句真实聊天

2026-10-18 收尾手册。先完成普通模式的新用户体验，再准备展位。第二台机器的人工结果仍待操作者回报。

## 1. 拿对安装包

本次使用 **v0.1.10** 的 `Love-College-Agent-0.1.10-Setup.exe`，产物位于 `D:\lca-gpt\release\`，固定副本在 `D:\lca-release-safe\v0.1.10\`。复制前核对同目录 `SHA256SUMS.txt` 和 [发布记录](../engineering/release-0.1.10.md) 中的回归与交付状态。

v0.1.10 包含新版 UI、文案和插件中心，以及模型热配置、日记恢复、礼物同意门槛等此前修复；本次补齐旧配置导入、忽略邮件退出上下文、上传即时读取，以及单一校园助手插件。先前测试报告不代替本次修复验收，第二台人工体验仍须实际完成。

可选核对：在 PowerShell 输入 `Get-FileHash -LiteralPath '安装包的完整路径'`。

## 2. 安装与启动

1. 双击安装器。核对来源后，如出现 Windows SmartScreen，选择“更多信息 → 仍要运行”。
2. 选当前用户安装，记住安装目录。应用不需要系统 Node、Python、pnpm 或浏览器。
3. **安装器创建桌面／开始菜单快捷方式，安装结束不自动启动。** 双击 `Love College Agent` 快捷方式；也可打开刚才的安装目录，双击 `LoveCollegeAgent.exe`。
4. 初次应看到“一本空白的书”。若已经出现聊天，说明该电脑已有用户资料；不要删除，先保留并用独立演示入口另开书本。

## 3. 配好聊天

1. 点“翻开”，写昵称。
2. 到“接上模型服务”，点“填写模型连接”。先只配置“日常对话”。
3. 使用你已经选定的服务，填它的接口地址、模型名、API 密钥；模板只是预填，不证明兼容。接口地址不要把 `/chat/completions` 整条请求地址误作 API 根地址。
4. 点“保存”，再点“测试连接”。“已配置”只代表保存；“已经连接”才是这次小请求成功。不要把密钥、配置文件正文或带密钥截图发到聊天／投屏。
5. 模型保存成功即生效，不需要为了聊天重启。继续向导：她的称呼 → 相处方式 → 点家具上色 → “开始吧”。
6. 开发模式保持关闭。向导的“你好”是固定欢迎词，不计真实模型验收。

已有配置可在模型连接区域底部点“导入模型配置”。v0.1.10 已兼容旧文件的附加字段和 BOM。本机预先准备的 `D:\lca-demo-private-20261018\providers-demo.json` 可私下复制到第二台导入，不放进公开卡包；该文件预设记忆/日记和隐私跟随主模型，含邮箱/Rodin 时按界面提示重启。原文件与兼容修复的边界见 [导入记录](../engineering/provider-import-compat-20261018.md)。

第一句建议：

> 桃子你好，我叫〔昵称〕。今天我们第一次见面，你想怎么称呼我？

看到实际回复后，关闭应用再打开，确认这两条消息仍在。再发：

> 请查一下现在的本地时间，再告诉我。

只有任务／工具结果出现且时间合理，才把它记成工具往返成功。不要单凭回复里写了一个时间判断。

## 4. 再补工作能力

“工具与设置 → 模型与声音”：检查“记忆与日记”和“隐私滤芯”的“使用方式”。新安装默认“跟随主模型”；升级时已有独立配置（含旧空占位）保持独立，需要操作者明确切换。

- 记忆与日记跟随：使用日常对话连接；也可选独立模型并保存。当天刚安装没有日记是正常的，完成日切后才写前一天；中断后日记页提供“请她补写”。
- 隐私跟随：**关闭隔离，主模型可以直接处理、看到新邮件和资料原文**；演示只用公开样例。公共文件直接拖入即可。
- 隐私独立：邮件／私密工具走独立滤芯；文件另外用 `/privacy on` 开启。失败即停，不自动退回主模型。切换不会把历史隔离资料自动公开；旧暂存资料需要显式重试。

模型连接和路由立即生效；语音、Rodin、邮箱连接仍按界面提示重启。

邮件只在普通模式使用。配置邮箱连接后重启；文件夹固定为“桃子”，只读未读邮件。公开演示只使用专门准备的演示邮件。Student Hub 属于外部插件，第二台机器没有对应项目／Python／数据库时不会凭空可用；不复制个人数据库来补演示。

校园助手只需安装一个插件：

1. 解压 `LCA-Campus-Assistant-v0.1.0.zip`，或使用演示卡包里的 `campus-assistant` 文件夹。
2. 普通模式打开插件页，安装这个文件夹，核对路径并启用。旧的 `student-hub/mcp.json` 与 `student-hub-candidates` 不再需要组合使用；新版启用后旧两项工具退出聊天工具列表，已有候选与忽略记录保留。
3. 说“检查校园助手是否准备好了”。通过后说“扫描学校更新，读完后把需要我决定的事情放成候选卡”。查看原文并确认需要的事项，再点“导出新确认事项”。扫描仍在进行时可继续查询进度或取消同一次任务。

默认使用本机 `D:\student-hub` 后端。第二台若已有独立安装的后端，按卡包内 `campus-assistant/README.md` 配置路径；源仓库中的说明位于 `plugin-packages/campus-assistant/README.md`。缺少后端或学校登录时，先用公开资料演示文件整理，不把依赖缺失当作“没有校园更新”。插件不含 Python、后端、账号登录和私人数据。

语音、OCR、实时生成礼物均不属于首次成功的前提。

## 5. 卡住时按现象处理

| 现象 | 下一步 |
| --- | --- |
| 安装完找不到程序 | 用桌面／开始菜单快捷方式，或打开安装目录中的 `LoveCollegeAgent.exe` |
| “已配置”但不能聊 | 确认是 v0.1.10；等待保存完成并测试连接；确认没有打开开发模式，保留实际错误分类 |
| 连接失败 | 核对该电脑的网络、服务地址、模型和密钥；保留界面错误分类，不反复改所有槽位 |
| 她不出声 | 默认静音且真实 TTS 尚待验收；文字回复成功已经满足本步 |
| 邮箱在展位模式不可扫描 | 这是现有门禁；评委扫描用独立普通演示档，同学体验用展位档 |
| 拖入扫描 PDF／截图不能整理 | 当前可靠输入是文字层 PDF、UTF-8 文本与 Markdown；换随附公开样例 |
| 旧版整理约 30 秒后报 privacy-unavailable | 升级 v0.1.10；已修复过短总时限与跟随模式错误分类，在资料卡显式重试 |
| 发一个仓库路径却无法探索 | 普通聊天没有任意磁盘遍历工具；上传需要读的文件，心流文件工具仅操作她的书桌 |
| 小窗黑角 | 先用书本继续演示；可在独立启动脚本中使用 `-OpaqueMini` |

人工验收待填写：安装目录、首次打开成功／失败、真实回复成功／失败、重启后聊天保留、第二句工具结果、界面缩放和小窗观感。只报告状态，别附密钥。
