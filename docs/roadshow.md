# 路演与答辩

2026-10-18 巡场前收口。当前可直接照读的三分钟版、操作顺序和答辩卡见 [评委操作卡](exhibition/judges.md)；全校展示见 [展位手册](exhibition/booth-runbook.md)。本次撤去 MC 相关演示。旧稿中的截图整理、privacy 失败改走主模型、清空数据恢复和“永不遗忘”措辞均不再使用。

## 1. 五分钟时间线

巡场不播放完整短片。正式路演仍保留“开场视频 → 现场演示 → 收尾视频 → 现场恢复”的已确认结构；207.5 秒完整母版用于展位，不能直接塞入五分钟。以下是排练目标，开场／收尾剪辑文件未核对到成品前不用占位文件冒充。

| 时间 | 内容 | 条件 |
| --- | --- | --- |
| 0:00–0:10 | 定位句、人物与书本 | “一个能把大学里的事办妥，也能留住共同经历的个人 Agent。” |
| 0:10–0:30 | 开场剪辑 | 现场机先试播；没有核实剪辑成品就用应用开场 |
| 0:30–2:30 | 邮件证据→确认→实际文件；公开资料；专注小窗 | 主线按三分钟操作卡，缩短讲解，不跳过用户确认 |
| 2:30–3:05 | 技术与落地 | 有界执行、来源记忆、主进程与隐私隔离；不要堆模块名 |
| 3:05–3:50 | 收尾剪辑 | 无讲话；与完整动画区分 |
| 3:50–4:35 | 恢复公开演示档、先核对历史，再问一句 | 不清空目录、不把模型措辞当恢复的唯一证据 |
| 4:35–5:00 | 收尾和缓冲 | 真正硬时限；网慢时直接使用已完成结果并说明 |

## 2. 讲稿与现场动作

### 2.1 开场

> 这是桃子，一个面向大学生活的个人 Agent。我们想让她能认真办事，也把与你一起做过的事留在同一本书里。

### 2.2 工作

> 这封是提前准备的演示邮件。她提出候选，我先对照原文核对时间，再确认、导出。这是实际生成的文件。她说完成并不算完成，操作结果和文件才算。

资料演示使用公开文字层 PDF／UTF-8 文本／Markdown，不用通知截图。文件整理交付与邮箱候选是两个入口，不能说拖一份文件就自动写进日程。

### 2.3 技术与落地

- 工作执行有步数、重复调用、取消和预算边界，所有动作有记录。
- 原始事件保存下来，压缩只改模型看到的投影；记忆有来源与纠正链，引用只取她当时看见过的内容。
- 密钥在主进程。原文只去已配置的 privacy 端点，失败停止，不改投普通模型；端点是否在校内按实际配置说明。
- Windows 安装包和本机数据已经存在。接其他学校仍需要适配与认证；不把 MCP 协议兼容说成多学校开箱即用。

### 2.4 过渡

> 记忆会有遗漏，但原来的书页和一起留下的东西，可以由你自己保存。

### 2.5 恢复

完整步骤见 [恢复操作卡](exhibition/judges.md)。只恢复经过核对的公开演示存档，确认一次后等重启。先看原聊天和文件，再让她回忆；不保证每次措辞与回答质量完全一致。

### 2.6 现场依赖

| 项目 | 可用证据 | 现场边界 |
| --- | --- | --- |
| 聊天、privacy、真实邮件 | 已有本机真实请求与邮件到交付证据 | 第二机和现场网络另测；展位模式真实邮箱关闭 |
| 资料、计时、恢复 | 本轮新安装 EXE 定向流程通过 | 服务合成的自动化与真模型质量分开 |
| 语音／OCR | 有代码与合成验收 | 真实服务未验收，不进必经流程 |
| Rodin 礼物 | 历史有一次真实生成 | 有已核实的成品才展示，不临场等待新生成 |
| 短片 | V8 完整中文字幕现场版已有文件 | 第二机完整试播、正式路演短剪仍需实物核对 |

## 3. 落地页

谁用：先服务大学生活中的通知、资料、专注与持续相处。怎么交付：Windows 本地应用、用户自己配置模型、数据可导出。后续：更多校园来源、可靠的角色素材生成和长期自主生活体验。成本只讲现有资源上限；未测出的每日金额不填估计数当实测。

## 4. 答辩卡

见 [六张答辩卡](exhibition/judges.md)。补充：

- 存档含私有证据库且当前不加密；它不是公开角色包。恢复不返还预算，也不结算导出到恢复之间的离线工作。
- computer use 只在隔离的静态书桌预览，系统命令有独立范围与逐次审批；不声称操作任意应用。
- 对话、文件、命令、网页和 MCP 的权限规则各不相同，不能概括成“所有操作每次都弹确认”。
- 与其他助手比较时介绍我们实际展示的流程，不声称别人一定没有记忆／工具能力。
- 来源声明保留已有参考和依赖的记录。撤去游戏演示不意味着抹掉历史参考来源。
- DeepTech 只讲一条能解释清楚的来源／否定／修订问题。合成用例的数字不可外推成真实模型准确率；选择性回滚实验未合入生产。

## 5. 彩排与现场检查

按 [15:00 前检查表](exhibition/judges.md) 执行三次同顺序彩排。预读邮件、预生成礼物、旧页与照片、短番茄、加速时钟（如用）逐项说明。新的真实扫描只在已经授权且配置正确的演示邮箱执行，不把扫描当确认。

片子音量不能压过主讲；独立电脑／档案负责观众体验。不要清空私人书本，不对共享体验者开放个人邮箱／真实旧档。
