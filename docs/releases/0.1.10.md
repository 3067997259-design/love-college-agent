## 主要行为

- providers 导入兼容附加字段与 BOM；模型配置热生效，显式跟随主模型或独立路由。
- 文件上传可在整理请求完成前进入获授权的当前回合，后续按文档 ID 读取。
- 忽略的校园来源退出当前工具、原文与自动事件；来源或权限变化会使生成中的旧回复失效。
- 一体校园助手复用现有提取、校验、确认和本地交付，不要求组合旧两种插件。
- 修复跨回合复用 tool callId 导致当前结果被误删的问题。
- 资料整理总时限调整为 90 秒，并保留无输出超时、取消、预算与准确错误分类。

## 当时的验证范围

类型、lint、77 个单测文件 / 569 项测试通过。源码 Electron 验证一体插件、上传、候选、记忆、礼物、隐私与重启；最终包内 EXE 通过七类原生 / 持久化探针与 39 个场景。

这些模型和校园来源为合成服务。包内运行不等于第二台电脑实际安装 / 升级，health 不等于账号认证，也不证明真实学校扫描或所有真实生成质量。历史真实聊天、privacy 和 IMAP 有独立记录，不自动覆盖此插件的全部路径。
