## 这一版的变化

- **一条时间线。**
  - 番茄提醒、新邮件、她出门回来这些事，和你们的对话进同一个会话；她在忙的时候听到，就在下一步接上。
  - 换项目文件夹不打断当天的对话：另一个项目里的会话会带上今天错过的那几句。
  - 新的一天开头带上前几天的摘要，你说的话会唤起相关记忆。工作回合里你说的决定和理由会记住，代码和工具输出不记。
- **她问你。**
  - 她改用 DSH 自带的提问：一次可以问一到四件事，选项可以带一句说明、可以多选，也可以自己写。
  - 书里的问题卡一件一件往下点，最后一起回答；只问一件时点选项就是回答。专注和安静时等到休息再问。
- **读到的东西什么时候撤下。**
  - 记忆、她的世界、资料状态、旧页和你要看的原文，随这一轮发给她，下一轮撤下。
  - 读过网页、邮件或附件原文的那一轮，写文件、运行命令逐次问你，下一轮撤下原文。重启或改模型设置后照样撤下。
- **上传的文件。** 她能读到你允许主模型处理的资料原文，整理中也能读；1.0.x 里她只拿到回执。
- **失败与额度。**
  - 断流前她说过的话保留为“被打断”。服务器忙或连接中断时自动重试最多 5 次，约 15 秒后才说失败。
  - 她自己开的一轮受自主额度限制；你的回合只在设了上限时受限，否则照记。
- **修正 1.0 起的遗漏。**
  - 开了语音，她的回复现在会读出来。
  - 你发消息时把出门的她叫回来，后台的记忆和日记整理让路。
  - 她自己开的一轮在你专注时失败，失败说明等到休息再出现。
  - 读过旧页印象的那一轮，她的话不进记忆。
  - 恢复存档后，她不再记得被回退掉的对话。
  - 她说话时退出应用，不再弹出 JOURNAL_NOT_WRITABLE 错误框、退不出去。
  - 安装版能解析 PDF 了。1.0.x 的安装包漏了 PDF 解析要的原生模块（`@napi-rs/canvas` 的 Windows 包），PDF 资料一律解析失败；源码运行不受影响。
  - DSH 断连或会话关闭后不再继续发送消息；发送过程中的断连也会被接住，避免主进程异常弹窗和退出挂起。
  - 她问你的问题，你的回答现在真的送到她那里。
- **移除。** 旧心流、书桌命令、预览电脑、网页读取、分身、任务卡，以及 `LCA_DSH=0` 回退和旧执行循环。开发者场景的脚本回复改由本地模型接口交给 DSH；Minecraft 的游戏回合保留自己的小循环。
