## 这一版的变化

- **聊天和写代码在同一个会话里。** 对话与工作由 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（DSH）执行。她在你选的项目文件夹里读写文件、运行命令，工作途中可以随时插话。旧心流保留为回退，启动时设置 `LCA_DSH=0` 即可使用。
- **项目。** 输入框上沿的纸签显示她在哪个文件夹干活。默认是她房间里的书桌；点开可以换回最近的项目，或用系统窗口选一个文件夹。磁盘根目录、系统文件夹和 LCA 自己的数据目录不能当项目。
- **信任。**
  - 系统沙箱在某个文件夹里运行不了命令时，她不会去改文件夹权限，而是直接问你要不要信任这个项目。
  - 信任后命令不走系统沙箱，危险命令仍先问你，LCA 的私人资料始终不碰。
  - 可以随时在纸签菜单里撤回信任。
- **第三方内容。** 她读过网页、MCP 工具结果或邮件、附件原文后，写文件、运行命令和再次联网都要你逐次批准，也不能新建授权；下一轮开始前，这些内容会从她的上下文里撤下。子代理受同样的约束。
- **书本。**
  - 她的话按 Markdown 排版：列表、代码块、表格、引用、行内代码和公式；换行不再被吞掉。
  - 做完的一轮工具活动收成一行"做了 N 步"，点开看每一步；正在做的一轮只露出最近几步。
  - 审批卡点一下就定，不占她的提问次数。
- **记录。** 工具调用的细节留在 DSH 自己的会话日志里；LCA 的日志只记对话、指向 DSH 回合的引用、审批与信任，工具流量不进记忆。
- **安装包。** 随附 npm 发布的 DSH 0.2.1-rc.2 运行时，未修改，只去掉了 LCA 用不到的部分，约 120 MB。每个随附包的第三方声明在安装目录的 `resources/dsh-runtime/THIRD_PARTY_NOTICES.txt`。Electron 固定为 44.7.0（DSH 的原生模块只接受固定的几个版本）。

## 已知限制

- DSH 的 Office 文档转换和语音输入没有随安装包分发。
- 她的自主活动（番茄提醒、邮件、生活）仍走旧循环；记忆看不到工作回合的细节，"今天一起做了什么"暂时记不住。
- Windows 系统沙箱需要给项目文件夹追加权限；文件夹所在磁盘不允许时（实测有的 D 盘根目录就不允许），沙箱里运行不了命令，书里会问你是否信任这个项目。
- 安装器未签名。仓库路径含 `,` 或 `&` 时，打包要输出到干净路径，见 [开发与打包](../deployment.md)。
