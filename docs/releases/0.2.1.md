# v0.2.1

发布日期：2026-10-19。本版是 0.2.0 demo 验收版的热修复，修复“普通聊天里出现旧心流计划清单、没有批准按钮”和“批准后口头开始仍被工具拒绝”两处阻塞。

## 下载与校验

- 安装器：`Love-College-Agent-0.2.1-Setup.exe`，Windows x64，未签名。
- 文件大小、SHA-256、app.asar SHA-256 与构建源码提交：构建后从 `release/build-receipt.json` 补录。

## 本次修复

- **普通回合工具列表**：不再把旧心流的 `update_plan`、`run_javascript`、`run_command` 与旧书桌工具放进普通对话；计划统一走 `task_propose` 和任务卡，看到的是带批准按钮的任务对象，而不是旧计划清单。
- **批准后开始**：点击任务卡“批准”后自动启动一个工作回合（专注中由 D3 续跑接管），不再需要用户再说一句“开始”才能写书桌。
- 其余 D1–D4 行为与 0.2.0 相同。

## 当时的验证范围

- `pnpm typecheck` / `pnpm test` / 合成 Electron 剧本（timeline-safety、attention-flow、handoff-flow、task-object）全部通过。
- 安装版七类探针与启动验证：安装后补录。
- 本版仍是合成模型验收；D5 真实模型验收未完成。

## 已知限制

- 同 0.2.0：旧 `flow.*` 历史脚本保留、跨天恢复在启动时执行一次、任务回合没有逐次命令审批通道、开发者剧本使用放大合成预算。
- 仓库路径含 `,`/`&` 时，打包版与安装器要从干净路径运行；见 [开发与打包](../deployment.md) 的路径提示。

使用见 [开始使用](../getting-started.md)，后续变化见 [CHANGELOG](../../CHANGELOG.md)。
