# v0.2.2

发布日期：2026-10-19。本版修复 0.2.1 验收时发现的“升级后旧心流仍占着普通回合”问题。

## 下载与校验

- 安装器：`Love-College-Agent-0.2.2-Setup.exe`，Windows x64，未签名。
- 文件大小、SHA-256、app.asar SHA-256 与构建源码提交：构建后从 `release/build-receipt.json` 补录。
- 本机安装路径与探针结果：安装后补录。

## 本次修复

- 旧版本遗留且未关闭的心流记录会在启动时被自动关闭（历史保持只读）。
- 此前这条遗留心流会让普通回合一直走旧心流工具列表：没有任务卡、`desk_write` / `run_javascript` 持续 `tool-failed`、口头批准无效，且“计划模式”字样会反复出现。关闭后任务统一走 `task_propose` 任务卡与批准流程。

## 当时的验证范围

- `pnpm typecheck` / `pnpm test` / 合成 Electron 剧本通过。
- 安装版七类探针与启动验证：安装后补录。
- 仍是合成模型验收；D5 真实模型验收未完成。

## 已知限制

- 同 0.2.1。
- 仓库路径含 `,`/`&` 时，打包版与安装器要从干净路径运行；见 [开发与打包](../deployment.md) 的路径提示。
