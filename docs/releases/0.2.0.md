# v0.2.0

发布日期：2026-10-19。本版是“日时间线” demo 验收版（D1–D4），用于本机验收与测试；D5 真实模型验收与维护者长期使用仍未完成。

## 下载与校验

- 安装器：`Love-College-Agent-0.2.0-Setup.exe`，Windows x64，未签名。
- 文件大小、SHA-256、app.asar SHA-256 与构建源码提交：构建后从 `release/build-receipt.json` 补录到本节。
- 构建源码在提交后构建（`trackedDirty=false`）；本机安装包路径为仓库 `release/`，不随源码提交。

## 主要行为

- **D1 任务对象**：任务、计划、批准、专注、步骤、检查点与关闭的事实和投影；对话流展示任务卡。
- **D2 一条时间线与安全**：去掉心流区间过滤；全天固定工具列表，写入按调用时的任务授权判定；`turn/degraded` 降级回合、`context.reveal` 一次性原文、未授权写入拒绝、书桌输出不进记忆；心流面板入口退役，旧记录只读。
- **D3 接收、唤醒与注意力**：运行中的回合接收全部待处理事件，安静/专注节拍只决定事件能否唤起新回合；专注中已批准任务按每段预算续跑（默认 4 回合 / 40k token / 单回 6 步），遇提问、失败或审批即停；注意力调度点统一决定生活作品让位和左页姿势。
- **D4 交班**：专注结束由模型用 `task_handoff` 提交完成项、逐字用户决定、未决与下一步；代码校验引用并附文件/命令/作品证据，失败时写证据兜底；检查点成为请求 B 段；跨天从检查点恢复为待批准任务，旧授权不复活。
- 普通回合固定工具列表包含任务书桌工具与 `task_step`，不再按心流状态切换。

## 当时的验证范围

- `pnpm typecheck` 通过；`pnpm test` 84 个单测文件全部通过。
- 合成 Electron 剧本通过：`test:timeline-safety`（D2）、`test:attention-flow`（D3）、`test:handoff-flow`（D4）；D1 剧本 `test:task-object` 回归通过。
- 包内 EXE 通过 `pnpm test:package --unpacked-only` 的七类原生/持久化探针（结果补录）。
- 以上模型均为合成剧本模型，无真实供应商调用；本机安装验收不等于 D5 真实协议验收。

## 已知限制

- 旧心流 `flow.*` 命令路径仍保留给历史场景脚本，产品界面已不可进入；后续清理。
- 跨天恢复在启动时执行一次；一天内跨零点继续运行要等下次启动。
- 任务回合还没有逐次命令审批通道；D4 交班只收集已有命令回执。
- 开发者剧本会话使用放大的合成预算且不经过资源账本，生产默认值不变。
