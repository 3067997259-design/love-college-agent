# v1.0.1

发布日期：2026-10-20。1.0 之后的第一个小版本：按维护者试用提出的几处打磨，集中在模型设置、新手指引和书本排版。

## 下载与校验

- 安装器：`Love-College-Agent-1.0.1-Setup.exe`，Windows x64，未签名。大小与 SHA-256 见下方构建回执。
- 从 1.0.0 升级：直接运行安装器覆盖安装，数据和连接配置保留；旧的 providers.json 不用改，工作模型默认跟随聊天模型。

## 这一版的变化

- **聊天模型与工作模型。**
  - 设置里多了一张工作模型的卡，默认跟随聊天模型，只配一个照样能用。
  - 两个模型分开时，每一轮由聊天模型开头。她第一次要写文件、改文件、运行命令或派子代理时，这一步交给工作模型重新判断并动手；你的下一句话再回到聊天模型。
  - 工作模型第一次接手时要读一遍当天的上下文，这一次的缓存命中不了。
- **模型设置。**
  - 每张卡显示服务商和模型名：认得的服务商显示名字，其他地址只显示打码后的域名，密钥从不显示。
  - “思考强度”只列出这个模型支持的档位，档位来自 DSH 随附的模型目录。改了从她的下一步生效，不用重启。
  - 服务商模板更新为当前的型号，新增 Google Gemini、Kimi、智谱 GLM。
- **新手指引。**
  - 上色改成你按住拖动去涂，涂到一大半，她拿羽毛笔接过去画完。每涂完一件，右页写一行它在书里管什么。
  - 羽毛笔的笔触起落有了快慢，笔身随方向摆动。修正了隔一会儿再上色时，颜色直接冒出来、看不到笔的问题。
  - 模型连接直接在向导页上填。
  - 设置里“重新体验新手指引”可以从封面再走一遍，不动任何资料。
- **第一次干活。** 输入框上方有几个可以直接点的开头。第一次换到自己的项目时，可以让她只读地熟悉一遍。
- **书本。**
  - 设置改成书里的一页，和其他书签一样翻在右页。
  - 权限请求和你的选择，与她说的话分开排版。
  - 你的长句不再右对齐。

## 验证范围

- `pnpm typecheck`、改动文件的 lint 通过，631 项单测通过。
- DSH bridge 的脚本模型检查 5 个场景通过，不用凭据也不出网：
  - 降级与撤回；
  - 沙箱失败时的信任；
  - 拒绝信任；
  - 聊天模型交给工作模型；
  - 从目录读出思考强度。
- Electron 冒烟：settings、providers、plugins、developer、electron 通过。providers 包括保存聊天模型后不重启就能聊。
- 未通过、与 1.0.0 相同的冒烟：onboarding（最后的上下文断言）、flow-sleep、model-slots、model-routing。它们仍按旧心流的假设写，留给 1.1 清理旧心流时一起改。
- 真实模型：维护者在开发版里试用了新界面。聊天模型与工作模型分开后的真实调用未在本版验证。

## 已知限制

与 [v1.0.0](1.0.0.md) 相同，另有：

- 子代理沿用派它那一步的模型和思考强度，不单独设置。
- 只有思考强度能在干活途中改；换模型或换连接仍要等她空下来。
