# 连续协作者：自动验收与世界状态表达

本批落实无需长期人工使用的验收计划：修正世界引用，复用现有工作／记忆／恢复关卡，增加正常产品的世界状态场景、独立 PostgreSQL 环境关卡和下一批真实服务的可审阅场景。旧 `1.2.0-continuity.1` 包和用户正在试用的 profile 保留；源码改动不会自动进入已打开的旧包。

## 产品改动

出行的 `item`、`acquiredAtMs` 在底层记录中属于预期物品和计划获取时刻。旧世界引用直接传这些字段，容易被当成已完成事实。主进程现在分别投影未出发、外出中、已返回／提前返回和取消的出行，用明确状态说明及带时区时间表达；只有实际物品列表支持“带回物”。计划时间已过不能推导已经出发，当前位置在房间也不能证明刚刚返回。

返回通知也通过同一投影，防止聊天引用已修复、通知仍带歧义。持久化 schema、生活调度、日记材料／解锁、renderer 接口均未改变，无数据迁移。撤回本批产品提交即可回到旧投影。

世界引用仍只带最近三次出行和最近三件物品，并明确标注覆盖范围及总物品数。生活作品只带既有元数据，不加入作品正文或日记原文。

## 可重复入口

- `pnpm test:continuity`：同一源码指纹的 22 个顺序任务；只构建一次，再依次跑相关产品场景。新增世界引用、生活作品普通入口和隔离 PostgreSQL 环境检查。T1–T16 审计只能读取本次结果。
- `pnpm test:continuity:world`：先构建；以六个独立普通模式 profile，经真实 DSH 到本地合成 HTTP，核对模型实际收到的世界引用。状态包括计划、逾期未出发、外出中、已返回、空手提前返回和取消。它不验证真实模型表达质量。
- `pnpm test:continuity:postgres`：仅使用本地已有的 `pgvector/pgvector:pg16` 镜像（可由 `LCA_TEST_PGVECTOR_IMAGE` 指定），记录实际 image ID，创建唯一容器和环回随机端口。执行原五项 SQL／并发测试及一次停库、重开、删除后重投测试。结束停止本次容器并保留数据供对账，不碰已有数据库；无 Docker 或无镜像明确记 `unavailable`，不冒充通过。
- `pnpm test:continuity:prepare-live <本次候选报告目录>`：核对已通过的离线报告及源码，冻结三批真实场景、证据哈希和额度建议。不读取连接配置，不调用模型；回执使用独占创建，不能覆盖旧授权请求。

六个世界夹具的金标准独立保存在测试数据中。聊天会按既有规则让正在外出的角色提前回来，所以 `away` 产品场景预期为 `cut_short`；投影单测另覆盖真正的外出中状态。测试按任务终态和工具屏障推进，不用固定等待当作成功。跨日／周月沿用 ManualClock，报告为模拟时间。

原 90 条检索样本与 24 条故事保持不变。本批增加 90 条查询的固定哈希向量回放，对照迁入算法与固定的上游算法是否等价；这只是迁移一致性证据，不是语义检索或完整回答质量评分。向量生成不使用相关性标签或预期排序。

## 真实服务批次

机器可读清单为 `scripts/continuity-live-plan.json`。离线阶段冻结三批额度建议；随后用户单独授权世界表达批次，实际执行及首次失败结果见[世界表达真实复测](continuity-world-live-20261101.md)。工作和记忆批次尚未授权；此前 8 次／128,000 单位授权不延续。

| 批次 | 场景 | 最大模型请求 | 最大预留单位 | 其中自主额度 |
| --- | --- | ---: | ---: | ---: |
| 世界表达 | 六种状态逐条核对自然回答 | 12 | 256,000 | 0 |
| 工作 | 阻塞时闲聊、修改要求、实际交付、立即追问、多任务停止、重启继续 | 48 | 1,048,576 | 0 |
| 记忆 | 记住／审阅、召回、更正、压缩、重启、忘记、非空恢复 | 32 | 1,048,576 | 262,144 |

这些是按每个用户回合可能产生工具往返、上下文增长及维护请求留出的硬上限建议，不是实际用量预测或账单金额。自主额度包含在总额内。记忆批另限 embedding 24 次、累计输入 200,000 字符，需独立配置并授权。世界批次运行器已接入并本地预跑；工作、记忆运行器仍需按范围接线，清单准备完成不代表真实场景已经执行。

逐批执行，首次失败停止并对账，不自动抽样到成功。不以关键词匹配单独判断回答正确，由 agent 对合成输入的回答与状态逐条审阅，无法确定则记不确定；不新增付费裁判模型。完整 90＋24 质量／成本矩阵、实际安装升级、第二台机器和长期体验另列验收，不由本批结果代替。
