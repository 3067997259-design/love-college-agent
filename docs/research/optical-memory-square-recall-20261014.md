# 光学记忆：方页回忆复查

日期：2026-10-14。状态：用户同意的一轮小复查已完成，12 次主模型请求、0 次新增 GPU 解码。复用 [先导试验](optical-memory-forgetting-pilot-20261014.md) 已有纸桥方页四档输出；未改提示词、原文、真值或历史结果，未实现业务代码。

## 1. 结论与赛前安排

**方页让共同经历的主线保留得更好，光学文本也比这份纯摘要多保留了一些正确细节；直接解码后的回忆仍会确定地说错，尚不能称为可靠的人类式遗忘。**

Large、Base、Small 都答对七项精确细节中的六项，署名稳定误读。Tiny 仍记得折纸桥、解决下弯、留下折痕作为“慢慢弄懂的证据”，没有重现长方页的“纸桥有内心”等错误情感主线；但编号与署名被确定替换，还把计时句的误读当成了付款经历。

四档更像“多数细节保持，然后部分读错或丢失”，没有看到置信程度随着退化明显下降。**建议赛前扩样在这里收口**，不自动追加重要性／重复次数实验。项目默认的文字分层记忆保持原设计，光学继续作为待验证的可选方向；若赛中有余力接入，只能按设计中的模糊印象边界处理，具体事实仍回查她当时可见的原文。本轮没有实现这项守卫。

这份证据支持继续关注光学的体验价值，但尚不能说明它比经过合理设计的文字记忆更像人。稳定主线、保留零碎细节以及能随退化承认模糊，仍需分别验证。

四档都能说出这次共同经历的六类主要语义：想做什么、遇到的问题、三角支撑的办法、分工、试验成功，以及为什么留下作品。Tiny 在回查前未说出三十秒这个限定，保留的是成功托住三颗弹珠的结果轮廓；主线保留不等于逐字逐项完整。

Tiny 的三项正确是 2027-05-14、19:35、照片未拍未发送。它确定给出 **PDF-074**（原文 PB-074）、**肖岑**（原文舟芩）。它只知道“纸张是浅灰色”，并明确说没有区分底板与桥面颜色，所以底板颜色只计部分支持，米白桥面未知；不能因为提到了浅灰色就算两种材料归属都正确。

Tiny 还在付款追问中确定说出 **“给哥哥交了三十块”**。可沿解码追溯到原文“用桌上的小计时器等了三十秒”的误读，是无依据的具体收款人／金额添加，单列记录。上一轮“未记录／未发生”的付款探针混杂仍未修复，本轮不把该探针计入七项正确率，也不借它证明不存在任何交易。

无答案线索让模型讲出当前材料中还在的细节，没有恢复 Tiny 被改错的编号、署名或丢失的材料颜色；并把未在自由回忆中说出的错误付款引了出来。**线索增加回答内容，不保证增加真实回忆。**

## 4. 相对摘要多留下了什么，原文回查能做什么

短日摘要能回答编号与未完成状态。方页 Large／Base／Small 还答对了日期、时间及两种颜色，确实比这份摘要多留下四个精确字段；Tiny 额外保留日期、时间，却失去正确编号并引入错误署名与付款内容。

这是相对**这份短摘要**的材料保留增益，不是光学在相同信息量下的独有优势。摘要较短，光学输出较长；尚无“同数量正确细节”的文字对照，也不能把更多输入信息带来的收益称为人类式遗忘。上一轮 B 候选只保住与摘要相同的字段，仍是不同机制的历史观察。

四个分支重读原文后，28 个选定精确字段全部正确；Tiny 的错误编号、署名和付款说法被替换。提示只要求更新，回答没有显式逐条承认先前错误。原文回查的效果与无答案线索分开记录，未测试实际检索、数据库或跨会话恢复。

选定字段正确也不保证整个回答没有新增：Base 回查回答仍加了“拿废纸试折”，原文没说明是废纸。这个小添加单列在语义注释中，没有用 28/28 掩盖。
