# 1.2 P5：普通委派、团队与左页协作面板

2026-10-24。按用户批准的 [P5 设计](v1.2-p5-collaboration-design-20261023.md)实施，承接 [1.2 计划](v1.2-development-plan-20261023.md)。本批实现功能和安全边界；全房间构图、小桃子位置和镜头切换仍等用户在场共同调整，没有生成或替换美术资产。

## 实现

- **包外共存。** LCA patch 只装配随附的 Team service，保留普通 `subagent/subagent_fork`。`list_agents/send_message/interrupt_agent` 各只有一个 LCA 适配，根据不透明目标和真实父子 / Team 关系调用已有服务。Team 创建、等待和共享任务也复用公开服务；没有修改 DSH npm 包、版本、锁文件或执行循环。
- **模型选择规则。** 稳定 system-prompt 段和工具说明进入实际请求：独立交付用普通委派，需要稳定责任、同伴通信、共同领取和依赖时用 Team；先查看已有成员，优先续用合适身份。主角色可同时派独立助手，普通助手不因此成为 Team 成员。
- **容量如实反馈。** 名册默认 8 位，创建失败仍占位，停止不会释放。两种成员共享默认 8 个运行容量，驻留空闲与正在工作不是同一个计数；公开服务不能精确观察当前驻留数，投影用 null 表示未知。满额返回原因与续用建议，不偷偷换根会话或扩大限额。
- **左页功能面板。** 左下“协作”展开成员、模式、任务、活动、等待批准 / 新指令、运行终态、允许展示的末次结果、用量及共享任务。支持新指令、单成员停止、整组停止、主角色领取 / 释放 / 完成 / 重开任务。共用原书页样式，右页对话和审批可达。
- **事实与接受分开。** 消息或中断 accepted 只是回执；成员终态取 DSH `turn/end`。`interrupted` 映射为已中止，只有明确 completed 才记已结束；未知结束类型保持 unknown。输入 / 输出 token 来自实际 DSH usage，预留单位来自 LCA 每步放行，二者不相互冒充。

共享任务的 revision、owner、依赖和写入范围提示仍属于 DSH。写入范围不是文件锁，完成状态也不替代产物核验。任务操作按 task revision 比较更新；成员消息和停止按当前控制版本核对；整组停止按根身份核对，不因主角色普通活动变化而失效。

## 安全与恢复

`dsh/lca-bridge/collaboration-state.js` 把来源租约、成员结果 / 用量和操作回执追加到根会话投影，任务本体仍在 DSH 的任务事件里。成员标签保留创建时的来源租约；任务状态或版本更新保留旧来源并合并新来源，不把旧内容重新标为干净。更新完成时重新读取最新租约，迟到更新不能回退 revision 或覆盖并发成员的来源限制。退役的任务标题、描述、范围、警告及 owner 显示名在模型读出口隐藏。错误只返回闭合错误码，不附带可能引用旧原文的上游异常。

renderer 只收到有界投影：没有 cwd、会话原文、工具参数、内部推理或凭据。成员有外部来源时收起结果原文；普通成员转述也按 member 来源处理，因此一些续派后的结果只显示状态，由主角色交付。它不是任意查看子会话的入口，也不向自动记忆抽取补交成员内容。

P2 的保守边界继续有效：新的根 followup 撤回旧成员授权，主角色单纯结束不取消成员。单成员停止额外保存收件截止序号，撤销本成员待批准操作；停止前已发布的消息即使迟到、续派或冷恢复，也不能重新生效。无法核对来源或持久投影损坏时拒绝继续。原文仍留在原始日志中，退役只改变模型投影。

操作带 requestId，先持久记录 pending，再执行并写回执。断连后显示 unknown，阻止重复发送；显式“刷新核对”可重连并读取原回执，不重放原操作或旧批准。旧 runtime / 项目 / 成员地址不能执行新操作。当前实现保留完整操作记录，未增加自动裁剪策略。

自主事件的 root 与所有成员共用六步上限和自主预算桶；主角色先闲置不会让成员切换成用户工作预算。用户明确给成员发送新指令后才解除自主步数上限，发送前就更新预算归属。主角色闲置时成员仍走 P2 审批。成员工作期间项目切换及扩展运行时维护受 busy 保护；熄灯、睡眠和停止沿用整组取消。
