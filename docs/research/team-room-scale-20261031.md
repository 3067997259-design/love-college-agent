# 团队远景：统一尺寸与重排位置（2026-10-31）

用户指出团队远景合成后很乱：小桃子之间尺寸不一致，整体布局不好看，并把它定为 1.2 进入测试和发布前的最后一项。本轮查明原因，改为按头部大小和远近统一尺寸、按房间实际空地重排位置；茶桌四张改画“站在小凳上”。同日下午用户交回站凳子四张与两台电脑，接入试摆后用户采用，见[下文](#站凳子试摆与采用)。没有打包、没有请求真实模型。

## 原因

在 `team-working` 场景、房间按 600 像素计时测得：

| 原因 | 实测 | 影响 |
| --- | --- | --- |
| 尺寸按整张图的高度给，每个位置单独手调 | 头约占站姿图的 40%，茶桌前排两张坐姿图占 61–62%；书架位离镜头最远，图高却给到房间的 26–29%，最靠前的地毯位只给 24% | 同屏头高 56–116 像素；茶桌前两位（102、116）比大桃子自己的头（约 74）还大 |
| 茶桌坐姿图和房间的茶桌比例对不上 | 电脑画在腿上；按前排小桃子的大小，茶桌约有她们身高的 2/3 | 只有把这四张放大到两倍多，电脑才够到桌面；统一尺寸后她们缩到桌面以下 |
| 位置和家具冲突 | 书架两个位置的脚落在茶桌桌面范围内（房间图里茶桌几乎贴着书架）；14 个位置里 9 个挤在茶桌和书架一带；“门口”位在左下角边缘，房间图里没有门 | 人像站在桌子里，左下角叠成一团 |
| 画风未统一（已知、延后） | 小桃子线条更粗、发色更艳 | 贴纸感；本轮不处理 |
| 换姿势左右跳 | 图按整张居中，几张图的脚偏离中心 10–15%（进门 .655、够书架 .61） | 换姿势时横移 |

对照图（左为原合成、右为只统一尺寸）为本机临时渲染，未入库。

## 改动

- **一个尺寸规则。** [teamScene.ts](../../src/renderer/src/book/team/teamScene.ts) 的 `headAt(y)`：头高只取决于脚在画面中的高度。房间图的透视很弱：茶桌四条腿的桌高从脚在 .807 处的 .128 到 .947 处的 .152，椅子相同，只有书桌一条腿不合群；拟合得等效地平线约 y = .06。前排头高定为房间的 50/600，最远的位置站姿仍约 84 像素（美术规格要求约 80 像素可辨认）。
- **按头部量图。** 新工具 [measure-team-sprites.mjs](../../art/tools/measure-team-sprites.mjs) 量出每张图的发型外框、脚底中心和底边，写入 `team/sprite-metrics.json`（`--check` 只核对不写）。渲染按头框换算图高、按脚底中心对齐，点击范围也改用头框，去掉了逐张手调的 CSS。单测核对尺寸表与图片哈希一致。
- **重排位置。** 茶桌：远侧两位、左右两端各一位；书架：书架与茶桌之间那条地面；书桌：她脚边与椅前；需要你处理的（等批准、出错）上前排右侧的阳光地板；休息在茶桌前；新来的从画面下缘走入。
- **茶桌占位。** 站凳子的图到位前，茶桌用读便条的站姿代替：桌面挡得住凳子的远侧两位垫高到凳子高度，两端站在地上。
- **停用旧坐姿。** 四张 `mini-v2-table-*` 不再使用、不再打包，文件和来源记录保留。换姿势不再对高度做 1.2 秒过渡，避免新图先按旧尺寸出现再缩放。

## 站凳子试摆与采用

用户按[提示词](../../art/prompts/2026-10-31-team-stool-standing.md)经 Codex 内置 imagegen 出图（第二版），四位站在凳上的小桃子和两台电脑已切成透明图；原图、提示词与哈希在本机 `art/retouch/2026-10-31-team-stool-standing/`。下午接入书页试摆，用户看过合成对比后采用。

| 问题 | 实测 | 处理 |
| --- | --- | --- |
| 手够不到桌面 | 按统一尺寸，双手离凳脚 1.47–1.57 个头高，桌面在 1.85；新图比现有 12 张矮胖（站高约 2.2 个头，现有约 2.4） | 只拉长凳腿：从凳面下第一行只有凳腿的行到最底行整段重采样，加 63–91 行，凳高约 1.05 个头，手落在 1.90；人物一个像素未改 |
| 远侧左位挡住书架 | 凳子把远侧两位垫高后，左位的头正好叠在书架前帮手的头前面，右位与书架另一位上下相接 | 茶桌改三座：远侧一位（偏右）、两端各一位；远侧左半留空，书架两位移到那段书架前。远侧左位那张（`stool-back-left`）未用，只留在本机候选目录，未入库 |
| 电脑放哪 | 两台电脑与人画在同一张原图、同一比例 | 按同图入库小桃子的平均头高（201 像素）换算大小，底边中点放在桌面上；远侧电脑挡住她的手，两端手在键盘上；右端电脑镜像（只镜像道具） |
| 左端在桌子后面 | 她站在桌子左端外侧，桌面挡住下半身，手却要搭在桌上的电脑上 | 同一张图在桌面和电脑之上再画一遍，裁到手的下沿 |
| 其他姿势 | 远侧与左端的凳子被桌面挡住，思考、受阻等姿势沿用垫高；左端垫高后鞋尖会从桌下空隙露出一点 | 垫高时裁掉鞋、不画地面阴影；右端凳子露在外面，不打字时她站回地上，凳子随打字图一起消失 |

测量工具加了道具分支（只量大小与底边，按同图头高换算），并从 manifest 读人工量取的双手最低行（自动识别会把开衫当成手）。单测新增：坐席的手落到桌面高度、帮手站在桌脚之外、电脑落在桌面内、遮挡层次、打字与其他姿势的选图和垫高。

| 检查 | 结果 |
| --- | --- |
| `pnpm typecheck`、`pnpm lint` | 通过 |
| 单元测试 | 92 个文件、680 项通过 |
| `node scripts/team-room-preview.mjs` | 8 项通过，另核对三座三台电脑、左端多画的一层、各场景电脑与人物图均已加载；仅合成数据 |
| 截图 | 四个团队场景，加一个临时场景（两端不打字，看完即删）：手在电脑上，凳脚落地，远侧凳子在桌下空隙里可见，书架两位不再被挡 |
