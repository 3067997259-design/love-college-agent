# 团队远景：统一尺寸与重排位置（2026-10-31）

用户指出团队远景合成后很乱：小桃子之间尺寸不一致，整体布局不好看，并把它定为 1.2 进入测试和发布前的最后一项。本轮查明原因，改为按头部大小和远近统一尺寸、按房间实际空地重排位置；茶桌四张改画“站在小凳上”，提示词已备好，新图到位前用占位。没有生成新图、没有打包、没有请求真实模型。

## 原因

在 `team-working` 场景、房间按 600 像素计时测得：

| 原因 | 实测 | 影响 |
| --- | --- | --- |
| 尺寸按整张图的高度给，每个位置单独手调 | 头约占站姿图的 40%，茶桌前排两张坐姿图占 61–62%；书架位离镜头最远，图高却给到房间的 26–29%，最靠前的地毯位只给 24% | 同屏头高 56–116 像素；茶桌前两位（102、116）比大桃子自己的头（约 74）还大 |
| 茶桌坐姿图和房间的茶桌比例对不上 | 电脑画在腿上；按前排小桃子的大小，茶桌约有她们身高的 2/3 | 只有把这四张放大到两倍多，电脑才够到桌面；统一尺寸后她们缩到桌面以下 |
| 位置和家具冲突 | 书架两个位置的脚落在茶桌桌面范围内（房间图里茶桌几乎贴着书架）；14 个位置里 9 个挤在茶桌和书架一带；“门口”位在左下角边缘，房间图里没有门 | 人像站在桌子里，左下角叠成一团 |
| 画风未统一（已知、延后） | 小桃子线条更粗、发色更艳 | 贴纸感；本轮不处理 |
| 换姿势左右跳 | 图按整张居中，几张图的脚偏离中心 10–15%（进门 .655、够书架 .61） | 换姿势时横移 |

对照图（左为原合成、右为只统一尺寸）为本机临时渲染，未入库。

## 改动

- **一个尺寸规则。** [teamScene.ts](../../src/renderer/src/book/team/teamScene.ts) 的 `headAt(y)`：头高只取决于脚在画面中的高度。房间图的透视很弱：茶桌四条腿的桌高从脚在 .807 处的 .128 到 .947 处的 .152，椅子相同，只有书桌一条腿不合群；拟合得等效地平线约 y = .06。前排头高定为房间的 50/600，最远的位置站姿仍约 84 像素（美术规格要求约 80 像素可辨认）。
- **按头部量图。** 新工具 [measure-team-sprites.mjs](../../art/tools/measure-team-sprites.mjs) 量出每张图的发型外框、脚底中心和底边，写入 `team/sprite-metrics.json`（`--check` 只核对不写）。渲染按头框换算图高、按脚底中心对齐，点击范围也改用头框，去掉了逐张手调的 CSS。单测核对尺寸表与图片哈希一致。
- **重排位置。** 茶桌：远侧两位、左右两端各一位；书架：书架与茶桌之间那条地面；书桌：她脚边与椅前；需要你处理的（等批准、出错）上前排右侧的阳光地板；休息在茶桌前；新来的从画面下缘走入。
- **茶桌占位。** 站凳子的图到位前，茶桌用读便条的站姿代替：桌面挡得住凳子的远侧两位垫高到凳子高度，两端站在地上。
- **停用旧坐姿。** 四张 `mini-v2-table-*` 不再使用、不再打包，文件和来源记录保留。换姿势不再对高度做 1.2 秒过渡，避免新图先按旧尺寸出现再缩放。
