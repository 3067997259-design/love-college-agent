# 世界状态表达：首批普通产品真实复测

2026-11-01。用户在离线及包内验收后另行授权：六种世界状态、最多 12 次模型请求、256,000 预留单位、零自主额度，首次失败停止。这不是此前 8 次 provider 探针授权的延续。

## 实际结果

固定 `1.2.0-continuity.2` 包，在五个独立普通模式 profile 发出相同的自然问题：“今天去海边了吗？带回东西了吗？”原始状态由关闭后的合成日志夹具准备，重新启动后通过正常 `message.send`、DSH 和保存的 chat 连接完成回答；没有向模型提供答案金标准。前台提问前后的状态以实际收到的引用为准。

| 场景 | 结果 | HTTP 请求耗时 |
| --- | --- | ---: |
| 尚未出发 | 正式语义审阅通过，明确“还没动身”、没有带回物 | 17.240 秒 |
| 计划返回时间已过，但仍未出发 | 正式通过，明确“只停在计划上，一直没动身” | 24.819 秒 |
| 初始外出中，产品接线后提前返回 | 正式通过，回答提前回来、没有带回物 | 29.542 秒 |
| 已完成出行且实际取得贝壳 | 正式通过，回答九点多出门、已经回来、贝壳放在书桌上 | 5.027 秒 |
| 提前返回且空手 | 产品日志记模型成功及回合 completed；事后只读审阅回答正确，但网关未确认响应成功，不能记整例正式通过 | 17.425 秒 |
| 已取消计划 | 未执行，遵守首次失败停止 |

实际 5 次请求，均收到 HTTP 200；独立账本预留 **80,000 / 256,000** 单位，自主 **0**。供应商报告输入合计 65,693 token、输出 184 token；时间为网关完整请求耗时，不是首 token。没有发生 45 秒超时，没有重试，也没有动用剩余额度继续第六例。上述四个正式正例和第五个事后正例不能代表六例整批通过，更不代表长期稳定性或随机 A/B 因果结论。

第五例回答为“去了，不过只待了一小会儿，提前回来了。这次没带东西回来，两手空空。”对应引用为 `cut_short`、房间、实际物品数 0。原失败 `report.json` 保留；另写 `early-return-reconciliation.json`，不覆盖原判定。

## 执行与额度边界

`node scripts/probe-world-live.mjs` 使用指定包，需 `LCA_TEST_EXECUTABLE`、全新的 `LCA_WORLD_PROBE_RUN`，真实执行另需 `LCA_REAL_MODEL=1` 和获授权的 `LCA_PROVIDERS_FILE`。已有 `run.json` 拒绝覆盖。实际配置只在独立 Electron 主进程读取；原密钥不进入 runner、renderer 或报告。测试 profile 仅取得环回网关的临时令牌；保持 chat 的模型、思考档位及手工能力声明，其他槽位由网关阻断，防止自主调用消耗额度。

每次真实转发必须匹配该 profile 已发布的 `model/attempt started` 准入回执，按其 `reservedTokens` 预留；同一回执只能使用一次。网关还独立限制 12 次实际请求和 256,000 单位，供应商适配器重试不能绕过。修复后的整批计数独立于每日账本换日，避免批次跨日重新获得额度。每例答完且网关完成收流后暂停，由 agent 对照引用记录审阅语义并写独占 review 回执；失败即停止，审阅不另调用付费裁判模型。

`--self-test` 只访问本地假服务，不读取真实配置；验证普通产品接线、重复准入拒绝、超额度拒绝、零自主拒绝及第 13 次准入拒绝。自检中的最后六个计数是无网络的额度边界测试，不能计作真实模型调用。

## 探针问题与离线修复

原真实批次仅记录网关响应未成功，未保存原始网络尾帧或细分错误码，无法唯一确定第五例失败原因。后续离线排查发现一个可复现的同类缺陷：完整 `data: [DONE]` 直接位于 EOF、没有结尾空行时，产品成功而旧网关报 `INCOMPLETE_RESPONSE`。已修复为解析完整 EOF 帧；残缺 JSON、无结束证据和传输失败仍拒绝。四项定向回归验证正常／分段 CRLF／EOF 用量／残缺流。

另一次本地全流程预跑出现未分类的准入失败，原报告保留。增加拒绝原因诊断，并修正并发日志读取边界：只使用换行结束的已发布记录，不把正在追加的尾行当作完整准入；三项定向测试验证部分尾行、未发布记录和真实损坏。不能将后续通过直接解释为原未分类失败已得到唯一因果定位。

收尾另补充产品回合完成与网关收流完成的同步条件，防止过早关闭实例；增加三项批次额度回归，验证换日仍限额、重复／第十三次拒绝及账本拒绝不消费回执。上述定向单测共 10 项通过，主进程类型（含探针）和定向 lint 通过。这与旧候选的 895 项全量测试分开报告。

最终本地预跑 `world-selftest-20261101-batch-guard` 六例全部通过，含六个本地 HTTP 请求和六个无网络的限额测试准入；没有真实请求，没有意外拒绝。它验证修复后接线及保护条件，不能替代真实模型复测。

这些改动仅在验收网关与测试代码中，新包未改动。修复后的真实复测没有执行，原批次不因离线修复而转为通过。

原始真实证据位于 `D:\lca-continuity-candidate-20261101\profiles\world-live-20261101-1`；实际运行的源码、编译网关、夹具及哈希已冻结。离线复现和最终自检分别保留在同级 `world-selftest-20261101-*` 目录。汇总、文件哈希与最终自检结果见[结构化证据](evidence/continuity-world-live-20261101.json)。
