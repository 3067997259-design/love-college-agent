## 行为

- 保留现有“工作中 / 安静 / 休息 / 熄灯”入口，补充每项说明。“工作中”使下一次用户新回合直接选择 work；安静 / 休息选择 chat。选择本身不发模型请求；工作途中插话沿用当前回合。
- 主模型可输出完整、严格的 `lca_state` JSON 信封申请状态切换。动态提示词给出当前门牌、执行角色和本次凭据，以及何时交接、工具与团队职责、不要假报完成的指导。
- main 校验根会话、用户回合、凭据、状态和取消情况，再走既有 `mode.set`。成功后才在书页显示 reply。chat → work 每轮最多续步一次，由 DSH 自己处理；不另开循环、不重写用户任务、不重置来源限制或扩大权限。
- 只有 work / quiet / rest 三种值；模型不能开关灯、改变睡眠或信任，也不能提前结束正在运行或暂停的番茄专注。每轮最多接受两次实际状态变化。用户新消息、手动改状态和作用域变化会使旧凭据失效。
- 原始 DSH 记录保留。控制 JSON 不进入书页或 LCA 普通记忆；无效、截断或被拒绝的状态指令不重试、不显示虚假的开工回应。
- 原有工具触发交接继续作为兼容路径。此次没有新增模型能力手动声明，也没有证明当前聊天供应商会遵守此 JSON 协议。
