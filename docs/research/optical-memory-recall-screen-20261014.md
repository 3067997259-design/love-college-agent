# 光学回忆小筛：误读、引用纠错与记忆回写

日期：2026-10-14。状态：独立模型能力实验完成，应用记忆未实现／未验收。用户授权先复用已有解码结果做小规模筛查，查看结果后再决定正式对照；本轮没有扩到新故事或文字摘要实验。

## 1. 结果与判断

**光学误读会进入主模型的回答。明确标为模糊印象时，本轮模型能表达不确定；省略来源类型后，同样的误读变成确定断言。引用原文能纠正，但错印象仍会进入记忆候选，事实资格必须沿数据流保留并由代码检查。**

- 4 组无关题材的虚构材料，12 个分支。实际 **53 次 HTTP 请求**：1 次连通、50 次完整质量调用、2 次生成触顶失败。两次失败保留，补测后所有分支完成；没有新增 GPU 推理。
- 6 个标为 `optical_impression` 的分支出现 **8 次错误印象复述、0 次错误确定断言**，并且所有具体事实回答均保留不确定性。2 个省略来源类型的诊断分支出现 **6 次错误确定断言**。
- 引用当时可见的原文后，**14 次错误复述全部纠正**；全体 82 项问答与原文相符，包含 12 项“原文未记载”的问题，未补造仪器、作者、日期或批准人。
- 引用前，**14 条错误内容进入记忆候选**，均为 `eligible_as_fact: false`。其中 **7 条仍被模型标成 `kind: fact`**。因此不能只看 `kind` 来决定能否按事实召回。
- 引用后，错误候选都有有效的取代引用；未发现未被取代的旧错误候选，也未发现新的有效错误事实候选。
- 两组错误回答各重复 3 次，放在 2 个模拟会话中，再提取：6 条错误印象仍保留，但没有因此取得事实资格。这里验证的是提示词约束下的候选输出，**没有运行真实数据库晋升或跨天进程**。

这些结果支持继续验证“印象 → 回查 → 纠正”的路线。光学方案相对文字摘要的收益、自然回忆质感和实际长期可靠性，本轮均没有比较。

## 3. 四步流程与重复诊断

1. **回忆**：只给本分支的原文或现有解码文本，以及相同问题。题目覆盖精确字段、修订、是否已执行和未记载信息。光学分支明确标为印象，具体细节要请求原文；未标来源分支是省略元数据的诊断，不是推荐产品行为。
2. **引用前提取**：把可见问答和相应来源交给独立整理请求，输出记忆候选，查看错误是否再进入候选、是否被赋予事实资格。
3. **引用回忆**：提供同一原文窗口、固定日摘要和周摘要，再回答同一组问题。原文只来自当时可见内容；日／周摘要由实验准备时人工写定，仅用于引用阶段，不构成文字摘要对照组。短页回读整页；密集页仅取记录01—03、记录18及结尾。
4. **引用后提取**：连同已有候选一起整理，查看新事实、来源与 `supersedes`。评分同时检查旧错误是否被取代，不能只因新数组里没出现错误就宣称它已消失。

随后对两组未标来源的初次回答做 **3 次原样复述、2 个模拟会话标签** 的提取。用户消息只问回忆，没有确认这些错误；最终来源仍是同一解码页。重复次数不被当成独立事实证据。

原文、问题、答案表与初始方案在请求前保存并固定 SHA-256。运行器对答案表做文件哈希校验，**不解析答案表、也不向模型注入标准答案**；评分器在响应存在后才解析答案表。光学初次请求不含对应可见原文或答案表；原文仅在原文对照与引用步骤提供。

一次具体表现：同一 Tiny 页带印象标记时回答“最终日期疑似为2027-11-08……需请求可见原文”；省略来源类型后回答“记录载明的最终日期为2027-11-08”。引用后两组均恢复成 2027-11-06，并明确纠正日期、负责人和房间。

记忆候选有一个尤其需要保留的反例：Large 标识符分支把错误序列保存成 `kind: fact`，但同时标 `epistemic_status: uncertain`、`eligible_as_fact: false`。另外两组诊断各有 3 条同类错误候选。**本轮有效事实候选没有污染，候选文本里仍有错误；这两个结果不能合并成“错误没有被记住”。**

评分先用规范值比较，再审查实际措辞、来源和取代关系。日期规范化不改变日期；标识符区分大小写和 O／0／I／l。人工确认“没有同意公开资料”“未确认同意”等保守否定与答案兼容，“未写明”对应“未记载”，“通知仍未发送”“转移尚未执行”保留否定。这些不算事实错误；“公开数据”与“公开摘要”仍按不同范围处理。标准答案和原响应没有改写。

## 6. 对设计的建议与下一步

以下是本轮发现对应的建议，不是已实现或已确认的新机制：

1. **来源等级贯穿解码、回答、总结、日记和再次提取。** 不能只在第一轮告诉她“这是印象”，以后把她的复述当成新的用户事实。事实资格最终由代码核对来源链决定，不能让模型单方面授予。本轮 `eligible_as_fact` 等字段只是实验观察接口，不是生产守卫验收。
2. **事实资格与事实／经历类型分开。** `kind: fact` 不足以证明可信；普通 `unreviewed` 也未必能区分原文候选与光学错印象。未核实印象可以保留，但其召回方式、措辞和可用动作应保留边界。
3. **访问次数可以增加重要性，不能改变来源等级。** 三次访问、两次会话可用于决定长期保留，不能将同源复述变成新证据。原文纠正后保留历史与取代关系，旧印象不能继续作为现行事实。
4. **正式对照再比较光学收益。** 建议先把以上条件列成明确契约，再用少量共同经历比较原文、日总结、Large 与 Small：事件主线、过度不确定、自然阅读体验、主模型实际 token 与回忆延迟。这轮不继续自动扩样。

本轮能够说明显式规则下的回答与候选生成行为。还没有验证生产提示词、真实工具回读、数据库筛选／晋升、日记生成、重启与跨天、自然触发回忆、任意模型迁移、角色口吻或摘要方案优势。
