# 模型能力手动声明

2026-10-26。用户要求推进 1.2 剩余清单中的模型能力手动声明。当前为源码开发版，尚未打包发布；本轮只调用本地模拟模型服务，没有额外调用真实供应商，也没有更改用户当前连接或声明值。

## 已实现

- 聊天 / 工作模型卡新增可折叠“模型能力”。支持上下文窗口、最大输出 token、文本 / 图片输入、关闭或自定义思考档位及 API 参数值；空白项不覆盖，恢复自动只删除当前绑定的声明。
- 声明按具体接口地址、密钥和模型保存，变更绑定不继承，切回可恢复；相同绑定的槽位共用声明，work 跟随 chat 时也共用，思考档位选择仍按角色独立。
- 主进程严格校验字段与界限，旧 modelRef 不能写入新连接。导入、GUI 保存和启动读取保持同一能力语义；无效导入不覆盖原配置。连接配置 / 凭据继续留 main，renderer 只消费当前绑定的安全投影。
- 字段实际传给 DSH 的 pi-ai 模型配置：contextWindow、maxTokens、input、reasoningEfforts。模型元数据展示明确标注“手动声明”与“DSH 目录或默认值”，不伪称网络发现或服务验证。
- off 留空不发送思考参数；填写 off 的 API 值时，当前 DSH 默认请求同样使用它，选择框与说明已明确标注。不提供档位不等于保证供应商停止思考。
- DeepSeek 官方原生连接继续使用原生适配器，只展示其能力，不提供此手动覆盖入口。其他目录路由保留原有协议；声明不替换调用协议。
- LCA 自身后台 / 隐私固定任务若采用同一绑定，输出请求会受声明上限约束，仅文本声明也会阻止图片发送；它们继续使用既有任务上下文裁剪，不引入新的上下文循环。
- 真实协作探针复制当前配置时同时保留声明注册表，本轮只做静态核对，未重新运行真实探针。

共享接口单独提交为 `711af30`（“接口：增加按模型声明能力的配置与安全投影”）。实现沿用包外 bridge，没有修改上游运行时、锁文件或艺术资产；此前未提交的其他工作保留。
