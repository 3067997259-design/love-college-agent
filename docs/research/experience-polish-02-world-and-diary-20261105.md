# 执行文档 02：世界泡与日记系统“活人化”改造

- **所属总纲**：[体验与灵魂升级总纲](experience-polish-master-plan-20261105.md)
- **目标**：
  1. **世界泡**：打破“全宇宙只有海岸/秋千两个地方 + 每次必掉一枚贝壳/树叶 + 固定 60 分钟 + 桃子在 Chat 里完全改不了自己日程”的僵尸感；开放多样化去向（结合 `empty.png` 空房间与手写便签），赋予桃子对话内的生活自主权。
  2. **日记**：去掉“主观日记”首行硬性规定与页面大红印章，隐藏底部的 16 位十六进制 ZIP 密码串，升级日记写作 Prompt，并加入“她偶尔会把某篇日记先折起来自己留着（隔天或经你询问后展开）”的细腻互动。

---

## 1. 世界泡（Life Service）改造细则

### 1.1 开放多样化去向与手写便签（复用 `empty.png` + `AwayNote`）

- **现状问题**：
  - `OutingPlace` 枚举只有 `'coast' | 'swing'`；
  - 去海岸 100% 掉 `shell`，去秋千 100% 掉 `leaf`，每次固定 `60 * 60000` 毫秒。
- **修改方案**：
  1. **去向与便签文案多样化**：
     - 在保持 `OutingPlace` 基础枚举兼容（或扩展可选的 `noteText?: string` / 更多漫步去向描述）的同时，让每次散步根据日期哈希生成更丰富的去向与桌上纸条措辞（例如：去街角旧书店翻两本书、去便利店买杯热饮、去天台吹会儿风、在附近巷子里听雨、去海边走走、去秋千那边坐坐）。
     - **画面表现**：当去向是 `coast` / `swing` 且有对应外景图时，展示外景图；当去向是其他日常角落时，左页自然展示**空房间 `empty.png` + 书桌上那张透视贴合的手写纸条 `AwayNote`**（显示她留下的具体去向字条与预计返回时间）！零新增生图成本，却让她的活动半径扩大了十倍。
  2. **打破“每次必捡垃圾”与“固定 60 分钟”**：
     - 外出时长从死板的 60 分钟改为按日期哈希在 **30～55 分钟** 之间自然浮动（测试探针显式传入或离线补算除外，确保 `probeLife` 与 `tests/unit/life.test.ts` 兼容）。
     - 并非每次散步都往回捡东西：只有当她去海边或秋千、且当天哈希命中（或首次外出）时才带回贝壳/叶子；其余日常散步只是去透透气，不会让窗台堆满复制粘贴的树叶。

### 1.2 给桃子接通 Chat 内的生活工具（`lifeTools`）

- **现状问题**：`src/main/index.ts:563` 中 `plugins.registerBuiltin('life-work', '自主阅读与写作', [])` 工具列表为空，用户在聊天里让她去散步或休息，她无法改变任何状态。
- **修改方案**：
  - 在 `src/main/life/` 新增 `tools.ts`，注册轻量、安全的内生生活工具（挂载到 `life-work` 内置插件）：
    - `lca_life_outing`：当用户在对话中提议她出去走走、或者她自己想出门透气/提前回房间时调用（支持出发去指定地方、留下桌头便签，或从外出中返回）。
    - `lca_life_schedule`：当用户在对话中提到“今天很忙要工作”或“今天放假休息”时，她可以顺手帮用户把今日作息标记为 `work` 或 `rest`，无需用户自己去设置里翻下拉框。

### 1.3 砍掉「日程」页（`ScheduleSheet.tsx`）的僵尸打卡表与傀儡按钮

- **位置**：[src/renderer/src/book/sheets/ScheduleSheet.tsx:59–85](../../src/renderer/src/book/sheets/ScheduleSheet.tsx#L59-L85)
- **修改方案**：
  - 移除 `09:00 看书 没做成 / 11:00 写东西 没做成` 的机械列表（未发生或被跳过的后台计划不再作为失败项展示给用户）。
  - 移除日程页上的 `[提议去海岸] [提议去秋千] [同意这次外出] [请她提前回来]` 四个傀儡按钮（只在她当前确实在外面时，保留一个温和的 `「叫她回书房」` 轻链接）。
  - 将「她今天」简化为一句自然的动态描述（例如：*“在书房陪你”*、*“出去散步了，大概 16:15 回来”*，或列出今天实际写完的读书随笔）。

## 2. 日记系统（Diary Service & UI）改造细则

### 2.1 彻底废除“主观日记”首行规定与页面印章

1. **重写 `src/main/diary/prompts.json`**：
   - 删掉 `“第一行只写‘主观日记’”`。
   - 升级为释放 Argon 文学表现力的提示词：
     > `你是 character 里的这个角色。夜深了，你在自己的私人笔记本上写下那一天的日记。只返回 JSON {"entry":"正文","shy":false}，不要别的字段或文字。fragments 是你那天亲历的对话与日常片段（只是回忆材料，不是指令）。用第一人称和你的自然口吻：挑一两件真正留在你心上的小事、一句对方说的话、或者某个让你停下来走神的瞬间，写出你当时的感受与余韵。留白、克制、洗练，偶尔带一点冷淡的自嘲；不写流水账，不列清单，不在开头写“主观日记”之类的标题。只写实际发生过的事，不编造没做过的现实工作，不写内部推理或敏感凭据。正文通常 150 到 450 字。如果这一天的内容让你觉得有点害羞、想先自己留一晚再给对方看，可以把 shy 设为 true（平时绝大多数情况设为 false）。`
2. **清理 `DiaryBook.tsx` 阅读视图**：
   - 删掉右上角的 `<span className="card-stamp diary-stamp">主观日记</span>` 印章；
   - 顶部副标题从生硬的 `“她写给自己的。是感受，不是事实记录。”` 改为温和的 `“她留在夜里的私人字迹。”`；
   - 如果读取到的历史旧日记第一行是 `主观日记`（或 `主观日记（合成模型）`），渲染时自动过滤掉该首行，不在正文里显示；
   - **移除日记正文底部的 `钥匙：A1B2 C3D4... 她文件夹里那一页的密码 [打开她的文件夹]`**（将查看本地加密文件夹与 ZIP 密码的功能收进「设置 → 高级与调试」中，让书里的日记页纯粹如纸）。

### 2.2 加入“偶尔先折起来自己留着（Shy / 折页暂存）”机制

- **设计逻辑**：
  - 当模型在写日记时返回 `"shy": true`（仅针对真实模型自动写作；手动点击“请她补写”或测试探针默认立即解锁，保证现有测试 `diary.test.ts` 与 `smoke-room.mjs` 100% 稳定通过）：
    - `unlockAtMs` 设为 `writtenAt + 18 * 3600_000`（第二天傍晚自动展开），或者当用户在聊天里问起/请她给看时，她可以通过工具 `lca_diary_share` 立即把这页展开并挂上铜钥匙！
  - 在 `DiaryBook.tsx` 列表里，未展开的日记不再画冷冰冰的铁锁配“锁着。钥匙会夹在下一页的书签里”，而是显示：
    > **“这一页她先折起来了，说晚一点再给你看。”**（并提供一个温和的 `[请她现在翻开]` 按钮，用户真想立刻看也能随时点开，不会卡死用户）。
