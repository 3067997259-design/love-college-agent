# 自动睡眠、早晨唤醒与素材切换

2026-10-26。用户指出早上 08:22 桃子仍显示睡姿，并选择“到早晨时自动醒来，重启时也按当前时间校正”；手动睡眠和熄灯保留。

## 定位

已有事实记录显示：自动睡眠最早在 10-21 04:00 以 `day-end` 写入，随后被每日 carry 保留；10-26 08:23 开灯后仍为睡眠，直到 08:24 手动唤醒才解除。旧服务只处理显式入睡 / 唤醒，没有早晨到期校正。另一个条件缺口是安全日切不分当前时段地申请睡眠，白天补翻昨天的书页也可能入睡。

本轮核对的内置素材路径与主状态一致：

| 程序事实 | 素材选择 |
| --- | --- |
| 地点不在房间 | 对应地点和时段的外景；缺失时回退空房间 |
| 房间内睡姿 | 熄灯用 sleeping_dark；夜间未熄灯用 sleeping_nightlight；其他时段用 sleeping_calm |
| 房间内清醒 | 按主进程姿势、表情、时段选图；熄灯保留清醒姿势并调暗 |

因此此次“赖床”来自睡眠状态缺少恢复规则，素材消费了仍为 sleeping 的投影。WebGL 换图已有旧加载取消守卫，本轮没有复现清醒状态最终仍画睡姿的问题；没有改动已采用艺术资产。

## 实现

- 自动日切入睡只在程序当前夜间执行；白天补翻书页不新增睡眠。
- main 从当前用户 / 角色的事实历史核对最近的 sleep 原因，兼容原有跨日 carry。只有可核实的 `day-end` 自动睡眠安排唤醒，手动或原因不明的睡眠保留。
- 统一 Clock / Scheduler 在入睡后第一个早晨分界唤醒；当前与现有 daypart 共用默认 06:00（上海时间）。启动或恢复时已经过期则立即追加 `day-start` 唤醒事实，不改写旧日志、不重放工作。
- 手动重复指定睡眠会替代自动原因并取消自动唤醒；熄灯保持独立，自动醒来不改 lightsOut、不替用户恢复后台与计时。
- 保留原有交互唤醒和睡眠忙碌守卫，退出时取消此服务的调度。
