# 开始使用

当前发布基线为 v0.2.1（demo 验收版），支持 Windows x64。模型服务由使用者自行配置；开始聊天与整理公开资料不需要学校账号、Python、语音或礼物生成服务。

## 安装与首次聊天

1. 从 [官方 Releases](https://github.com/3067997259-design/love-college-agent/releases/latest) 下载安装器。v0.2.1 文件名为 `Love-College-Agent-0.2.1-Setup.exe`，校验值见 [版本记录](releases/0.2.1.md)。安装器当前未签名，运行前核对来源。
2. 按安装器选择当前用户安装。安装后通过桌面、开始菜单快捷方式或安装目录的 `LoveCollegeAgent.exe` 启动；安装结束不会自动打开应用。
3. 按向导填写昵称，在“填写模型连接”中配置“日常对话”的接口地址、模型和 API 密钥。地址填写 API 根地址，不把完整 `/chat/completions` 请求路径当作根地址。
4. 保存后点击“测试连接”。“已配置”表示已保存，“已经连接”表示本次小请求成功。模型保存即时生效。
5. 完成角色称呼与相处方式设置，发送一条消息。关闭再打开，核对对话仍在；需要验证工具时，可以请她查询本地时间，并查看实际工具结果。

已有 providers JSON 可通过模型设置的“导入模型配置”读取；无需把配置发到聊天或贴进问题反馈。旧配置的额外字段和 BOM 会按已知字段归一化。

## 先完成一次资料整理

准备一份不含私密信息的 UTF-8 文本、Markdown 或带文字层的 PDF，拖入书页，或使用资料选择入口，再提出整理要求。完成后从交付卡打开实际文件。

当前上限为单文件 10 MiB / 120,000 字符、PDF 60 页，同时导入最多 5 份、待处理最多 20 份。扫描 PDF 或截图不能作为已验收的文字输入；文字层 PDF 应能直接选中文字。

新安装默认隐私处理跟随主模型，主模型可处理获授权原文。选择独立隐私模型后，文件是否过滤还由 `/privacy on` / `/privacy off` 控制；关闭时可先暂存，开启并具备依赖后再整理。旧隔离资料不会因为切换模式自动公开，需要显式重试。完整规则见 [隐私与数据](privacy-and-data.md)。

## 安排专注与休息

在日程页提出或修改番茄计划，确认后再开始。草案和正在执行的计划分别保存，确认改动保留当前计时进度。专注时使用迷你陪伴窗，点回书本可展开；休息不抢焦点。

安静陪伴允许受预算约束的后台活动；“熄灯”暂停后台与计时。日记与日摘要需要实际日切，不会在刚安装时凭空出现。普通聊天使用 `/compact` 压缩旧完整回合的模型投影，旧页记录仍保留。

## 按需增加能力

- **校园事务：** 按 [插件说明](plugins.md) 安装校园助手，另行准备 Student Hub 后端及登录配置。候选需要在书页确认，再导出本地文件。
- **只读邮箱：** 在连接设置中配置 IMAP，按提示重启。当前内置入口固定读取“桃子”文件夹的未读邮件，不写已读标记。先确认该文件夹存在。
- **记忆与日记：** 可以跟随主模型，也可以独立配置后台模型。新安装默认跟随；已有独立配置在升级时保留。
- **语音与实时礼物：** 服务可选，配置变更按界面要求重启。礼物制作需要单独同意；未配置时保留文字与预制羽毛笔能力。

## 保存与恢复

在设置的“角色与书本”使用私人存档入口，取得羽毛笔后也可通过它导出。导入时先核对概要，再确认恢复；应用会先备份当前状态，然后重启恢复。不要先删除现有数据来测试恢复。

`.lca-save` 含聊天、记忆和可能的私有证据，当前不加密。它与可分享的角色包不同，不要公开上传。连接配置和凭据不随存档迁移，换电脑后需要重新配置。

## 遇到问题

| 现象 | 检查方向 |
| --- | --- |
| 已保存模型但不能聊天 | 测试连接，核对服务地址、模型与网络，并保留界面的错误分类。 |
| 配置改了仍没变化 | 模型应立即生效；语音、Rodin、邮箱需要重启。确认没有进入隔离开发 profile。 |
| 校园助手不可用 | 先运行依赖检查；后端、Python 和登录配置需要另行准备。失败不表示学校没有更新。 |
| 文件显示暂存或整理失败 | 核对隐私模式、模型依赖、文字层和输入大小，再在资料卡显式重试。 |
| 她不能按一句磁盘路径浏览目录 | 普通聊天没有任意目录工具；上传资料，或在心流的受管理书桌中工作。 |
| 迷你窗有黑角 | 启动前设置 `LCA_MINI_OPAQUE=1`，使用不透明回退，见 [开发与运行](deployment.md)。 |
| 没有声音 | 文字模式可独立使用；语音另需配置，真实质量仍需实际验证。 |

反馈请附版本、复现步骤、预期和实际行为，使用合成样例替代私人文件。不要附密钥、providers 文件、原始邮箱数据库或私人存档。
